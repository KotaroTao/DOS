# 百の迷宮と 魂の王 — Hundred Labyrinths: Rise of the Soul King

ウィザードリィ風の**カードめくり探索RPG**。HTML + ES Modules + Canvas だけで動く、ビルド不要の単一Webゲームです。魔物・装備・迷宮には専用イラストを使い、演出や代替の絵はCanvasで描画します。

**▶ 今すぐ遊ぶ: https://kotarotao.github.io/DOS/**

スマホのブラウザで開いて「ホーム画面に追加」すれば、アプリのように起動できます（PWA対応）。クラウド保存版はオンライン接続が必要です。

Supabaseによるクラウドセーブも設定できます。クラウド有効時はオンライン接続が必要です。規約同意後にメール登録なしのゲストでも開始でき、あとから登録して別端末へ引き継げます。[使い始める手順](docs/cloud-save-setup.md) と [実装・設定の詳細](docs/cloud-save.md) を参照してください。

## どんなゲーム？

死者の魂を喰らう百の迷宮。生身の人間は還れないその深淵へ、人型の器 **「人業（ドール）」** に死者の魂を宿して挑む——あなたは魂を繰る者、〈操霊師（ソウルマンサー）〉。

- **手作りの迷宮を選んで探索** — 本筋と寄り道の迷宮が、物語・報告・発見に応じて開きます。土地ごとの景色や魔物に加え、迷宮ごとの掟が戦い方を変えます。序章から第十四章までの89迷宮を実装（第十四章の敵イラストは実装済み、物語の挿絵は後日制作）し、百の迷宮以上へ拡張する計画です。
- **カードめくり探索** — 裏向きのカードをめくり、魔物・宝箱・罠・死体・泉・土地ごとの足元の仕掛けに出会いながら階段を探します。
- **魂と人業の育成** — 死体や戦闘で手に入れた魂を人業に宿します。メイン魂で職業が決まり、進行に応じて開くサブ魂から他職の技やパッシブを借りられます。技とパッシブは魂Lvで習得し、融合数によるランクのパッシブもあります。
- **無限迷宮** — 第八章の結びを報告すると解放。Lv1の仮の器で始め、魂・品・魂の残火を集めて本編へ持ち帰ります。保存した魂の記憶からの再挑戦もできます。
- **能力と装備・属性相性** — STR/VIT/AGI/INT/PIE/LUKと武器・防具・小手・装飾で隊を育てます。火→風→土→水→火、光↔闇の相性と、魔物ごとの弱点・耐性を見極めます。
- **街の支度と物語** — 人業の館で編成・魂の強化・融合、商会で売買・鑑定・鍛え直し、宿屋で回復。酒場の依頼や噂、王への報告、図鑑・勲章・宝物庫も冒険を支えます。施設の働きは進行に応じて開きます。
- **冒険の記録は1枠** — 自動保存され、設定から保存してタイトルへ戻れます。
- **常時オートセーブの緊張感** — 全滅すれば戦利品を失い、砕けた人業は救出を待ちます。呪いの装備、宝箱の罠、ミミックにも注意が必要です。
- **チップチューンBGMと効果音** — Web Audioで曲と効果音を生成し、街・探索・戦闘・主との戦いで切り替えます。

## 遊び方（ローカル）

ES Modules を使っているため、簡易サーバー経由で開きます（ビルド不要）。

```bash
python3 -m http.server 8000
# もしくは npx serve .
```

ブラウザで `http://localhost:8000/` を開いてください。

### テストプレイ

タイトルの「テストプレイ」から、通常の記録を変更せずに確認できます。試遊中の進行は保存されません。

- **序章を通して遊ぶ**: 最初から、または三体で森・四体で地下墓地・五体で回廊・六体で修道院へ向かう段階から開始。物語と手ほどきを続けて確認できます。
- **迷宮・街**: 層別の一覧から追加済みの全迷宮を選び、指定した階や街から開始できます。森の古屋は「序章」の欄にあります。
- **チュートリアル／ストーリー**: 手ほどきの実操作や物語の場面を個別に確認できます。

画面上部の「終了してホームへ」で通常のタイトルに戻ります。

### 操作

| 操作 | 方法 |
|------|------|
| 移動（カードをめくる） | スワイプ / 隣のタイルをタップ / 矢印キー・WASD |
| 離れたマスへの移動 | めくり済みのマスをタップ（最短経路を歩く） |
| 戦闘 | 敵をタップで攻撃 / 画面下のコマンド（技・防御・逃走・オート） |
| ステータス・装備 | 隊タブ / 人業のカードをタップ |
| ミュート切替 | 🔊ボタン / M キー |

## ファイル構成

```
index.html            画面レイアウト + 起動エラーの自己修復
styles.css            スタイル
manifest.webmanifest  PWA マニフェスト
sw.js                 コードの版更新・画像の継続キャッシュ
src/
  game.js             進行・入力・街と探索・セーブの統合
  board.js            カードの盤面と迷路・出来事・足元の仕掛け
  combat.js           ターン制戦闘と見積もり
  skilldefs.js        共通の技の定義
  jobkit/             職業ごとの固有技・パッシブ・習得表
  souls.js            魂と人業のモデル・職業・融合・ランク
  items.js            装備・道具と能力の計算
  dungeons/world.js   本筋・寄り道・序章の迷宮台帳
  dungeons/           魔物・体質・伝承・迷宮の規則
  quests.js           酒場の依頼と進行条件
  story.js            師を捜す物語・手がかり・解放の場面
  archive-stories.js  読み返す物語の本文
  abyss.js            無限迷宮の深さ・風の掟・主の組み立て
  ui/                 街・隊・出撃・戦闘・図鑑などの画面
  photoload.js        必要になった画像の取得と同時取得数の制御
  sprites.js          共通描画と画像取得後の更新
  battlebackgrounds.js 迷宮ごとの戦闘背景
  catalog/            装備・道具・収集品の台帳
  audio.js            Web Audioの音楽・効果音の窓口
  music/              音楽・効果音の生成
```

開発の詳しい約束事（ID の append-only 運用、公開時のService Workerの版付けなど）は `CLAUDE.md` を参照してください。


## 開発時の検査

テストフレームワークは使わず、`tools/` のNodeスクリプトと、Playwrightによるブラウザ検査で確認します。

```bash
node tools/balance/check.mjs                  # 技・出来事・実測と見積もり
node tools/balance/attack-skills.mjs          # 後発技の用途とMP効率
node tools/balance/resistance.mjs             # 抵抗値・装備・図鑑の開示
node tools/balance/auto-resistance.mjs        # 図鑑の知識とオートの候補
node tools/balance/monster-temperaments.mjs   # 魔物ごとの体質・属性相性
node tools/balance/walls-check.mjs            # 敵の強さの段と個体への適用
```

出撃画面には、章にかかわらず敵の強さの「壁」の倍率や注意文を表示しません。検査は内部の強さの計算を確認するもので、画面への説明を要求するものではありません。
