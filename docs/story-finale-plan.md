## 2. 最後に答える問い

対立の中心は**「誰の意思で、誰の救いを決めるのか」**。

師オルドは、生き切った魂が誰にも引き止められず休めるよう、器へ戻す仕組みに限りを書こうとしている。モルデンは、善悪を問わず一人があらゆる命を支配する「魂の王」の誕生を防ごうとした。弟子は、生きたい者、休みたい者、今日は休みたいが明日は働きたい者に出会ってきた。

弟子にも万能の答えはない。声が聞こえない魂もあり、待っている間に苦しむ者もいる。それでも、その不確かさを理由に一人が全員の生と終わりを決めることを拒む。師の求める休息と、モルデンの恐れる支配の両方を受け止め、魂の王の力を継がずに帰る。

勝った者を正しいと語り手が断定しない。師の善意は本物であり、夜明けの町の幸福も最後まで本物。師やモルデンを操っていた黒幕、悪意による洗脳で対立を解消しない。

## 3. 結末から逆算した世界の仕組み

### 底に眠る力と、その手放し方

底に眠るものは、**あらゆる魂に一人の意思を届かせ、従わせる力**。その力を手にした者が「魂の王」となる。生者も死者も含む命への支配であり、師はそこへ新しい限りを書こうとしている。承認済み本文では、三つの弧を重ねた黒い冠として具体化した。最初の王を引き止める結びを広げたもので、完成後は誰にも渡されず底へ封じられた。

魂の王の力と、魂そのものの巡り・器に魂を宿す術は区別する。最後に終わらせるのは、全員の意思を一人の命令で上書きする力。魂の巡り、個々の灯、眠り灯、器を直して魂を戻す術は残る。人業が一斉に消えたり、世界から蘇生が失われたりはしない。

この区別と、支配する力だけを手放せる根拠は**第十七章の本筋で提示する**。第十八章で初めて都合のよい破壊方法や新しい力を登場させない。単に王位を辞退して次の誰かを待つ終わりにせず、同じ力を次の者が独占できないところまで決着させる。承認済み本文では、外の留めを緩め、三つの弧を開いて響きを逃がし、最後に一つの名の座を砕く。途中で王が命じると結びが締まり直し、響きを抱えたまま砕くと灯も引き裂く。第十八章では隊が外の留めを緩め、最後に師の助けも借りて冠を解く。

### 願いを扱うときの基準

- 器で休むこと、眠り灯に魂を預けること、存在の終わりを望むことを同じにしない。師の決まり「眠り灯に預けた魂はもう器へ戻さない」と、日々の休息を区別する。
- 再会したい生者の願いだけで死者の願いを代弁しない。生き続けたい死者の願いも否定しない。
- 返事がないことを同意・拒絶のどちらにも決めつけない。保護と休息を続けて聞き直せる余地を残すが、それで全員を救えたとは書かない。
- 各地の強制や放置を止めるための具体的な行動は取る。「本人の意思が不明だから何もしない」を弟子の結論にしない。
- 本人の声を聞くことを、戦闘や魂の付け替えのたびに確認を要求する新しい操作へ変換しない。復活の回数制限、隊員の強制離脱、育成済みの魂の消失も作らない。

## 4. 章ごとの構成

各章の本筋は「入口 → 中盤二迷宮 → 結び」を基本にし、中盤の順を替えても情報がつながるようにする。以下の四つは各迷宮の役割であり、名称・ID・階数の確定ではない。

### 第十四章「深淵の聖堂」— 再会を願う者たち

**問い：生者と死者の願いが違ったら、誰の願いをかなえるのか。** 第十三章の大炉の奥から聞こえる鐘と祈りにつなぐ。生者が寄せた祈りが届き、死者を器へ呼び戻してきた聖堂。祈りは善意から始まり、再会に救われた人もいる。

| 本筋 | 見つけるもの・起こす変化 |
|---|---|
| 入口 | 再会の祈りと、それに応えて戻った魂。まず再会の喜びを描く。師もその喜びを見ていたと分かる。 |
| 中盤A | 戻って暮らしたい魂と、生者との約束。一律に戻れなくする法が奪うものを見る。 |
| 中盤B | 休みたいのに祈りで呼び戻される魂。祈る側にも、別れを受け入れられない理由がある。 |
| 結び | 願いの違いを聞き分けず、祈りを実行し続ける主と対決。一方的に呼び戻す働きを止め、望んで再会する道と魂を休ませる場所を残す。 |

寄り道二つは、再会後の日々の支度と、会えなかった者の残した品を扱う。どちらも本筋の結論を逆転させる秘密は置かない。

王への報告では王自身の長命と他人の願いを重ねる。館ではイレーヌとセラが「戻ってきたこと」と「この先も戻りたいか」を別々に語る。師は再会を憎んでいるのではないと伝え、次章では声を確かめること自体が難しくなる。

### 第十五章「凍てつく王墓」— 答えのない灯

**問い：答えられない魂を、どう守るのか。** 第十二章の王家の廟は「終わりを望む明確な声を無視した場所」。こちらは声を失った魂を守るための凍った墓で、別の問題を扱う。第六章の氷の堰と同じ由来にはしない。

| 本筋 | 見つけるもの・起こす変化 |
|---|---|
| 入口 | 壊れかけた灯を、いつか声が戻る日まで冷やして守る営み。待つことによって救われた記録もある。 |
| 中盤A | 長く待って声を取り戻した魂と、待ち続ける側の疲れ。希望を偽物にしない。 |
| 中盤B | 問いかけても返事のない魂と、保護を続けるための具体的な困難。師が残した、答えを書けなかった記録。 |
| 結び | 守るためにすべての灯を閉ざし続ける主と対決。保護の場所を壊さず、聞き直しと手入れができる道を開く。全員が目覚める奇跡は起こさない。 |

寄り道二つは、灯を手入れする者の暮らしと、声を取り戻すために試した工夫を扱う。必須の治療法や唯一の正解は隠さない。

弟子は答えを持ち帰れず、それでも保護を引き受ける人々とつながる。王も館の者も沈黙を代弁しない。墓の下の道が冥府の門へ続き、師に直接尋ねる段階へ進む。

### 第十六章「冥府の門」— 師との再会

**問い：決めずに待つことにも、責任はあるのか。** 終わりを求める声と、引き止める声が重なる門。ここで弟子が師に追いつき、初めて現在の師と直接話す。記憶の中の師との会話で代用しない。

| 本筋 | 見つけるもの・起こす変化 |
|---|---|
| 入口 | 門前に置かれた、今の師の道具。師がこの先へ進む準備をしていると分かる。 |
| 中盤A | 休息を願いながら引き止められている魂を助ける。待つ間も続く苦しみを、弟子自身が目にする。 |
| 中盤B | 師と再会。休ませてほしいと頼まれた魂を、自分の判断で何度も戻した過去を師自身が語る。 |
| 結び | 門を閉ざす主と対決し、道を開く。師との対話は決裂し、師は底へ進む。弟子も自分の意思で追う。 |

師の過去は、救いを押しつけた後悔から、二度と引き止められない限りを設けようとする理由につなぐ。承認済み本文では相手は石工ナタン。弟子を取る前から師と仕事をしており、坑道で死んだ後に器へ戻り、家族の世代が移る間も生き続けた。既存人物へ置き換えず、詳しい年数は本文にない数値を補わない。師は自分の矛盾を理解しながら「それでも誰かが決めねばならない」と責任を負おうとする。

寄り道二つでは、門のそばで別れを支える人々と、戻る道を整える人々を描く。師への反論に必要な証拠は本筋で得る。

館へ帰った弟子は師の言葉も伝える。再会できた喜びと、同じ道を選べなかった苦しみを両方残す。この章で師との最後の戦いを済ませず、弟子が選べる別の道もまだ完成させない。

### 第十七章「竜の巣」— 王にならずに進む道

**問い：善い者が魂の王になれば、解決するのか。** 最深部への道を守る古い竜の領域。一門の祖の記録と竜が見てきた事実を照合し、底の力と、その力を独占させない方法を明かす。

| 本筋 | 見つけるもの・起こす変化 |
|---|---|
| 入口 | 竜が底への道を守る理由と、師がそこを通った痕跡。竜を全知の解説者にはしない。 |
| 中盤A | 祖の名と記録。祖は闘技場の灯番の子であり、器へ戻す術そのものの発明者ではないと整理する。 |
| 中盤B | 底の力の正体と限界。魂の巡りを残したまま、全員へ命令する力を手放せる根拠・具体的な手順・危険を知る。 |
| 結び | 道を守る竜の主と対決。力を継げる弟子にもそれを拒む覚悟があるかを問うが、勝利を正しさの証明にはしない。最深部への道を開く。 |

祖の記録では、「魂を、腐らせるな」「そのためなら、何をしてもよい」が主の死後も残った経緯と、「底に触れるな」という警告の理由を結ぶ。祖も人業を捨てた者であり、無傷の聖人にしない。祖の名は承認済み本文で**エリアス**と確定。この章より前の図鑑や依頼に漏らさない。

寄り道二つは竜とその領域の暮らし、長く守り続けることの代償を扱う。閉架の書庫を探索済みなら研究の積み重ねに触れてよいが、未探索でも本筋で同じ結末へ進める。

ここで弟子の方針が定まる。師の代わりに善い法を一つ書くのではなく、一人がすべての命を従わせる力を終わらせる。館の灯を守る意味も「師の言いつけ」から、それぞれの意思へ移る。

### 第十八章「終焉の玄室」— 師を連れて帰る

**問い：すべてを決める力を得られるとき、何を選ぶのか。** 魂の王の力が眠る底。新しい文明史や黒幕の説明を重ねず、これまで聞いた声と師の決意を結末へ集める。

| 本筋 | 見つけるもの・起こす変化 |
|---|---|
| 入口 | これまでの土地から魂が巡ってくる道。生きたい声、休みたい声、まだ答えられない灯が同時にある。 |
| 中盤A | 力を手放すための準備を進める。第十七章で知った手順を実行し、帰還の道も確保する。 |
| 中盤B | 師の準備した法を知る。大事な者だけを例外にしない覚悟と、一人では聞き取れなかった声の両方を確かめる。 |
| 結び | 本編最後の敵、師オルドとの対決。勝利後に弟子にも力を継ぐ機会が来るが、継がずに支配する力を終わらせ、師と帰還する。 |

寄り道二つは、帰る者の支度と底に残された個人の記録を扱う。先に探索でき、エンディング後にも探索を続けられる。最後の決着を寄り道へ移さない。

最後の対話の核（台詞の最終稿は本文制作時に整える）：

> オルド「お前は、一つずつ尋ねて歩くつもりか。返事のない灯には、いつまで待つ」
>
> 弟子「分かりません。ですが、私に答えがないことと、師がすべてを決めてよいことは、同じではありません」

師は最後まで自分の理由で戦う。敗北後の記憶だけで和解を済ませず、現在の師と弟子が話す。世界が勝手に解決する奇跡や、師の自己犠牲による死亡で決断を肩代わりさせない。

## 5. エンディングと、その後の世界

1. 魂の王の力を終わらせる。魂や器を消すことで解決せず、眠ることも再び生きることも選べる手段を残す。
2. 師は生きて帰る。弟子への全面降伏や即座の免罪にはせず、自分が助けた者と傷つけた者の声を、今度はその場で聞いていく。
3. 夜明けの町は暮らしを続ける。ミラの感謝とヨルクの願いをどちらも残し、眠り灯から戻りたい声にも耳を向ける。全員が同じ答えになる後日談にしない。
4. 王は、名を奪われた者の名を取り戻す責任を引き受ける。用意された自分の棺へ入る日を、結末の都合で即座に決めさせない。
5. モルデンの灯は眠ったまま保たれる。師を止めたから正しかったとも、旧都を沈めたことが許されたとも書かない。
6. 最後は人業の館へ帰る。イレーヌの意思で守られた灯が、師を迎える。

最後の場面の核：

> オルド「……まだ、灯を守っていたのか」
>
> イレーヌ「はい。お帰りを待ちたいと、私が決めました」

冒頭の「館の灯を、絶やすな」が、イレーヌ自身の選択として返ってくる。師を捜して始まった物語を、師の帰還で閉じる。

クリア後は本編の迷宮、依頼、育成、無限迷宮、宿敵の再戦を続けられる。クリア前へ時間を巻き戻して結末を無かったことにしない。主の再戦は既存の記憶との手合わせに合わせ、魂の王の力が復活した扱いにしない。世界の大きな支配を終えることと、各地の魔物や未解決の営みが残ることを両立させる。

## 7. 制作の順序と一章の完了条件

### 本文で確定した詳細と、次の制作

第十七〜十八章の冠の姿・成立・解き方と危険、第十六章の石工ナタンとの過去、祖エリアスの名は、完成稿で具体化しユーザー承認済み。エンディング第七場面は、師がイレーヌへ説明できなかった理由を自分の口で話し、イレーヌ自身の言葉を聞く「書けなかった言葉」に置き換えた。

第十四章は w54〜w57・ws30/31 として完成稿を進行条件へ割り当て済み。六迷宮・依頼・手がかり・館の会話・魂の転生を実装し、専用イラストは後日制作する。次は第十五章の詳細設計と実装へ進む。ゲーム側の判定・保存・画像の仕様は本文の保存だけでは追加しない。

その後は十四→十五→十六→十七→十八の順で、一章ずつ「六迷宮の詳細設計 → 本文一式 → ゲームへの実装 → 通し確認 → 専用イラスト」を進める。本文と機能の実装、画像の制作はレビューできる単位のPRに分けてよい。

### 六迷宮の詳細設計で決めるもの

- 迷宮ごとの景色、暮らしていた者、探索の目的、踏破で変わること。主には土地を守る・動かし続ける理由を持たせ、五章を同じ「命令装置を壊す話」の繰り返しにしない。
- 本筋の手がかり・主との対面・主の記憶・報告・館の語り・章の結びを、一続きで読める本文として用意する。重要な体験を過去の記憶だけで済ませない。
- 寄り道二つの依頼、人物、由来、報酬。本筋を補う立場と暮らしを置き、章の結論に必要な情報は本筋にも置く。
- 階数・推奨Lv・掟・足元の仕掛け・魔物・品・極めて稀なる出来事・手がかりの恵み。既存の追加規則は `CLAUDE.md` に従う。
- 章ごとの機能解放は `docs/unlocks.md` の計画を引き継ぐ。本書では新たに実装済みとしない。魂の転生などの遊びの用語を、物語上の強制的な生まれ直しと混同させない。
- 挿絵・人物と小道具の参照・魔物・戦闘背景・盤面・出撃画面・依頼人の絵の一覧。本文の確定後に物語の絵の指示書を作り、既存の制作手順へ渡す。

### 各章の確認

- 本筋中盤の順を替える、手がかりを見落とす、報告を後回しにする、主に負けて再挑戦する場合でも進める。前章までのセーブから新章へ到達できる。
- 寄り道を一度も遊ばなくても物語が成立し、図鑑・由来・依頼・酒場の話・試遊一覧が後の核心を先に明かさない。再挑戦で核心の開示を早めない。
- 手がかりの恵み、迷宮の掟の代償と見返り、足元の仕掛け、極の割り当て、敵の強さと報酬を既存の検査で確認する。新章の酒場の言い伝えと、機能に関する心得も整える。
- 章末で、その土地に暮らす者の状況が具体的に変わる。問題が残る場合は、何を止め、何を引き受けたかが分かる。
- 第十八章では、最後の戦いの負け・再挑戦・勝利後の保存と再開でも結末が欠落・重複せず、クリア後の探索・育成・再戦を続けられる。
