# 武魂 #1309 に合わせた装備性能の再調整

基準は #1309 マージ後の `0c4dfa419ec0287ba607a735dc3722e6ed22f0ed`。全2,050点を再点検し、827点の割合性能を変更した。属攻451点、属防264点、状態異常耐性147点（重複あり）。基礎能力・武器係数・装備条件・会心性能は全点で維持。指定済みの確定首級24点は、割合性能と重複方法も変更しない。全品の前後は [equipment-percent-audit.csv](equipment-percent-audit.csv)。

## 数値の基準

武魂は現在138種、直線成長・部位制限あり（最新mainの#1311も反映）。装着枠はC/UC1・R/SR2・LR3。属攻はLv×20%、属性軽減と状態異常耐性はLv×5%。装備の役割は属性付与と固有の得意分野、武魂の役割は部位ごとの補完と育成とする。

- 通常の属攻の帯はC10〜20 / UC20〜30 / R30〜50 / SR40〜80 / LR60〜100%。隠しLv1〜200で線形補間、旧上位品は+20%、武器以外の増幅は6割、10%刻み（最低10%）。最大120%。武魂Lv1の+20%、Lv10の+200%に対し、装備選択も意味を持つ帯にする。武魂は無属性の武器に属性を付与しない。
- 通常の属防は耐性力を経由せず、直接の軽減率にする。帯はC5〜10 / UC5〜15 / R10〜20 / SR15〜25 / LR20〜30%。胴1.2、盾1.1、頭0.8、小手/靴0.7、装飾0.9倍、旧上位品+5ポイント。5%刻み・単体5〜35%。副属性は主属性の約半分（最低5%）。来歴別の防御対象274点と元の絵の色は維持。
- 状態異常耐性はC5〜15 / UC10〜20 / R15〜25 / SR20〜35 / LR25〜45%の帯。元の得意度を75%、入手段階を25%として帯の中を補間し、5%刻みにする。品質は既存どおり影響する。武魂・パッシブで95%まで補強する余地を残す。
- 専門品は個別に設定。静寂の聖骸布は眠り/魅了/混乱40%・即死30%、鳴かぬカナリアは毒45%・麻痺/石化30%、凍王の氷冠は麻痺/混乱45%・魅了30%・石化/眠り25%。終盤の解呪の宝珠は固有の全異常耐性95%を維持する。
- 会心は従来の帯を維持。武魂の会心は武器/小手に限られ、他の部位の固有会心は上限までの補助になる。連撃、再生、ブレス耐性、追加付与、物理/魔法耐性、一戦一回の自動蘇生などの指定効果は維持する。

## 加算・旧品

通常の装備固有20%と武魂20%なら40%軽減。同属性合計は80%。全属性耐性も同じ枠へ加算する。旧耐性力の品・確定首級・旧付呪は互換形式を保持し、耐性力の合計RからR/(100+R)を算出して直接軽減に加える。物理/魔法耐性80%・恒常複合90%は従来どおり。回避は軽減とは別の命中判定。

既存品はロード・品質再構築時に目録へ同期する。品質・武魂・鍛造・ロック・共有参照は保つ。魂の記憶を再構築しない既存ルールは維持。新規装備は `eDef:{kind:"defense",reductions:{fire:0.2}}` で直接軽減を定義できる。旧 `{el,pct}` / `{values}` も有効。

## 表示・最適装備

戦闘・品の説明・比較・価格・最適装備は共通の `elementDefenseReduction` を使う。武魂の単属性/全属性の直接軽減を評価に含め、同属性80%を超える分は加点しない。靴の回避武魂も評価し、見切り込み80%を超える分は加点しない。条件つき武魂の与ダメージ/軽減の上限は、条件成立後の合計へ適用する。

特定の敵を決めない汎用評価で、物理40/呪文40/ブレス20%、無属性込み7属性を均等に見る。回避は同速の敵（基礎10%）を仮定。条件つき効果は条件不成立/成立の2通りの平均、追加付与は耐性0/50/80/95%での成功率平均。実際の敵・戦況ごとの最適解ではない。特殊武魂の探索効果や発動条件は付け替えの得失の説明にも残し、必要な品はロックして持たせられる。

武魂ヘルプの倍増・無料合成・旧最大Lvの記述と、無限迷宮の格抽選の説明を #1309 に合わせる。心得 `t_equipment_percent_role` / `t_elemdef` / `t_enchant3` を更新し、`t_equipment_bukon_balance` を追加。
