## 1. 目的

- 入るたびに Lv1 から始まるローグライク。毎回中身が変わり、運が悪いとすぐに全滅する。
- 何度でも新鮮に遊べて、どこまで潜れたかを競うエンドコンテンツ。
- 本編とは完全に別の遊び。**本編を進めて有利になるのは、図鑑で敵の情報が分かることだけ**。

## 2. 名前と設定 (決定)

- 名前は **「無限迷宮」** で統一する。本編の「奈落」(第五章〜の物語の舞台) とは完全に別物。画面・ヘルプ・心得から「奈落」の呼び名を外す。
- 無限迷宮の口に吹く風は、育って重くなった魂を吹き返す。軽い魂しか降りられない。
- だから入口に漂う **「名もなき魂の欠片」** を、土くれの **仮の器** に宿して降りる。本編の人業・魂はそのまま街に残るので、同時に存在しても矛盾しない。
- 器は迷宮を出ると崩れる。最初に宿した欠片は迷宮へ還る (= 最初のメイン魂は持ち帰れない)。
- **風だまり** (5の倍数の階の、主の手前の踊り場。吹き上げる風が止む所) に2人がいる:
  - **回収人** (商会の者): 迷宮で拾われた品を引き取り、商会の棚へ回す。売却・回復の道具・風切りの羽・鍛え直し。
  - **灯番** (名もない人業): 踊り場の古い灯籠を守り、器と魂の欠片をつなぎ直す。メイン魂の付け替え・✦Soul での魂の強化・魂の残火での Lv上限UP。正体は語らない。
- 「持ち帰った品は商会に並ぶ」は、回収人が商会の者だから、で説明がつく。

## 3. 始まり (決定)

- 隊は仮の器6体。装備なし・持ち物なし (帰還の鈴も持たない)。
- 1人ずつ、3つの魂から1つを選んでメイン魂にする。
  - 出るのは **コモンとレアだけ** (比率は通常の入手と同じ 70:20 を2種で割り直す)。エピック・レジェンドは迷宮の中で拾うしかない。
  - 3つはすべて違う職業。ほかの器が選んだ職業は出ない。
  - セラの灯守 (unique) は出ない。
- 全員 Lv1。
- 魂の安定度は消費しない (仮の器なので)。

## 4. 本編から乗せないもの (決定)

- サブ魂は無い。
- 控えの結社・極めて稀なる出来事の永続強化・手がかりの恵み (回避+1%・ブレス耐性+5% ほか)・本編の装備や品は乗せない。
- souls.js `recalcDoll` が人業すべてに足している底上げ (`setOrderSource`・`setPermanentStatSource`・`syncClueBoons` 由来) を、仮の器では切る必要がある。

## 5. 迷宮の進み方 (決定)

- 5階ごとが1区切り。**5の倍数の階 = 風だまり (回収人・灯番) → 主 → 「帰る / 続ける」** の順。
- 帰還魔法陣は無い。帰れるのは **主を倒した後の「帰る」** と **全滅** だけ。
- 毒の沼 (蝕む床) と落とし穴 (落ちる床) は **6階から** 出る。風切りの羽 (浮遊の道具) は回収人が常に売る。
- 迷宮の掟・異変は、浅い階では軽いもの、深くなるほど強いもの (魔封じ・必ず奇襲のような強い掟は深い階で解禁)。段の表は別途作る。
- 回収人が売る回復の道具は、階の深さで強くなる。回収人に売った品は、商会に売ったのと同じ扱い (商会の在庫になる)。

## 6. 敵 (決定)

- 雑魚は、本筋・寄り道の迷宮の魔物を深さに応じて出す。**本編でまだ到達していない章の魔物も出す**。
- **本編の主・強敵 (名のある強敵)・出来事の魔物は出さない**。
  - よって首級・懸賞は無限迷宮とは関わらない。
- **無限迷宮の主 (5階ごと) と強敵は、既存の魔物 (雑魚) からランダムに選び、レベルを高くする**。
  - 抵抗値は強敵・主の段に準じる (resistance.js の主/強敵の基礎値・即死と怯みの扱い)。
  - 実装の目安: 出来事の魔物の `spawnRanked` (その階の雑魚の最上位ランク + n、HP 倍率) と同じ作り。主・強敵として扱う印 (`_strongFoe` 相当) を付け、溜め・払いのけ・弱体は −2段まで・強敵の回避の上限などを本編の主・強敵と同じに効かせる。
  - 表示Lv (enemylevel.js) はその魔物の雑魚としての基準から測るので、自然に高く出る。

## 7. 図鑑 (決定)

- 無限迷宮で倒した魔物も図鑑に登録し、討伐数も数える (本編の討伐と合算)。
- 名前・姿・能力・属性・抵抗値・説明文は、本編か無限迷宮の討伐数で今までどおりの段 (名前1体・能力5体・説明10体、主/強敵は1体) で明かす。
- まだ倒していない魔物は、どちらでも不確定名と影のまま出る。
- **伝承 (`monlore.js`) だけは、本編で1体以上倒すまで伏せる**。無限迷宮で10体倒していれば、本編で1体倒した時点で伝承が開く (段は合算の討伐数で判定し、「本編で1体以上」を別に記録する)。
- 出現する迷宮の一覧で、本編でまだ地図に現れていない迷宮は「？？？」と出す。

## 8. 育ち方 (決定)

- 戦闘の経験値は魂に直接入る。
- 迷宮で拾う ✦Soul は、灯番で魂の強化に使う (いまの隊の Lv上げ・新しく拾った職の魂を育てて実戦ですぐ使う、など)。
- 迷宮の中で、すでに持っている職の魂を拾うと **自動で融合** する。
- 灯番でのメイン魂の付け替え:
  - **砕けた (死んだ) 器はメイン魂を付け替えられない**。
  - 付け替えても受けた傷・状態異常は残る。**HP・MP は今の値を引き継ぎ、付け替えた魂の最大値を超えるならその最大値にする**。
  - 確認画面に、付け替えた後の HP・MP を出す (最大の小さい魂に替えて戻すと減ったままになるため)。

## 9. 落とし物 (決定)

- 迷宮の中の品は、最初から鑑定済みで落ちる。
- 無限迷宮だけの装備・称号・勲章を作る。無限迷宮だけの職業は作らない (一旦廃止)。

## 10. 持ち帰り (決定)

| もの | 帰る (主の後) | 全滅 + 赤い魂 | 全滅 (赤い魂なし) |
|---|---|---|---|
| 拾った魂 | ○ | ○ | × |
| 拾った品 | ○ | ○ | × |
| 拾った魂の残火 | ○ | ○ | × |
| 最初に選んだメイン魂 | × | × | × |
| 金貨・✦Soul | × | × | × |

- **魂**: 拾った数ごとに **＋1 (融合の素材)** として本編の魂に足す。**Lv は捨てる** (迷宮で ✦ を注いだ分も)。自動融合された分も、拾った数として持ち帰る (拾った数を記録する)。帰還画面で「＋1 の素材として持ち帰る・Lv は残らない」をはっきり示す。
- **品**: 手元には届かず **商会の棚に並ぶ** (本編で手に入れるには金貨で買う)。
- **魂の残火**: 迷宮で使ったかどうかに関わらず、**拾った数** を本編の残火に足す (拾った数を記録する)。

## 11. 装備可能レベル (本編も共通、決定の方向)

- 全装備に「装備可能レベル」を設ける。基準は人業の **メイン魂の Lv**。適正より高い品を手に入れても付けられないのは問題なし。
- 値の決め方 (ユーザーの案を式にしたもの):
  **必要Lv = その品のランク (R = ceil(隠しLv/10)) が通常の抽選で落ちうる迷宮 (落とし物の上限 `lootCapR` = 基準R+2 が R 以上) のうち、推奨Lv が一番低い迷宮の推奨Lv (1階)**。
  - 品ごとに迷宮を調べるのでなく、**R ごとの表** を読み込み時に台帳から作る (落とし物から外した品・依頼や宝物庫の品・首級・無限迷宮だけの品にも同じ式が使える)。
  - 数えるのは通常の抽選の窓だけ (宝箱ランク・からくり錠・掟の lootBonusLv の上乗せは数えない)。
  - LR (`LR_UNLOCK`) と層の逸品 (`layer`) の条件も式に入れる。
  - 本編の迷宮で落ちないランク (いまは R19・R20) は、台帳の伸び方で延長する。
  - 現在の台帳での値の目安: R1〜3 = Lv1 / R4 = 10 / R5 = 18 / R6 = 22 / R7 = 30 / R8 = 37 / R9 = 41 / R10 = 49 / R11 = 55 / R12 = 62 / R13 = 70 / R14 = 75 / R15〜16 = 89 / R17〜18 = 100 (寄り道 ws13)。
- 無限迷宮の深さごとの推奨Lv は、隊が Lv1 から実際に育つ速さと同じ曲線にする (ずれると深い階の品がどれも付けられない)。
- 付けられない理由の札・最適装備・商会・図鑑・候補の表示すべてに出す。メイン魂を替えて Lv が下がった時は、付けられなくなった装備を袋へ戻す (`fixHandsAndShields` と同じ形)。

## 12. セーブとやり直し (決定)

- 行動ごとにオートセーブし、やり直しはできない。
- **乱数はゲーム全体で種つきの乱数に替え、乱数の位置もセーブに入れる** (読み込み直しても同じ結果になる)。
  - 乱数は「遊びの乱数」(結果を決める・保存する) と「演出の乱数」(粒子・揺れ・保存しない) に分ける。演出が遊びの乱数を消費すると、速さの設定で結果が変わる。
  - 順番は「結果を確定 → 乱数の位置ごと保存 → 演出」。演出の途中で閉じて読み込み直す抜け道を残さない。
  - combat.js だけで `Math.random` が63か所ある。**無限迷宮とは別の PR で先に入れる**。
- 無限迷宮の進行は、本編のセーブとは別のキーに小さく保存する (毎回ゲーム全体を書くとスマホで重い)。

## 13. 出来事 (決定)

- 無限迷宮だけの出来事を **約100種** 作る (本編の events.js の出来事は使わない)。
- 報酬の語彙は「品・魂・回復・この出撃だけの強化・金貨 (回収人で使う)・✦Soul・呪い」に絞る。
- 風だまりの回収人・灯番は出来事ではなく、5の倍数の階に必ず置く。

## 14. 今の奈落を置き換える時の後始末

- `abyssMaxDepth` (深さの上限)・`FEATURES.abyssDeep` (第十八章の結び) は不要になる (第十八章の解放の枠が空く)。
- 第五章の結びの解放ページ (`UNLOCKS.infinite`)・ヘルプ・酒場の心得・テスト記録 (`A3` などの欄)・出撃画面の奈落の頁を新しい仕様に直す。
