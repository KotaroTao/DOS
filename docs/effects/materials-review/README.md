# 技の材質とランクの比較

[全37系統・ランク1/2/3の比較画像](families-ranks.png)。火柱も同じ盤面・同じ時点で載せ、材質の濃淡・輪郭・密度を見比べる。画像は尺の40%の静止画なので、動き全体の評価には本編の設定「技の演出を試す」を使う。

`python3 tools/effects/materials-browser.py` で生成する。全960技への材質適用と、37系統×3ランク×通常/軽量×動き低減ON/OFFの444比較を検査する。通常は時点ごとに形が変わり、動き低減では形が固定すること、素材取得失敗時も描画が残ることを確認する。描画の存在を、画質が同じであることの判定には使わない。

制作素材は `tools/effects/build-material-textures.py` から生成した10材質×18コマの共用アトラス。比較画像は公開サイトへ配信しない。
