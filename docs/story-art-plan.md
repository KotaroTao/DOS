# ストーリー専用イラストの制作台帳

オープニング画像と承認済み3枚を共通の基準とする。本文・解放条件は `src/archive-stories.js` が正本。章ごとに4〜6枚を制作し、手指・人数・人物造形・本文との整合性・スマホ表示を確認してから提示する。確認待ちの画像は `art/story-review/` に保存し、承認後に `art/story/` とゲーム表示・SW登録へ反映する。

## 共通基準

- 3:2、1536×1024の原画。ゲームではオープニングと同じ384×256相当の表示を基準にする。
- 細かなドット、自然な頭身、石・金属・木・衣装の質感、冷たい月光と暖かいろうそくの光。
- 王：長い白髪と白い髭、痩せた老いた顔、尖った金の王冠、赤い衣、黒い斑のある白い毛皮。
- 宰相：痩せた長い顔、くぼんだ目、黒紫の高帽、赤い内衣、金の官職の鎖と赤い宝石。
- イレーヌ：既存画像と承認済みの出会いを参照。黒い長髪、紫の目、金の髪飾り、紫と黒の衣、黒いレース。正体を明かす場面より前は継ぎ目を見せない。
- 弟子：承認済み画像の暗い旅の外套、控えめな金の模様、革の肩ひもと荷袋。背面・横顔中心。
- 人業：オープニング第三幕の木の器、丸い木の頭、黒鉄の継ぎ目。前半の隊は戦士・僧侶・盗賊、四体目が魔導士。
- セラ：髪は本物の長い黒髪 (ユーザーの指示、2026-10。本文もそれに合わせた)。彫られた木の顔、額に金の「灯を掌に載せた手」。基準は灯守の原画 `docs/art/sera/sera-r1-final.png`。
- 館の師の灯は燭台に立てた一本の蝋燭。師のランタンは第一章の地下墓地に残され、以後、記憶の中の師は持っていない。
- 人物・小道具・時の流れの正典は `docs/art/codex-story-art-brief.md` の「2. 正典」にまとめた。
- 手指は親指＋4本。謁見の隊は3体、出立・門衛の隊は4体。

## 次の制作

第一章「師の灯」の全15場面は承認済み。`art/story/chapter1/<場面ID>.png` をストーリー画面へ適用し、SWにも登録済み。原画・一覧・制作記録は `art/story-review/chapter1/` に保存。序章の人物・建築・細密ドットの画風を参照し、宰相と人業の造形を修正済み。

第二章「捨て砦」は全13場面を各1536×1024の専用原画として承認済み。確認用原画と本文の一覧は `art/story-review/chapter2/index.html`、場面ごとのファイルは同ディレクトリの `<ID>.png`。本文は `src/archive-stories.js` に合わせて `scenes.json` にも保存。王宮・館・隊の既存原画を基準に人物と衣装を統一し、不要な人物の混入と師の燭台を修正した。制作時の作業環境には第一章の完成原画が未収録だったため、序章の既存原画と共通基準を参照した。`art/story/chapter2/<場面ID>.png` をストーリー画面へ適用し、SWにも登録済み。

序章の6枚を確認後、「砕けても、名は消えない」と第一章の手がかりを次の便で制作する。オルド・セラ・ヴェルナーを描く前に、既存の設定に合わせた人物基準を固める。王宮や館は承認済み画像と同じ建築・衣装を参照し、場面ごとに構図を変える。先の章の正体や手がかりを背景に紛れ込ませない。

第1便の門衛の場面は、盗賊の弓・矢を除いて短剣の装備へ変更し、魔導士の衣装を出立の絵と同じ紫の衣に修正済み。序章第1便6枚は承認後に `art/story/` へ反映し、オフライン対象にも登録済み。

第1便の3枚目「最初の名前」は、中央の余分な腕を除去して左右1本ずつの計2本へ修正済み。

第三章「魂脈の根」の11場面は、序章・第一章の制作済み原画を画像生成の参照として直接渡し、1536×1024のPNGで作り直した。簡易SVG描画の旧画像を `art/story/chapter3/` の新原画へ置き換え、ゲームのストーリー表示とSW登録へ反映済み。第二章の完成原画はこの作業環境には見つからなかったため、確認できた序章・第一章の人物・衣装・細密な質感を基準とした。

参照画像と生成元の記録は `art/story-review/chapter3/manifest.json`。本文と画像の全48場面一覧は `art/story-review/chapter3/index.html`（初期表示は第三章）。`tools/storyart/chapter3.mjs` は画像を生成せず、原画の反映と正本からの一覧再作成を行う。

第四章「王都の地下」の全10場面は、第二章・第三章の既存原画を画像生成へ直接渡し、各1536×1024のPNGで制作した。王・弟子・イレーヌの衣装と造形をそろえ、セラは第二章の木製の顔と第三章の胴を基準に修復後の姿を描いた。`art/story/chapter4/` をストーリー一覧とゲーム内の同じ場面へ適用し、SWにも登録済み。

第四章の原画・本文一覧は `art/story-review/chapter4/index.html`、参照画像と生成元の記録は同ディレクトリの `manifest.json`、本文の記録は `scenes.json`。`node tools/storyart/chapter4.mjs` で保存済み原画の反映と一覧の再作成を行う。
