## 1. 釣り合いの考え方

### 1-1. 数値は「同じランクの標準品の点」を物差しにする

- 1つの追加の大きさ = **基準点 B(R) × 割合**。
- B(R) = その品と同じランク (R) の標準の防具 (体・頭・足・小手・盾・装飾) の性能点の平均。性能点は値段の式 (`pricing.js` の `STAT_W`: STR・VIT・AGI 1 / INT・PIE 0.7 / LUK 0.6 / HP 0.15 / MP 0.25 / 会心1% = 1) と同じ物差し。
- いまの目録での B(R) の目安: R10 ≈ 28点 / R15 ≈ 49点 / R20 ≈ 76点。
  - 例: R10 で 0.2 × B = 約6点 → STR +6、または HP +37、または INT +8。
- 武器も防具も同じ B(R) を使う (武器の点は攻撃性能が大半なので、武器の点を物差しにすると能力値が大きくなりすぎる)。
- **値段も同じ点で上がる** (決定: 追加の分だけ値段が上がる)。点の式が1つなので、強さと値段が必ずそろう。

### 1-2. 格 (追加1つの強さの段)

| 格 | 印 | 割合 (B(R) に対して) | 内容 |
|---|---|---|---|
| 常 | なし | 0.15〜0.25 | 能力値1つ・状態異常の抵抗など |
| 稀 | ◇ | 0.25〜0.35 | 能力値2つ・属性・特効・追加効果など |
| 秘 | ◆ | 0.35〜0.50 相当 | %補正・条件つきの与ダメ/被ダメ・発動する効果 |
| 極 | ★ | 固定 (下の表 J・X) | 戦い方が変わるもの。武器・胴・頭・小手は6つ、足は7つ、装飾は9つ |

- 割合の幅の中では、深い階ほど上の方が出やすい。
- 条件つき・発動する特性は点に直しにくいので、表の数値を固定で決め、値段の点は `pricing.js` の `EFF_PTS` と同じく固定点にする。

### 1-3. 付く数と格の出やすさ (深さで変わる)

| 階 | 付く数 | 常 / 稀 / 秘 / 極 (%) |
|---|---|---|
| 1〜20 | 1 (25% で 2) | 85 / 15 / 0 / 0 |
| 21〜40 | 1 (50% で 2) | 70 / 25 / 5 / 0 |
| 41〜60 | 2 (30% で 3) | 55 / 32 / 12 / 0.05 |
| 61〜80 | 2 (60% で 3) | 45 / 35 / 17 / 0.1 |
| 81〜100 | 3 (30% で 4) | 35 / 38 / 22 / 0.25 |
| 101〜 | 3 (60% で 4) | 30 / 38 / 25 / 0.4 |

- レジェンド装備は81階以降、4つ付く抽選に当たると同じ確率 (81〜100階30% / 101階以降60%) で5つ目を抽選する。5つになる確率はそれぞれ9% / 36%。各枠で格を独立して引くため、極が5つ付く組も極めて低い確率で出現しうる。

- 極は 2026-10-15 に下げた (以前は 1 / 3 / 5 / 7)。付呪 (6章) で誰の装備にも書けるので、拾えること自体をごく稀にする (ユーザーの指示)。2026-10-15 から極は全部位に付く (X)。品1点あたりでは 150階の装飾でも約1.5%。

### 1-4. 重ねすぎを防ぐ決まり

- 1つの品に **同じ種類は1つまで**。**属攻・属防はそれぞれ1属性まで**。
- 無限迷宮で拾う品の極の数に制限は無い。**発動する特性 (J) は1つまで**。付呪では、すでに極を持つ品に極を追加できない。
- 1つの品の追加の合計は **B(R) × 1.0 まで** (超える分は引き直す)。深い階の4つ付きでも、標準品の約2倍が上限になる。
- 隊の1人が装備全体から受ける上限 (種類ごと):
  - 与ダメ (条件・特効の合計) +40% / 被ダメ −30% / 会心 +10% / 回避 +6% / 消費MP −20% / 回復量 +20%。
- **付けないもの** (LR と本編の価値を守る): 連撃・状態異常無効・属攻◎ (Lv2)・物理または魔法の抵抗 +10 超・経験値の倍率。
- 付くのは無限迷宮で拾った装備だけ。本編の迷宮で拾った品には付かない。
- 品の名前の前に、一番格の高い追加の名を付ける (例: 「窮地の」ロングソード)。格の印 (◇◆★) を名前の後ろに出す。レア度の色とは別。

## 6. 付呪 (無限迷宮からの初回帰還 — 2026-10-16・実装済み)

無限迷宮から初めて戦利品を持ち帰った時に解放する（通常帰還・保護帰還。没収全滅は含めない）。無限迷宮で拾った品の追加の能力・特性を、本編の好きな装備へ移す。

### 6-1. 流れ

1. **写し取る**: 商会の「付呪」で、特性の付いた品 (袋の品・商会の棚の追加つきの1点) から特性を1つ選んで「特性の巻物」にする。**元の品は消え、ほかの特性も失われる** (ユーザーの決定)。棚の品は買値を払って写す (棚の組は消える)。装備中・ロック中・保存編成の品は写せない。
2. **書き込む**: 特性の巻物を、金貨を払って手元の装備品 (装備中・袋) に書く。巻物は使い切り。
3. **消す**: 手元の品の特性を1つ消せる (費用なし)。巻物には戻らない。
- 巻物は `G.afxPages` (保存する)。袋の枠には数えない。街の商会でだけ使える (無限迷宮の中では使えない)。

### 6-2. 決まり

| レア度 | 書ける数 | 能力値の容量 (B(R) に対して) |
|---|---|---|
| コモン | 1 | 0.35 |
| アンコモン | 2 | 0.55 |
| レア | 3 | 0.75 |
| スーパーレア | 4 | 0.9 |
| レジェンドレア | 5 | 1.0 (= 無限迷宮で拾う品の上限と同じ天井) |

- **格の上限は無い** (ユーザーの決定)。コモンにも極を書ける。
- 容量に数えるのは能力値の特性 (A・B・D・K の kind B / fixB) だけ。割合・条件つき・発動する特性は数えない (拾う品の上限と同じ数え方)。
- 1つの品に、同じ種類は1つ・極は1つ・発動する特性 (J) は1つ・属攻・属防・追加効果はそれぞれ1つまで。品が元から属攻・属防・追加効果を持っていれば、その種類は書けない。部位の決まり (2章の「部位」) は拾う品と同じ。
- **隊の別々の人業が同じ極 (一番手など) を付けるのはよい** (ユーザーの決定)。その代わり極が拾えること自体をごく稀にした (1-3)。
- 隊の1人あたりの上限 (1-4: 与ダメ +40% など) は本編でもそのまま効く。
- 巻物の値: 能力値の特性 (kind B) は「B(R) に対する割合」で持ち、書く品のランクで値を出し直す (浅い階の特性でも強い品に書けば伸び、低い品に深い階の数値は乗らない)。割合・固定の値の特性はそのまま。

### 6-3. 費用

- 書き込み = 書く品の買値 (目録の並品) × 格の倍率 (常 0.5 / 稀 1 / 秘 2 / 極 4) × 枠の倍率 (1枠目 1・2枠目 1.5・3枠目 2・4枠目 2.5・5枠目 3)。最低 💰100。
- 書いた後の買値の上がり分より安くはしない (書いて売るだけで儲からない)。
- 写し取る (手元の品)・消すは無料。棚の品から写す時は、その品の買値。

### 6-4. 実装の場所

- 決まりと値: `src/infaffix.js` の「付呪」(`ENCHANT_SLOTS` / `ENCHANT_CAP` / `ENCHANT_TIER_COST` / `pageFromAffix` / `pageValue` / `enchantRoom` / `enchantBlock`)。
- 操作: game.js の「付呪」(`enchantSources` / `extractAffix` / `enchantTargets` / `enchantInfo` / `enchantCost` / `writeAffix` / `eraseAffix`)。数え `G.stats.enchant`。
- 画面: `src/ui/enchant.js` (商会の区分「付呪」)。王の解放のページ `UNLOCKS.enchant` (story.js)、ヘルプ `enchant` (journal.js)、酒場の心得 `t_enchant1`〜`t_enchant3`。
- 検証: `python3 tools/enchant/browser-check.py` (localhost:8000 が必要)。
