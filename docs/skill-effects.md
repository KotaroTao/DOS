# 技の演出

味方の全960技を実際の作用に沿って37系統に割り当てる。看板技の識別子と職業ごとの個性は保ち、材質画像の重なり・向き・濃淡で表す。敵の術・ブレスも同じ画像の描画口へ通す。通常攻撃の描画と戦闘結果・対象・乱数・通信の確定順序は変えない。

## 図形を使わない描画（2026-11-03）

技の主演出・作用点・吸収の流れ・奥義・待機表示には線・円・星・十字・多角形・照準・紋を使わない。`skill-fx.js` と `skill-fx-materials.js` の描画口は画像だけを使う。図形だった弱体や回復の印も、効いた対象への小さな材質の濃淡へ変える。待機時は技名を示す。HP/MP・数値・状態名などの結果表示は維持する。

`art/effects/skill-materials.webp` は光の帯・圧力・氷・水・風・闇・聖光・生命・毒・岩の10材質×18コマ（576×2880）。規則的な輪・星状の放射・花弁ではなく、不規則な濃淡・乱流・摩擦・屈折を焼き込む。制作元は `python3 tools/effects/build-material-textures.py`（numpy/Pillow・固定種）。火柱・火球・爆発には既存の透過炎アトラスも使う。画像を対象人数分取得せず、共用する。

斬撃は専用の `physical-materials.webp`（192×96×18コマ、約119KiB）を使い、明るい摩擦の面と両端が細くなる不規則な輪郭を保つ。

通常は隣接コマを混ぜ、軽量時は1コマ描く。動き低減では固定コマ・固定位置。素材失敗時も、不規則な濃淡を持つ小さな代替画像を使い、図形へ戻さない。色付きの帯は最大6面（約8MB）を保持する。色変換は描画中に行わず、空き時間に準備し、未準備時は明るい原素材を使う。図形の補助粒子は作らない。武器の実物・矢の形・手・腕・人物は描かない。

## 物理の速度と表示時間

`kind: 'phys'` の全424技は、ランクの表示時間から分離する。一撃の移動を65msで終え、85msごとの打撃枠＋60msの余韻にする。単発145ms・2連撃230ms・5連撃485ms・8連撃740ms。高ランクでも一撃を遅くしない。対象人数や命中した回数で尺を変えず、未命中・無効の枠では命中演出を出さない。

| 種別 | 通常の尺 | オート・高速 |
|---|---|---|
| 物理技 | 定義上の打数×85ms＋60ms | 移動65ms・打撃枠85msを維持し、余韻のみオート20ms・高速35ms |
| 術・回復・補助・探索 | ランク1/2/3以上で400/700/1200ms | オート60%、手動高速80%（両方ならオート優先） |

`skillFxDuration` は生成・確認画面・音・行動待ちで共用する。実際に生成した演出の終了まで待ち、全て不発で生成しない場合の追加待機はない。探索の入力は止めない。連撃の数値と追加の命中音は同じ85msの枠へ合わせる。斬撃の連撃は右斜め・左斜め・急角度・横など一撃ごとに方向を変える。ダメージ数値は一撃ごとに切り替え、古い数値との重なりを防ぐ。実戦の最初の描画を表示時計の起点とし、DOM更新や音の準備中に演出を消費しない。画質・動き低減で尺を変えない。

## 自然な音

技・準備・追加命中・着弾・治療の音は `naturalSkillName` 経由。風切り、摩擦、衝突、破砕、水しぶき、炎のはぜ、低い空気の動きを模した非周期の合成音にする。回復は柔らかな水の流れ、蘇生は立ち上がる息、治療は細かな洗い流し、MP回復は低い流れとし、攻撃の衝突・破砕を混ぜない。救命系は立ち上がりと音量も穏やかにする。録音ファイルの追加はない。音階・正弦波の掃引・倍音の和音・ビープを重ねる方式は使わない。BGMとUIの選択音は別の仕組み。

表示する尺と同じ長さのバッファを生成し、ピッチを変える時間伸縮を使わない。短い物理技を長い電子音で引き延ばさない。主音は一手1回、追加命中は短い自然音。音量・ミュート・非表示中の停止は従来どおり。ゲーム用乱数は消費しない。

## 確認と検査

設定「技の演出を試す」または [effects-lab.html](../effects-lab.html) で検索・系統・連続再生・音・軽量・動き低減・6体への作用点を確認する。未習得技の名前を含む注意を表示する。本編の保存・認証・進行・クラウドは呼ばない。[全技の割当表](skill-effects-catalog.csv) は生成元 `tools/effects/build-catalog.mjs` から更新する。

```sh
node tools/effects/build-catalog.mjs --check
node tools/effects/check.mjs
node tools/effects/organic-check.mjs
node tools/balance/effect-scope-check.mjs
python3 tools/effects/materials-browser.py
python3 tools/effects/combo-browser.py
python3 tools/effects/browser-check.py
python3 tools/effects/game-browser.py
python3 tools/effects/combat-readability.py
```

HTTPサーバーは8000番。ブラウザ検査にはPlaywright/Chromiumを使う。全960技の描画、37系統の444比較、図形APIの禁止、素材失敗、低減中の固定、連撃の作用点、物理の尺、自然音105条件の長さ・有限性・発振器禁止を検査する。一括描画は全技×通常/軽量×低減ON/OFF×尺の5/30/65/92/105%で19,200件。CPU通常と4倍遅延を測り、JSONと比較画像を出す。

描画計測はCanvas命令を発行するCPU時間であり、GPU完了時間・実機FPS・音のリアルさを保証しない。見た目は比較画像と実際の再生でも確認する。成果物は `/tmp/dos-material-fx/`・`/tmp/dos-skill-fx-check/`・`/tmp/dos-combat-readability/`。描画の予算は同時32・作用点12、計測の保持は240件。自動軽量化の条件は4ms超が6回連続、復帰は2ms未満が240回連続。

酒場の心得: `t_skill_fx_read`・`t_skill_fx_rank` 更新、`t_skill_fx_organic` 追加。`t_skill_fx_combo` 追加。`t_skill_fx_material`・`t_skill_fx_lite` も維持する。
