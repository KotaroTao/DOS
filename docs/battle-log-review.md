# 戦闘ログの表記見直し

戦闘開始・行動・結果・勝利後・全滅時を通して確認し、対象・原因・結果を短く記す表記に揃えた。技名・敵の表示Lv・数値・持続・残り回数は必要に応じて残す。戦闘計算と乱数の扱いは変更しない。

## 修正した箇所

- 通常攻撃・物理技・連撃・追撃・反撃・攻撃呪文・攻撃道具：空白を減らし「敵に120ダメージ」に統一。
- 技・呪文の使用：「○○は△△を唱えた！」を「○○の△△！」へ統一。再詠唱は「（重詠）」を添える。
- 会心と付随効果：「120ダメージ（会心・火弱点×1.5・物理軽減25%）」のように括弧へまとめる。
- 属性相性：「火属性の弱点でダメージ増加（×1.5）」を「火弱点×1.5」、「火属性の相性でダメージ減少（×0.5）」を「火耐性×0.5」へ短縮。
- 魔法弱点：「魔法の弱点！」を「魔法弱点×倍率」へ変更。
- 物理・魔法の抵抗：「物理抵抗50！」を「物理軽減50%」へ変更。貫通や魔導の深淵で軽減を無視した分を反映し、完全に無視した軽減は表示しない。
- 金属の体：固定1ダメージには「金属」を添え、適用されない属性弱点は表示しない。
- 魔法壁・魔障壁・障壁：「ダメージを和らげた」「呪文を弱めた」を「半減」へ統一し、残り回数を併記。
- 大結界・加護の祈り・封の結界・金剛の守り：「半減」と「無傷」を区別。
- かばう・盾役の受け止め：長い演出文を「○○が△△をかばう」「○○が渾身の一撃を受け止める」へ短縮。
- 能力強化・弱体：「攻撃が上がった／下がった」を「攻撃+1段／−1段」へ短縮。段と重複していた倍率を省く。
- 支援呪文・支援道具：「力がみなぎる」などの説明を、対象・能力・段・持続ターンの表記へ変更。
- 引き付け・かばう構え・反撃の構え・溜め・継続回復・呪文／ブレス対策：効果の種類・倍率や軽減率・回数・持続を短く併記。
- 戦闘中持続する効果：内部の長いターン数を「戦闘中」と表記。
- 属性耐性低下：「守りに綻びが生じた」を「火弱体×倍率、3ターン」の形へ変更。
- 毒・麻痺・眠り・封印・魅了・混乱・石化・怯み：付与を「○○に毒」などへ統一。魅了には「仲間を攻撃」を添える。
- 異常の抵抗・即死：成功・抵抗・無効を「即死」「即死を防いだ」「即死無効」などに書き分ける。
- 行動不能：「痺れて動けない」などを「麻痺で行動不可」へ統一。眠り・石化・怯み・五寸釘・混乱・魅了も同形式にする。
- 混乱・魅了による行動：攻撃相手を残して短縮。自傷にはダメージ量を併記。
- 毒・再生・リジェネ：毒は「毒50ダメージ」、再生とリジェネは「HP+50」の形へ統一。
- 異常回復・浄化・強化解除・弱体解除：「穢れが祓われた」などを「状態異常解除」「強化解除」「弱体解除」へ変更。
- HP・MP回復：「HPが50回復した」を「HP+50」へ統一。全体回復・刃の光・聖なる残光は対象ごとの回復量を表示。
- HP・MP吸収・魔力循環・魂喰い：資源名と回復量を「HP吸収：HP+50」「魔力循環：MP+10」の形で表示。
- 蘇生・不屈・勇者の意地・墓碑・不死鳥・命の分与・復活の祈り・聖座の奇跡・濁った魂：演出文を短縮し、蘇生とHP1で耐える効果を区別。個別蘇生には復帰時のHPを残す。
- 開幕のパッシブ：聖戦の雄たけび・罪の刻印・狩りの采配・死の宣告・五寸釘・浄化の光・竜の息吹・死者の軍勢の長い演出文を効果中心へ短縮。
- 時間跳躍・たぎる血潮・激昂・魂喰らい：再行動・現在の段・物理の増加率・対象変更によるリセット・上昇する能力を短く明記。
- 敵の大技：予兆を「強打の構え」「全体強打の構え」「強ブレスの構え」「大呪文の構え」へ変更。発動時には「（溜め）」、中断時には「溜め解除」を表示。
- 敵の呪文・ブレス・召喚・浄め・禍言：行動名と結果を中心に短縮。召喚や解除の失敗も明記。
- 逃走：手段ごとに異なっていた成功文を「逃走成功」へ統一。「逃走失敗」「逃走不可（退路封鎖）」「敵が全員逃走」を区別。
- 装備の持ち替え・道具使用：「旧装備→新装備に持ち替え」「○○を使用」へ短縮。他人の袋から使う場合と、外れた装備の行き先は残す。
- 使用できない行動：「MP不足」「対象なし」「道具なし」「射程外」に整理。射程の種類は残す。
- 盗み・敵の盗み・魂奪い・レベルドレイン：対象・金額・資源・低下後のLvを短く表示。金額の「G」を「💰」へ統一。
- 遭遇・先制・奇襲・待ち伏せ：敵名・表示Lv・体数・先に行動する側・確定先制の原因を残して短縮。
- 迷宮の掟による開幕効果：掟名とHP／MPの消費合計・能力低下・状態異常・障壁回数などを短く併記。
- 魔封じ・格上の迷宮・敵の蘇生・観客の歓声：制限・推奨Lv・不利になる判定・蘇生回数・攻撃上昇の開始時点を残して短縮。
- 観客の注文：注文・達成／未達成・報酬倍率を中心に短縮。
- 出来事の加護・発破・主の弱み・紅玉：原因と効果を短く表記。紅玉は実際のHP消費量を表示。
- 勝利・敵の逃走・強敵討伐・魂の入手：戦果と結果を短縮。逃走した敵の戦果がないことは残す。
- レベル上昇・技習得：通常戦と再戦の両方を「Lv10→11」「○○が△△習得」へ統一。
- 勝利後の回復・浄化・慈悲の祈り：原因と結果を短縮。HP／MP回復は隊の合計量、蘇生は復帰時のHPを表示。
- 全滅・断念・救済・戦利品喪失：結果を短縮し、救済手段・赤い魂の消費・HP1での帰還・失うもの／残るものを明記。
- 酒場の心得：`t_elem` に短い属性表記の読み方を反映し、`t_battle_log` にHP／MPの増減と各結果の読み方を追加。

## 確認

- `node tools/balance/battle-logs.mjs`：6属性・通常攻撃／呪文／道具／敵の攻撃／敵のブレス／敵の呪文・竜の息吹で、弱点／耐性／等倍を確認。会心・貫通後の軽減・無効・金属・異常・全体回復・強化も確認。
- `node tools/balance/check.mjs`：全958技と全311出来事・952選択肢の既存チェック。
- `node tools/balance/run.mjs --sim`：7,400件の模擬戦。
- 旧版との比較：全958技×乱数2種の1,916条件で、戦闘状態・行動結果・乱数消費の一致を確認。
- JavaScriptの構文確認と `git diff --check`。
