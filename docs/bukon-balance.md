# 武魂の仕様（2026-10-29）

有効138種。削除IDは互換用として保持し、抽選・装着不可。旧X14は魔法会心率、旧X32は封印付与へ交換。部位に合わない旧武魂は同じ記録の商会へ返す。魂の記憶は書き換えない。

## 合成

同種の異なるLvを使用できる。価値は3^(Lv−1)、目標より低いLvから必要分だけ消費。装着中・保護中は消費しない。成功率100%。Lv1→2は100金貨。加算系は以後1.1倍（支払時切上げ）、他は2倍。一括合成は総額を先に確認し、素材・金貨をまとめて更新。不足時は変更しない。

## 上限・重複

加算系のみLv上限なし、特殊3種はレベルなし、他はLv10。特殊は人業の全装備から同種の最高Lvのみ。種族特効と特殊の弱点ダメージは与ダメージ枠の上限対象外で加算。通常の条件つき与ダメージ・回復量は装備由来合計+100%、軽減80%、MP軽減は他の同系パッシブと合計70%。条件を満たしてから集計する。最終会心率80%、回避力80%、状態異常耐性95%、状態異常成功率95%。恒常軽減の積は最大90%。

属性攻撃は基準100%へ加算（Lv10は+200%）。属性付与はしない。武魂の属性防御は直接軽減率。旧装備の耐性力による実軽減と足し同属性80%まで。全属性耐性もこの枠に加算。

復活は毎回Lv×5%で判定、合計50%まで、最大HP10%（最低1）で戻る。既存装備の1戦闘1回の自動蘇生は別に維持。物理被弾時VIT反撃（胴・LR）はLv×5倍の物理反撃。魔法被弾時VIT反撃とは別種で、魔法側の倍率は維持。耐性低下は同種累積なし・最高50ポイント、最低0、金属・固有無効は対象外。追加行動は他の効果と合わせて1ターン1回。分配回復の再分配なし。金貨奪取は敵1体成功1回。宝箱・魂経験値・逃走率低下は隊で最高値のみ。

## 抽選

先に格を白80%・緑12.5%・青5%・橙2%・赤0.5%で選び、対応部位の種類から等確率で選ぶ。格の確率は装備のレア度に依存しない。部位にその格の候補がない場合は格内の全種類から選び、装備に宿さず商会へ直接保管する。ドロップLvの成長は従来どおり装備の格と進行で決まる。
