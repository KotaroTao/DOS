# タスク一覧 — 計画書と採用した案を、1 PR ずつの作業に

> 2026-10-04 作成。もとにしたのは `docs/refactor-plan.md` (計画書と追補) と、ユーザーが採用した2つの案:
> **(1) 機能解放は1章に1つ**、**(2) 第6層からの強敵を「名のある強敵」に格上げ**。
> 1タスク = 1 PR (大きいものは「分け方」に従って分割)。着手したら行頭に `[着手]`、マージしたら `[済 #PR]` を付ける。
> 範囲は行番号でなく関数名・見出しで書く (計画書の追補 9)。

## 決まったこと (2026-10-04、ユーザー)
- **開発の速さを最優先にする。** まだリリース前で、開発とテストプレイはユーザー1人。CI などの安全網 (S) は公開の前まで後回しにする。
- 名のある強敵の**首級は「固有ドロップ廃止」の例外**にする。
- 名のある強敵は**最初から名前で表示**する (不確定名にしない)。
- **game.js の分割中は、ほかのセッションで game.js を触る作業を止める。**

## 並べ方の考え
- **まず、すぐ遊べる面白さ。** 採用した2案のうち、第1〜5層で今すぐ試せる部分を先に出す (解放の付け替え・名のある強敵の仕組み)。
- **安全網 (S) は公開の前に回す。** 開発の速さを優先する (上の決まったこと)。代わりに各 PR で `node --check` と DOM スタブでの読み込みを手で回す。
- **尺度の統一は、奈落と第6層より前に。** どちらも旧来の n の生成器に頼っているため。
- **ファイルの分割は最後。** 機能の作業と同時に game.js を割ると衝突する。分割中は、ほかのセッションで game.js を触らない。

## S. 安全網 (公開の前まで後回し)
> ユーザーの決定で後回し。公開の前、またはテストプレイをほかの人に頼む前に入れる。

### S1 公開前の速い検査 (CI)
- **目的**: 構文エラー・読み込み時の検証エラー・`sw.js` の書き漏れがあれば公開しない。
- **内容**: `tools/check/fast.mjs` を作り、`.github/workflows/pages.yml` の公開の前に回す。
  - 全 `src/**/*.js` の `node --check`。
  - DOM スタブで `src/game.js` を読み込む (bestiary・world・jobkit・catalog の読み込み時の検証が走る)。
  - `index.html` から import をたどった全ファイルが `sw.js` の `ASSETS` にあるか (計画書の追補 4)。足りなければ失敗にする。自動生成への切り替えは R2 の前に別 PR で。
  - `sw.js` の `CACHE` が main より上がっているか (PR のときだけ)。
- **完了の条件**: わざと構文エラーを入れた PR で CI が赤くなり、公開されない。
- **依存**: なし。

### S2 通しテストとバランス検査 (重い検査・別の流れ)
- **内容**: Playwright で タイトル → はじめから → 出撃 → 戦闘 → 帰還 を流す (`tools/check/flow.mjs`)。#489 の検査 (全迷宮の1階・最下階で、1戦の✦ ÷ `refSoul` と被ダメ) を `tools/check/balance.mjs` に置き、許容幅を決める (計画書の追補 2・3)。
- **完了の条件**: main への push で走り、結果が Actions に残る。公開は止めない。
- **依存**: S1。

### S3 セーブの版数と変換 (最小限)
- **内容**: 保存データに `ver` を持たせ、読み込み時に変換を順に当てる仕組み (数十行)。以後の仕様変更はセーブキーを変えずに変換を1つ足す (計画書の追補 6)。

## U. 機能解放は1章に1つ (採用した案)

### [着手] U1 機能解放を「章」で決める + 親しさの数え方
- **目的**: 報告の総数 (`FEATURE_AT` = 2・3・4・5・7・11・40・50) で決める方式をやめる。黒水の取水口 (w04) を後回しにすると、解放と親しさが1章ずつずれる不具合も直す (計画書の追補 #487-1)。
- **内容**:
  - `FEATURE_AT` を、章とその章の中での報告の何本目かで決める表に置き換える (`FEATURES`)。`at: { chapter, report }`、`report` は数字か `"finale"`。
    | 章 | 解放 | 条件 |
    |---|---|---|
    | 第一章 (入門) | 魂の融合 / サブ魂1枠 / 酒場の噂 / 控えの結社1席 | 章内の2・3・4本目 / 結び |
    | 第二章 | 結社2席 | 章内の2本目 (今の報告7と同じ時期) |
    | 第三章 | 結社3席 | 章内の2本目 (今の報告11と同じ時期) |
    | 第四章 | サブ魂2枠 | 結び |
    | 第五章 | 奈落 | 結び (A1 と組) |
    | 第六章〜 | U2 で決める新しい仕組み | 原則は結び |
  - 第一章だけは入門なので4つ。第二章からは1章に1つにする。
  - `UNLOCKS` (story.js) と `TUTS.at` (tutorial.js) を、数字でなく機能のキーで引くようにする (`unlockSceneFor`)。
  - `CONTENT_LIMIT >= 50` による奈落の封をやめる。奈落は第五章の結びが条件になるので、第五章ができるまで開かない。
  - 親しさ: `段 = min(2, 報告数) + 結びを報告した章の数` (上限5)。`ctxNow()` に `c.chapters` (結びを迎えた章の数) を足し、第四章からの台詞を `when: (c) => c.chapters >= 3` のように書けるようにする (計画書の追補 #487-1・2)。
  - CLAUDE.md の `FEATURE_AT`・`BOND_REPORTED` の記述を直す。
- **完了の条件**: w01→w02→w03→w05→w06…と回っても、w04 を最初に回っても、各章の結びで同じ解放と親しさになる (DOM スタブで報告の順を何通りか流して確かめる)。
- **依存**: なし。

## B. 尺度の統一

### [済] B1 尺度の統一の残り (n を tune に畳み込む)
- **やったこと (2026-10-04)**: 台帳の迷宮に `power` (強さの素。階ごとの値) を書き、敵の強さ = power × lvPow(推奨Lv) × tune にした (旧来の値を誤差2%以内で写した)。戦果の写し・逃走/回避の基準 AGI (`partyAgi`)・罠の解除/ダメージ (`lockPow`) も推奨Lv から。`lvStrength` を廃止 (奈落の `lvStrengthHere` も A1 で廃止)。
- **残り**: なし (`n`/`nTo` の残りは A1 で外した)。
- **目的**: 難しさの物差しを推奨Lv の1本にする。#489 で報酬・落とし物・強化費用は推奨Lv から決まるようになったが、敵の強さだけが旧来の n の物差しに残っている。
- **内容**: 計画書の追補 #488-1 のとおり。「旧来の n の強さ ÷ lvPow(n の物差しの Lv)」を迷宮ごとの `tune` に畳み込み、地図の迷宮から `generateDungeon(n)`・`baselineLv`・`LV_EST`・`naturalLevelRaw` を外す。残す尺度の役割を決める (推奨Lv = 難しさ / 隠しLv・R = 推奨Lv から導く / layer = 景色と顔ぶれ / 魔物のランク = 顔ぶれの中の相対 / `cfg.rank` = 消す)。
- **完了の条件**: #489 の検査 (Playwright で全迷宮の1階・最下階の1戦の✦と被ダメを測る) を手で回し、値が変更前と同じ (許容幅の中)。
- **依存**: なし。

## R. 整理 (計画書の第2・4・5段)

## C. 層の仕上げ手順に足すもの (第6層からの各層で)
### C1 層の仕上げ手順の更新 (CLAUDE.md の Per-layer polish checklist)
今の手順に、次の確認項目を足す。
- **名のある強敵2体** (E2 の表から)。首級・懸賞・縄張りを書く。
- **逸品の SR が十分か**: その層で落ちうる SR が30種以上あるか確かめる (逸品を作らないと、第8〜12層で3〜13種まで減る)。
- **逸品は掟を裏返す効果を**: SR・LR に、その層の掟や顔ぶれへの答えになる効果を最低3点持たせる (例: 奇襲を先制に変える、逃げられない獄で倒すたびに HP を吸う)。
- **戦術の道具**: 3層ごとに、使いどころを考える道具を3〜4点足す (主の特技を1回封じる札、行動順を入れ替える香など)。回復量を増やしただけの上位品にはしない。
- **出番のない魔物を作らない**: 層の顔ぶれ20種がすべて、どこかの迷宮の帯に入っているか確かめる。今は第2層の 鋼鱗の大鯉・深海魚人、第3層の 墓守ゴーレム・墓所の巨人 が漏れている。この4体は、出来事やまれな階の「迷い込んだ魔物」として使う。
