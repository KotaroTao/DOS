### 留守居の修練 — 廃止 (2026-10-13、操霊師の見識へ置き換え。以下は旧仕様の記録)
- 控えの人業を「留守居の席」に就けると、隊が戦闘に勝つたび、そのメイン魂にも隊のメイン魂が得る経験値の10% (`RUSUI_EXP_RATE`) が入る。魂の Lv で減る (隊と同じ `soulLvMul`)。無限迷宮での戦闘では入らない。
- 席は第六章の結びで1つ、第七章の結び (`rusui2`) で2つ、第十章の結び (`rusui3`) で3つ (2026-10-11 ユーザーの指示「最初は1席、先の章で徐々に増やす」)。
- **面白さ**: 魂の安定度で休ませた人業と入れ替えて潜れるよう、控えが遅れない。
- **作り**: game.js `distributeBattleSoulExp`。くわしくは CLAUDE.md の「留守居の修練」。
- 以前の **遠征** (控えの人業を踏破済みの迷宮へ1〜4時間送り出す) は「手順が多くて使わない」(ユーザー) ので取りやめた。

### 魂の共鳴 (第七章 / 毒沼) — 取りやめ (2026-10-11 ユーザーの指示: パーティ編成の自由度を奪う)
- 隊に特定の職の組み合わせがそろうと、隊全体に小さな効果が付く (例: 侍+忍び = 先制 +10% / 僧侶+聖騎士 = 回復量 +10% / 魔導士+賢者+司教 = 呪文の消費MP −10%)。20〜30組。
- 発見式: 初めてそろえた時に名前が明かされ、図鑑に「共鳴」の区分ができる (伏せた組み合わせを探す楽しみ)。
- **面白さ**: 隊を組み替える動機。36職の組み合わせに意味が出る。
- **作り**: データ表 `RESONANCES = [{jobs, fx}]` を jobkit の fx 語彙で書き、`_recalcBuffs` に足す。規模は中。

### 宿敵の再戦 (第九章 / 闘技場跡) — 実装済み
- 実装: 出撃画面の一覧の最後の「闘技場跡 ― 宿敵の再戦」から挑む (町の施設にはしなかった)。記憶との手合わせなので、終われば隊の HP・MP・状態は挑む前に戻る (負けても砕けない)。入る時に迷宮と同じ魂の安定度を使う。勝てば ✦Soul・金貨 (挑む Lv の普通の1戦 × 強敵4・主6)。くわしくは CLAUDE.md の「宿敵の再戦」。
- 一度倒した名のある強敵と迷宮の主に、町の「闘技場跡」から挑み直せる。相手は今の推奨Lv に合わせて強くなり、特色が1つ増える (例: 首切り鬼が「神速」を得る)。
- 勝つと、その強敵の首級を ＋1 に鍛えられる (首級の ＋1〜＋5 の段 = `item.forge`。品質の鍛え直しとは別の仕組み)。主は記憶の断片 (物語の小話) を落とす。
- **面白さ**: 名のある強敵 (E1) の続き。好きな相手と何度でも、強くなって戦える。
- **作り**: `startBattle` を迷宮の外から呼ぶ入口 + 強化表。規模は中。

### 付呪 (第十一章 / 魔導書庫)
- 装備1つに「属性攻撃 Lv1」「属性防御 Lv1」「状態異常耐性 +15%」のどれか1つを書き足す。費用は魂の残火 + 金貨。書き足せるのは1品に1つ (書き直しは可)。
- **面白さ**: 気に入った装備を、次の層の属性に合わせて使い続けられる (層ごとに属性の相性が変わる作りに答える)。
- **作り**: 品の実体に `ench` を持たせ、`recalc` で足す (`forge` と同じく `reflattenItemStats` の後に掛け直す)。規模は小〜中。

### 装備の品質と鍛え直し (第五章) — 実装済み (2026-10 ユーザーの指示: 金貨の使い道)
- 装備品 (コモン〜LR。道具・収集品は除く) は手に入れるたびに品質 0〜100 を引き、性能が目録の値の ±20% で変わる (50 = 並品)。品質は最初から付く。
- 商会の「鍛え直し」で金貨 (その品の買値) を払って品質を引き直す。結果を見て、新しい品質か元のままかを選べる。金貨は引くたびにかかる。
- 売値・鑑定料は品の種類で決まり品質に依らない。商会の棚の品は並品 (売った品も並品として戻る)。
- **面白さ**: 余る金貨の使い道。同じ品でも当たりを狙える。品質91以上は約10回に1回なので、深い品・LR ほど金貨を食う。
- **作り**: items.js「品質」・game.js `reforge*`・`src/ui/reforge.js`。くわしくは CLAUDE.md の「装備の品質と鍛え直し」。
- 以前の案 (第十三章の工房で ＋1〜＋5 に鍛える) は取りやめ。＋N の段 (`item.forge`) は第九章「宿敵の再戦」の首級に残す。第十三章の枠は空き。

### 魂の転生 (第十四章 / 深淵の聖堂)
- ランク5・Lv上限に届いた魂を、Lv1 に戻して「転生」させる。転生した魂は能力に恒久の上乗せ (+5%/回、上限5回) と、名前に星が付く。
- **面白さ**: 極めた後の長い目標。育成の楽しみを何周もできる。
- **作り**: 魂に `rebirth` の回数を持たせ、`jobStatsOf` に掛ける。規模は小。

### 異変を選ぶ (第十五章 / 凍てつく王墓)
- 出撃シートの「迷宮の異変」を、抽選された1つではなく、候補3つから選べるようにする (または「異変なし」)。危険な異変ほど見返りが大きい今の作りはそのまま。
- **面白さ**: 隊の得手に合わせて危険を選べる。高難度の自主的な挑戦。
- **作り**: `mutatorStrip` の抽選を3つにし、選んだものを確定する。規模は小。

### 誓約 (第十六章 / 冥府の門)
- 潜る前に「縛り」を最大3つ選ぶ (道具禁止 = 既存の無頼の誓 / 回復の呪文禁止 / 逃走禁止 / 隊を4人に / 敵の HP +50% など)。縛り1つごとに、その潜入の✦Soul・金貨・落とし物の格が上がる。
- **面白さ**: 終盤の繰り返しに変化を付ける (いわゆる「ヒート」)。慣れた迷宮が別物になる。
- **作り**: 異変と同じ `activeModifierDefs` の仕組みに乗せる。規模は中。

### 奈落の底を開く (第十八章 / 終焉の玄室) — 取りやめ (無限迷宮に深さの上限が無いため。`FEATURES.abyssDeep` は削除した)
