- **新しい通貨は作らない。** 金貨・✦Soul・赤い魂・魂の残火・収集品だけで回す (計画書の弱み「仕組みと通貨が多く入口が重い」への配慮)。

## 新しい仕組みの案 (それぞれ 3〜5行)

### 遠征 (第六章 / 氷結回廊) — 実装済み
- 控えの人業 (隊に出していない・砕けていない・メイン魂を宿した者) を、踏破済みの迷宮 (依頼の迷宮も可・奈落は不可) へひとりで送り出す。同時に3人まで、長さは1時間 / 2時間 / 4時間。実プレイ時間 (`G.stats.playMs`) で進み、出発時に魂の安定度を迷宮の入場と同じだけ使う (セラは使わない)。
- 戻ると ✦Soul・金貨を持ち帰り、メイン魂に ✦ の 1/3 の経験値が入る。まれに収集品 (1時間ごと25%) と職業の魂 (1時間ごと5%)。量 = その迷宮の推奨Lv の中ほどの `refSoul`/`refGold` × 1時間7.1戦 (隊の57戦の1/8) × 強さ。3人を同じ深さへ送っても隊の稼ぎの約29%。
- 強さ: 推奨Lv 以上 = 1.0 (✦ には迷宮と同じ Lv差の減り)、推奨Lv −1〜−5 は1Lvごとに −4%、−5 より下は「途中で引き返した」(時間の半分で戻り、戦果は3割)。いつでも呼び戻せる (経った時間の分だけ)。
- 遠征中の人業は隊に入れられず、魂・装備も付け替えられない。帰ってきた遠征は、街で手が空いた時に「遠征から帰ってきた」の1枚にまとめて知らせる。
- **面白さ**: 控えの人業と控えの魂に出番ができる。町に戻るたびに「帰ってきた」小さな楽しみが増える。
- **作り**: `src/expedition.js` (数) / game.js の「遠征」(状態 `G.expedition = [{doll, dungeon, since, dur, ends, …}]`・付与) / `src/ui/expedition.js` (画面)。くわしくは CLAUDE.md の「遠征」。

### 魂の共鳴 (第七章 / 毒沼) — 実装済み
- 隊に特定の職の組み合わせがそろうと、隊全体に小さな効果が付く (例: 侍+忍び = 先制 +10% / 僧侶+聖騎士 = 回復量 +10% / 魔導士+賢者+司教 = 呪文の消費MP −10%)。20〜30組。
- 発見式: 初めてそろえた時に名前が明かされ、図鑑に「共鳴」の区分ができる (伏せた組み合わせを探す楽しみ)。
- **面白さ**: 隊を組み替える動機。36職の組み合わせに意味が出る。
- **作り**: データ表 `RESONANCES = [{jobs, fx}]` を jobkit の fx 語彙で書き、`_recalcBuffs` に足す。規模は中。

### 宿敵の再戦 (第九章 / 闘技場跡)
- 一度倒した名のある強敵と迷宮の主に、町の「闘技場跡」から挑み直せる。相手は今の推奨Lv に合わせて強くなり、特色が1つ増える (例: 首切り鬼が「神速」を得る)。
- 勝つと、その強敵の首級を ＋1 に鍛えられる (首級の ＋1〜＋5。鍛え直しの仕組みを先取り)。主は記憶の断片 (物語の小話) を落とす。
- **面白さ**: 名のある強敵 (E1) の続き。好きな相手と何度でも、強くなって戦える。
- **作り**: `startBattle` を迷宮の外から呼ぶ入口 + 強化表。規模は中。

### 付呪 (第十一章 / 魔導書庫)
- 装備1つに「属性攻撃 Lv1」「属性防御 Lv1」「状態異常耐性 +15%」のどれか1つを書き足す。費用は魂の残火 + 金貨。書き足せるのは1品に1つ (書き直しは可)。
- **面白さ**: 気に入った装備を、次の層の属性に合わせて使い続けられる (層ごとに属性の相性が変わる作りに答える)。
- **作り**: 品の実体に `ench` を持たせ、`recalc` で足す (`forge` と同じく `reflattenItemStats` の後に掛け直す)。規模は小〜中。

### 鍛え直しの工房 (第十三章 / 溶鉄炉)
- 出来事にしか無かった「鍛え直し」(`item.forge`) を、町の工房でできるようにする。＋1〜＋5、段が上がるほど金貨と、同じ品か同じ部位の収集品を求める。
- **面白さ**: 同じ品を2つ目以降に拾ったときと、奉納済みの収集品に使い道ができる。
- **作り**: 既存の `applyForge` をそのまま使い、施設の画面を足すだけ。規模は小。

### 魂の転生 (第十四章 / 深淵の聖堂)
- ランク5・Lv上限に届いた魂を、Lv1 に戻して「転生」させる。転生した魂は能力に恒久の上乗せ (+5%/回、上限5回) と、名前に星が付く。
- **面白さ**: 極めた後の長い目標。育成の楽しみを何周もできる。
- **作り**: 魂に `rebirth` の回数を持たせ、`jobStatsOf` に掛ける。規模は小。

### 異変を選ぶ (第十五章 / 凍てつく王墓)
- 出撃シートの「迷宮の異変」を、抽選された1つではなく、候補3つから選べるようにする (または「異変なし」)。危険な異変ほど見返りが大きい今の作りはそのまま。
- **面白さ**: 隊の得手に合わせて危険を選べる。高難度の自主的な挑戦。
- **作り**: `mutatorStrip` の抽選を3つにし、選んだものを確定する。規模は小。

### 誓約 (第十六章 / 冥府の門)
- 潜る前に「縛り」を最大3つ選ぶ (道具禁止 = 既存の無頼の誓 / 回復の呪文禁止 / 逃走禁止 / 隊を4人に / 敵の HP +50% など)。縛り1つごとに、その潜入の✦Soul・金貨・落とし物の格が上がる。
- **面白さ**: 終盤の繰り返しに変化を付ける (いわゆる「ヒート」)。慣れた迷宮が別物になる。
- **作り**: 異変と同じ `activeModifierDefs` の仕組みに乗せる。規模は中。

### 奈落の底を開く (第十八章 / 終焉の玄室)
- 奈落 (第五章) の深さの上限を外し、第20層の先も深くなり続ける。最深記録が勲章になる。物語の結びの後の、終わりの無い遊び。
- **作り**: A1 で作る奈落の上限を外すだけ。規模は小。
