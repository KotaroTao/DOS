# 職業の共通バランス調整

燕返しだけを弱めても、物理・呪文の成長差と耐性の処理が残るため、共通式から調整する。36職の役割を同じ火力へそろえることは目的にしない。

## 調査した原因と変更

- LUK会心加算は旧式 `(LUK−8)×0.005` ではLUK208で100%に達する。新式は `0.25×(1−exp(−max(0,LUK−8)/50))`。通常の合計会心率は85%まで。明示的な確定会心・眠り等の条件は維持する。
- 貫通が少しでも付くと物理抵抗値100未満を全て無視していた。指定の貫通割合だけ耐性の軽減を無視し、会心は軽減の半分を無視する。両方ある場合は大きい割合を使う。物理無効と金属の特殊処理は維持する。例: 物理抵抗値75への100ダメージは通常25、25%貫通44、会心の耐性処理63 (会心倍率を掛ける前)。
- 味方から敵への回避判定は敵AGIの絶対値だけで上限40%へ達し、攻撃側の素早さを無視していた。敵味方とも `clamp(0.2+0.2×log2(対象の実効AGI/攻撃側の実効AGI),0,0.4)` に統一。敵のAGIは既存の逃走用 `fleeK` で規模を合わせる。技の命中補正は維持する。
- 動体視力 (`dynamicVision`、2026-10): 味方→敵の物理で、敵の回避 (AGI差 + 回避持ちの15%) を Lv1/2/3 = 30/50/70% 打ち消す。素の外れ6%は残すので、これだけでは命中94%を超えない。重ねがけ不可 (メイン魂・サブ魂で一番高い Lv)、金属の魔物の回避には効かない。習得: 狩人・暗殺者 Lv10/40/100、戦士・武僧・聖戦士 Lv20/60/130、修羅・勇者・竜騎士 Lv30/80/160。騎士系は覚えない。試算 (隊の平均AGIの敵): 戦士 Lv19 61% → Lv20 71%、回避持ちの敵 46% → 60%。
- 強敵の回避の上限 (2026-10): 主・強敵・ミミック・出来事の強敵は素早さが雑魚の中央値の1.3〜2.0倍あり、隊の平均AGIの者の命中が54〜67%に落ちていた (第1層・俊敏・神速ほど低い)。味方の物理をかわす計算でだけ、換算後の素早さを推奨Lvの隊のAGI × 1.2 までに抑える (`STRONG_EVADE_CAP`)。手番・逃走は元の速さのまま。試算: 平均AGIの者の命中は強敵に約69%、雑魚に74% (変わらず)。テスト記録は金属の魔物の戦いを精鋭等から分け (`m`)、職ごとの命中も記録する。
- 物理技はATKへ威力倍率が掛かる一方、攻撃呪文は上位でも能力値の係数が0.5で、高Lvほど伸びの差が拡大した。攻撃呪文の基礎威力を `power+stat×(0.25+min(140,power)/分母)` に変更。分母は全体60・その他40。信仰の術は既存のINT/PIE選択に従う。初期の単体威力10は係数0.5を維持する。重力の割合ダメージは別処理。
- 上位回復は `power+PIE×(0.5+max(0,min(120,power)−14)/160)`。初期の威力14は係数0.5を維持する。
- 実際の揺らぎは上下非対称で平均が基礎値より約10%高い。自動戦術の見積もりへ平均を反映し、会心・貫通・見切り・回避も同期。攻撃と同時の隊回復は専用の実処理と同じPIE係数0.3を使う。

## 魂の格 (消費MPと威力、2026-10)

テスト記録 (w10・隊Lv40〜44) では19戦でMP消費446・回復266と6割を戦闘中に取り戻し、最下階でもMP67%が残っていた。消費MPは技ごとの固定値なのに、最大MPは魂Lv・レア度・融合数で伸びるため、術者・高レア職ほど上位の技を何十回も撃てた (Lv40 大魔導 深淵の波動26回、Lv100 59回。物理職は1〜3回)。さらにMP吸収が与ダメ比例で、Lv40 冥刃 (消費10) で31、Lv200 闇刃 (消費3) で78を吸い、撃つほどMPが増えた。

- 消費MP = 技のMP + メイン魂そのもののMP × 格の割合 (技のMP 〜6:2% / 〜13:4% / 〜24:6% / 25〜:8%)。装備・サブ魂・結社で足したMPは含めないので、底上げしたMPはそのまま撃てる回数になる。
- 威力 × (1 + 0.8 × (1 − 技のMP ÷ 魂の格込みの消費))。高Lvでは撃てる回数が「1 ÷ 割合」に落ち着くので、威力も×1.8へ落ち着く形にした (上限なしだと消費の倍率に合わせて術者だけ伸び続ける)。
- MP吸収はどの技もその技の消費MPの1.1倍まで (`MP_DRAIN_CAP`、技ごとの `mpDrainCap` で上書き可。2026-10 まで魔力強奪だけが1.1倍で、ほかは消費MPまで)。魔力循環は与ダメの10/15/20%、1回で最大MPの2/3/4%まで。
- MP回復のパッシブ (2026-10 下方修正、ユーザーの指示): 敵を倒した時・攻撃を受けた時・技の後・戦闘開始時・階の移動は最大MPの1〜2.5%前後へ (闘気循環 2/4/6%・苦痛の糧と門守の誓約は確率込みで4/6%は据え置き)。戦闘勝利後のMP回復は魂1つにつき最大MPの4%まで (`VICTORY_MP_PER`、5%から下げた)。禊の加護はブレス軽減だけになった (勝利後の隊のMP回復は祈りの余韻と重なっていた)。
- 攻撃の技 (物理技・攻撃呪文) は最低の格も4% (2026-10 追補)。2%のままだと、Lv1の強撃やLv20のファイアストームのような安い低位の技が、Lv100で17職・Lv200で12職でMP効率の最良の技として残っていた。4%で7職・2職に減り、最強の技とMP効率の最良の技がほぼ同じになる (効率差の中央値 1.18→1.01、1.08→1.00)。回復・MP譲渡は2%のまま。「どの技も同じ割合で重く・強くする」(消費 = 技のMP × 倍率) も試したが、低位の技の得はむしろ増えた (Lv200で24職) ので採らなかった。全体技が単体より得な職 (Lv200で15職) は、技ごとの消費・威力の見直しで扱う。

満タンで上位の単体技を撃てる回数 (裸・魂ランク2の試算、変更前→後): Lv40 戦士 1→1・魔導士 10→7・大魔導 26→12 / Lv100 魔導士 14→7・大魔導 59→17 / Lv200 戦士 2→2・魔導士 12→6・大魔導 49→10。

同条件の模擬戦 (Lv40/100/200 × 36職 × 5作戦 × 4敵 × 2乱数、4,320戦) の前後: 勝利率は ±10ポイント以内 (Lv100 魔法耐性 73→82%、Lv40 物理耐性 86→83%)、1戦の本人のMP消費は術職で Lv100 通常 16→26・Lv200 通常 16→35、物理職で 13→18・11→15。1戦だけの模擬なので、連戦でMPが尽きる度合いはテスト記録で確かめる。

## 回復・治療の作り直し (2026-10)

レジェンドの回復役はPIEが大きく、ヒール (消費MP2) で参考HPの137%を回復できた。全体回復はMP1あたり単体の4〜6倍回復し、テスト記録 (w10) では地下1〜9階のどの階にもHP100%で着いていた。物理職は最大MPが小さく、術の回復をほとんど撃てない。

- 標準の技 (ヒール〜ピュリファイオール) を、決めた消費MP・習得Lvの幅で各職に配る。ヒールは対象の最大HPの50%まで、ハイヒールはヒールの2.5倍、フルヒール系は全快。ヒールオールはヒールの4倍の消費なので、全員を回復しても効率は1.5倍に収まる。
- 物理職の回復は量の物差しを変える。体の手当て = 使い手の最大HPの割合、刃の癒し = 与えたダメージの割合。どちらもPIEに依らないので、魔法職がサブ魂で借りても自分の術より弱い。物理職が借りても、低位の刃の癒しは1人あたり最大HPの10%で止まる。
- 例 (Lv40・装備なし): 陣中の手当て (最大HPの20%・対象の35%まで・MP4〜) は騎士で参考HPの26%、守護騎士で36%。僧侶が借りると15%、魔導士では11%。
- 残る固有の回復は、旧 power の量をヒールの倍率に直し、級の標準の消費 × 付加効果の上乗せで消費を決め直した。

同条件の模擬戦 (4,320戦) の前後: 勝利率は Lv40 の主 40→31%・魔法耐性 40→34%、その他は ±2ポイント以内。安い回復で全快できず、リバイブの消費が重くなった分。

## 攻撃の技の見直し (2026-10)

全36職を裸・魂ランク2・敵2体で比べ、技ごとの与ダメとMP効率を測った (`tools/balance/attack-skills.mjs`)。直したのは次の3つ。

- 全体技が単体の技より得すぎる: 敵2体でのMP効率が単体の1.25倍以下になるよう、全体攻撃44技の消費MPを上げた (元の2.5倍まで)。あわせて、敵全体への攻撃の技は魂の格の割合を最低6%にした (`SOUL_TIER_ALL_MIN`)。ファイアストームなど元のMP6〜7の全体呪文は Lv20 前後の隊の柱なので技のMPは据え置き、魂が育つほど重くする (技のMPを上げる案では Lv20 の模擬戦の勝利率が 物理耐性 51→41% に落ちた)。
- 強すぎる前の技: 盗賊の瞬殺 (威力 4.5→1.85) と朧抜き (2.4→1.65) が、後に覚える連撃をすべて上回っていた。
- 弱くて重い後発の技: 前に覚える技にどこでも負ける技の威力を、習得Lvで前の技の1.1倍に上げた (六連斬 0.75→1.35、影討ち・乱舞突き・斬光・夢幻泡影、鞘走り・颶風抜刀、百裂拳、双牙・阿鼻叫喚、絶影)。連撃は1回ごとに敵の防御を差し引くので、表の倍率より弱く出ていた。
- 共通の二段斬りと、Lv200 でなお前の技に負ける19技 (多くは付く効果で選ぶ技) は据え置いた。

前後 (変更前→後): 全体技が単体の1.3倍を超える職 Lv40 8→1・Lv100 8→0 (最大1.62→1.24)・Lv200 10→0 (1.93→1.25)。前の技に負ける後発の純粋な技 Lv100 15→12・Lv200 28→19。

同条件の模擬戦 (Lv20/40/80/120/200、7,200戦) の前後: 勝利率は Lv20 物理耐性 51→57%、Lv40 魔法耐性 37→33%・主 34→31%、その他は ±2ポイント以内。

## 魔騎士の底上げ (2026-10、ユーザーの指摘「聖戦士に比べて魔騎士が弱い」)

`node tools/balance/run.mjs --sim` (Lv20/40/80/120/200、作戦「全力」、中央値との比) で、魔騎士の与ダメは 0.83〜1.13 で、聖戦士 (2.2〜2.7、Lv200 で 6.3) の半分以下だった。原因は、聖戦士の剣技は `pieScale` でPIEも乗る (十字斬 +PIE×0.4) のに、魔騎士の剣技にはINTが乗らず、INT 1.6 が弱い攻撃呪文と通常攻撃の魔力付与にしか使われていなかったこと。魔騎士専用の魔法武器 (STR×0.5 + INT×0.5) を持つと、むしろ攻撃力が下がっていた。

- 魔騎士の闇の剣技に `intScale` (INTの乗り): 暗黒剣 0.4・吸血剣 0.3・呪縛剣 0.3・暗黒剣・終焉 0.5 (この4つは skilldefs.js、魔騎士だけが覚える)、血闇の剣・黒鉄断ち・闇喰らいの刃・黒渦斬り 0.4、獄炎の魔剣・宿命の黒剣・業魔断・斬首の黒刃 0.5、終焉・黒天 0.6。盾で打つ魔盾の三連撃はVITのまま。
- Lv40 の看板技 魔喰いの太刀: 威力 2.2→2.8・INT 0.5、消費MP 8→10。
- Lv65 の枠の共通技 心眼撃を固有技 魔刻の黒剣 (`DARKKNIGHT_MAKOKU`、MP14・威力3.2・INT 0.5・命中UP・HP6%の代償) に入れ替えた。Lv57〜95 に新しい攻めの技がなかった。
- 能力: STR 2.0→2.4、HP 8.0→7.6 (合計は据え置き。HPは聖戦士7.0より高いまま)。

前後 (中央値との比 Lv20/40/80/120/200): 魔騎士 1.03/0.98/0.83/1.13/1.09 → 1.31/1.59/1.49/1.29/1.74。魔闘士 (1.0〜1.8) と並び、聖戦士より下。攻撃の技の検査 (`attack-skills.mjs`) の結果は変わらない。

## 聖戦士の下方修正 (2026-10、ユーザーの指示)

同じ模擬戦 (作戦「全力」、中央値との比、8通りの乱数) で聖戦士は 1.24/2.14/2.31/2.22/5.14 (Lv20/40/80/120/200) と、伝説職を除く職で最も強かった。強さの源は、開幕の STR ×1.5 (聖戦の鬨と突撃の勢いの2段が重なる)・Lv40 の十字斬 (2連撃 + 1撃ごとにPIE×0.4)・STR 2.6。

- 突撃の勢い: STRの強化を外し、AGI ×1.15/1.2/1.25 (2ターン) だけにした。開幕のSTRは聖戦の鬨 (ユーザーの表の値) の1段だけになる。
- 十字斬: 威力 1.5×2 → 1.2×2、PIE 0.4→0.3。
- 贖罪の刃 PIE 0.8→0.5、聖戦の突撃 威力 5.6→5.0、十字架のなぎ (全体) 1.8→1.5、聖炎の突撃陣 (全体) 2.9→2.4。
- 能力: STR 2.6→2.4、HP 7.0→7.2。

後: 1.21/1.32/1.65/1.91/4.05。Lv200 の模擬戦はほぼ1ラウンドで終わり、先に動く者 (突撃の勢いのAGI) が倒しきるので比は当てにならない。見積もりの単体の最大の与ダメでは、Lv40〜200 とも物理職の中ほど (修羅・竜騎士・狂戦士・侍より下、魔騎士より少し上)。攻撃の技の検査 (`attack-skills.mjs`) の結果は変わらない。

## 全職の見直し (2026-10、ユーザーの指示「攻撃面だけでなく守り面や回復面など各方面から。魂の重ねやすさも考えて」)

### 測り方 (`node tools/balance/jobs.mjs`)

- **同じだけ遊んだ時点で比べる**: Lv L に届くまでの時間 (levelcurve.js `minutesToLevel`) × 職業の魂の入手 16/時 (見込み。テスト記録の `sl` で直す) × 死体の魂のレア度の割合 (70/20/9/1%) ÷ そのレア度の職の数 = その職の魂の数 (重ね数 → ランク・能力の伸び)。1職あたりの魂はコモンがレジェンドの約70倍出るので、Lv85 でコモンは R2 (×36)、レアは R2 (×7)、エピックは R2 (×4)、レジェンドは R1 (×1) ほど。Lv上限は残火で届く前提。
- **装備**: その Lv の迷宮の落とし物の帯 (`lootBand`) の中ほどまでのランク別標準装備から、ゲームの「最適装備」(autoequip.js + itemview `gearScore`) で選ぶ。裸だと武器の分 (攻撃力2〜3倍) だけ物理職が不利に出た。
- **戦い**: 5人の基準の隊に1人加え、その Lv が推奨Lv に入る本筋の迷宮の本物の魔物 (出現表・強さの素・手直し・強敵・主) と休まず12戦。合間に迷宮の「全員を回復」(蘇生 → 治療 → MP効率のよい回復) と勝利後のパッシブ。攻め・守り・回復・MPのもちが「もった戦数」にまとめて出る。
- **基準の隊**: A = 騎士・戦士・盗賊・僧侶・魔導士 (盾と回復のある整った隊)、B = 侍・義賊・狂戦士・狩人・呪術師 (盾も回復役もいない攻めの隊)。職が重ならないので、測る職が入っている組では測らない (入れ替えると入れ替えた職の値打ちを測ってしまう)。難しさ (敵の強さの倍率 k) は組・Lv ごとに、どちらにも入らない聖騎士で12戦の半ばまで進む強さに合わせる (Lv25〜85 で k = 0.85〜2.3、ゲームの強さに近い)。
- **点**: もった戦数を組ごとの中央値で割り、Lv の重み (Lv25 0.5・Lv45〜85 1・Lv130 0.5・Lv200 0.25) で平均する。1人は6人の1人なので差は縮んで出る (全能力 +10% で約 +0.05)。乱数のばらつきが大きいので `--seed-base` を変えた4回 (計32通り) の平均で判断する。
- **目安**: コモン 0.95 / レア 1.00 / エピック 1.05 / レジェンド 1.15 (手に入りにくく重ねにくい魂ほど、同じだけ遊んだ時点で少し強い)。

### 見つかった仕組みの問題 (直した)

- **魔力の譲渡 (司教 Lv80 `MANAGIFT`)** が払った MP より多くの MP を渡していた (INT と魂の格で伸び、Lv120 で払った MP の約4倍)。隊の MP が尽きず、司教が休まず戦う時の最強の職になっていた。渡せるのは払った MP の8割まで (`MANA_GIFT_RATE`、実処理とオートの見積もり `manaGiftAmount`)。
- **最適装備の重み** (itemview `gearWeights`): 使わない能力にも最低 0.35 の重みがあり、騎士・戦士が神理の法衣 (VIT19・PIE37) を竜王の鎧 (VIT39) より良いとして法衣を着ていた。最低の重みを 0.15 に (一番伸びる能力の重み 1.25 は据え置き)。

### 変えた数値

- レア度の係数 `RARITY_MUL`: レア 1.15→1.25・エピック 1.3→1.35・レジェンド 1.5→1.6 (レアがコモンを下回っていた)。
- 能力の基礎値 (souls.js `SOUL_CLASSES[].stat`):

## 盾役の見直し (2026-10、ユーザーの指示「盾役を調整して」)

能力値を上げても盾役は伸びなかった (守護騎士の HP・VIT を2倍にしても +0.03)。戦いが2〜3ラウンドで終わり、合間に回復で立て直せるので「早く倒す」が一番効き、矢面の構えで引き受けても傷が盾役へ移るだけで隊の合計は減らない。敵から隊への傷の内訳は通常攻撃が68〜91% (`TALLY=1 node tools/balance/jobs.mjs` で出る)、休まず戦って終わるのはほとんどが普通の戦いでの全滅 (消耗) だった。そこで「狙われた分だけ隊が楽になる」仕組みを足した。

- 固有パッシブの条件 `when.taunting` (自分が敵を引き付けている = 矢面の構え・挑発の効果中)、`hurt` にも `when` を付けられるようにした。
- `take` の `best: true` = 隊で重ならない守り (持ち主が何人いても一番強いものだけ。combat.js `_perkSum`)。
- オートの挑発の値打ちに、引き付けると硬くなる分を足した (combat.js `tauntGuard` → autotactics)。

| 職 | 引き付けると硬くなる (被ダメ) | 引き付けた打撃を返す | 隊全体のブレス・全体呪文 (best) |
|---|---|---|---|
| 騎士 | 騎士の鉄則 −25/32/40% | 騎士の鉄則 傷の40/50/60% | 方陣の規律 −8/12% (Lv145・175 → Lv45・125) |
| 守護騎士 | 不動の根 −20/28/36% (開幕の引き付け 2→3ターン) | 報復の楯 35/40/45% で傷の100/140/180% (Lv60 → Lv30) | 楯の誓い −8/12% |
| 神殿騎士 | 門守の誓約 −20/28/36% (開幕の引き付け 2→3ターン) | — | 魔除けの門 ブレス −6/12% → ブレス・全体呪文 −8/14% (Lv60 → Lv30) |
| 聖騎士 | 白銀の名乗り −18/24/30% | — | — |
| 護教官 | — | — | 後衛の守護 後衛 −6/10/14% → −10/15/20% + ブレス・全体呪文 −12/16/20% (Lv75 → Lv35) |

結果 (全職の測り直し、前 → 後): 騎士 0.81→0.86・守護騎士 0.83→0.86・護教官 1.02→1.04、神殿騎士 0.95→0.93・聖騎士 0.91→0.91 (盾役のいない組 B だけで見ると +0.02〜0.05。組 A には騎士がいるので、2人目の盾役は引き付けを分け合い、隊の守りも重ならない)。仕組みは効くが、この測り方の目安 (騎士0.95・守護騎士1.00) には届かない。残る差は「戦いが早く終わる」ことによる構造の差で、次の手は (1) 数値をさらに上げる (2) 反撃を厚くして守りを攻めに変える (3) 主・強敵の戦い (一撃が重い) の値打ちを別に測る、のどれか。 → (3) を次の節で行った。

## 主・強敵の戦いを別に測る (2026-10、ユーザーの指示)

`node tools/balance/jobs.mjs --scenario elite|boss|strong` = 12戦をすべて強敵 (`elite`)・すべて主 (`boss`、主のいない迷宮の Lv では推奨Lv の近い本筋の主をその階の強さで呼ぶ)・強敵2戦ごとに主1戦 (`strong`) にする (既定の `mixed` は従来どおり)。難しさ (k) は場面ごとに合わせ直す。`TALLY=1` の内訳は主・強敵・雑魚 (呼ばれた手下) と溜めた大技に分けて出る。

分かったこと (盾役の見直しの後、32通りの平均):

- 盾役は主・強敵の戦いで**さらに下がっていた** (雑魚込み → 強敵 / 主): 守護騎士 0.86 → 0.75 / 0.69、騎士 0.86 → 0.78 / 0.78、聖騎士 0.91 → 0.85 / 0.84、神殿騎士 0.93 → 0.91 / 0.87、護教官 1.04 → 0.93 / 0.93。盾役のいない組 B でも同じ。逆に上がるのは単体の火力・回復の職 (枢機卿・魔闘士・賢者・魔法剣士・死霊術師、+0.12〜0.22)。
- 理由: 主の戦いの傷はブレス・全体呪文 (Lv45 で79%、Lv85 で40%、引き付けでは逸らせない) と、主が呼ぶ手下の打撃 (Lv85 で46%) が多く、長引くほど手下が増える「倒す速さの勝負」。主から隊全体への傷を30%減らしても +0.03〜0.07 しか動かない。強敵の戦いは溜めた渾身の一撃が傷の26〜34%。
- 盾役は戦闘の初めに引き付けて (不動の根・門守の誓約・白銀の名乗り・騎士の矢面の構え) おり、挑発が足りないのではない (守護騎士は長い連戦の途中でMPが尽きる)。

足したもの:

- **受け止め** (combat.js `_tauntHolder`): 敵を引き付けている味方がいれば、溜めた**渾身の一撃**はその者が必ず受ける (猛威・溜めたブレスは全体なので対象外)。オートは渾身の一撃を溜めている敵がいる時の挑発を高く見る。
- 条件 `when.strong` (相手が主か強敵 = `_strongFoe`) と、`aura` の成分の持ち主側の条件 `holder` (例 `holder: {taunting: true}` = 持ち主が引き付けている間だけ隊に効く。combat.js `_perkSum`)。`deal` にも `best` を付けられる。
- **隙を作る** (引き付けている間、主・強敵への味方全員の与ダメージ+、盾役どうしでは一番強いものだけ): 騎士 騎士の鉄則 +12/16/20%・守護騎士 不動の根 +13/18/23%・神殿騎士 門守の誓約 +10/14/18%・聖騎士 白銀の名乗り +8/11/14%。
- 主・強敵のブレス・全体呪文への守り (best): 方陣の規律・楯の誓い −18/26%、魔除けの門 −18/28%、後衛の守護 −20/25/30% (ほかの敵には従来の −8〜20%)。

結果 (全職を3つの場面で測り直し、雑魚込み / 強敵 / 主、前 → 後):

| 職 | 雑魚込み | 強敵 | 主 | 主 (組 B = 盾役1人) |
|---|---|---|---|---|
| 騎士 | 0.86 → 0.89 | 0.78 → 0.91 | 0.78 → 0.90 | 0.78 → 0.90 |
| 守護騎士 | 0.86 → 0.86 | 0.75 → 0.84 | 0.69 → 0.76 | 0.73 → 0.89 |
| 神殿騎士 | 0.93 → 0.92 | 0.91 → 0.96 | 0.87 → 0.91 | 0.88 → 0.97 |

| 護教官 | 1.04 → 1.07 | 0.93 → 0.93 | 0.93 → 0.92 | 0.98 → 0.96 |

ほかの職の動きは ±0.05 以内 (組 A の騎士が隙を作るぶん、組 A の他の職もわずかに楽になる)。盾役1人の隊では主の戦いで0.9〜1.0 に届いた。組 A (すでに騎士がいる) へ2人目の盾役を入れた時は、引き付けを分け合い、隙を作る・全体攻撃の守りも重ならないので低いまま (守護騎士 0.64) — 盾役は1人で足りる、という作り。

## 比較の限界と次の判断材料

装備なし・サブ魂なし・模擬戦は魂ランク2。残火でLv上限を延ばす設定なので、実際の高Lvの装備/融合状態とは異なる。職業のレア度補正は残り、物理職と術職では隊構成も異なる。敵は同Lv戦士の能力値から作った負荷確認用で、実際の迷宮の魔物ではない。Lv10の模擬敵は多くの隊が敗れる強さであり、この勝率を序盤の難易度とは扱わない。

会心と耐性貫通を抑えた分、魔法耐性持ちや主への勝率が下がる条件もある。全職の完全な均衡や、実際の100以上の迷宮の難易度を保証するものではない。次はゲーム内のテスト記録で、隊の装備・サブ魂・Lvと各迷宮の勝率、消費MP、回復、選ばれた技を集める。状態異常・守り・探索能力は単純な与ダメージ順位では評価しない。
