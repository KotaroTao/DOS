# 武魂に合わせたスキル・パッシブ改定（2026-10-29）

HP/MP回復・吸収・蘇生時HP・消費MP・習得条件・回復を含む複合技は変更しない。武魂の性能も変更しない。

## 会心

2026-10-30追記: 深淵の知の魔法会心率は+5/10/15/20%。会心ダメージ補正は物理と魔法を別々に計算する。装備の会心ダメージ補正と加算し、元の会心倍率に掛ける。従来の必殺・急所読み・冴えの倍率はその後に適用。会心率は通常80%上限、確定会心は従来どおり別。

| 対象 | 追加会心ダメージ | 条件 |
|---|---|---|
| 武士の一分 | 物理 +10 / 20 / 30% | 常時 |
| 抜き身の心得 | 物理 +15 / 25 / 40% | 1ターン目 |
| 闇よりの一刺 | 物理 +15 / 25 / 40% | 対象HP90%以上 |
| 深淵の知 | 魔法 +50 / 100 / 200 / 300% | 常時 |
| 呪文会心 | 魔法 +10 / 20 / 30% | 常時 |

条件付き補正は `critDamage` のfxで判定し、実ダメージ・反撃・オート予測で共通に使う。戦闘情報の物理倍率は対象未指定のため、一刺のような敵依存条件は含めない。魔法の2種は既存の独立したパッシブLvを読む。重力は会心しない。
