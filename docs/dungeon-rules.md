# 迷宮の掟の台帳 — 案の出し尽くし

> 2026-10-11 作成 (ユーザーの指示「迷宮の掟の案を先に出し尽くしておきたい」)。
> まだ実装していない案の一覧。新しい迷宮・土地 (章) を作るときに、ここから選んで `trait` (迷宮の掟) か `REALM_RULES` (土地の掟) に起こす。
> 使った案は「状態」に迷宮の id を書く。案を足すときは末尾に番号を続ける (番号は並べ替えない)。

## 決まりごと (CLAUDE.md より)
- **★ 強い掟は格上の迷宮 (`challenge: true`) だけに付ける。** 土地の掟にはしない (「迷宮の数の目安」の②)。
- 土地の掟 (`REALM_RULES`) が持てるのは開幕の効果 (`hpDrain`/`mpDrain`/`chill`/`poisonStart`/`boltStart`) と `say` だけ。それ以外の案を土地の掟にするなら `REALM_FIELDS` を広げる。
- 迷宮の掟は土地の掟と同じ効果を作らず、その迷宮だけの違いにする。
- 盤面の加工 (`shaft`/`ledge`/`vent`/`bog`/`mist`) を使う迷宮は、`floorHaz` に対応する足元の仕掛けを置く。
- 新しい掟を実装したら、その掟に触れる酒場の心得 (`tavern.js`、`req: "open:<迷宮id>"`) を足す。

- 【小】 … 少し足せば作れる

- **第九章「闘技場跡」の土地の掟**: 103 見世物の闘技場 か 22 高まる戦意。
