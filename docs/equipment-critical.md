# 既存装備の会心性能

2026-10-17。`src/equipmentcrit.js` が品のレア度・Lv・用途から本来性能を決める。結果は拾得乱数に依存せず、既存品も保存読込で更新する。

| レア度 | 物理／魔法会心率 | 物理／魔法会心ダメージ補正 |
|---|---:|---:|
| コモン | 1〜2% | 5〜10% |
| アンコモン | 2〜4% | 10〜20% |
| レア | 4〜7% | 20〜35% |
| スーパーレア | 7〜12% | 35〜60% |
| レジェンドレア | 12〜20% | 60〜100% |

- 本来性能は範囲内をLv1〜200で補間。率は0.1%、ダメージ補正は1%単位。品質による増減も適用する。
- 追加特性の抽選幅は別に定め、下限を共通、従来上限×C1/UC1.25/R1.5/SR1.75/LR2とする。追加会心率はC1〜5%・LR1〜10%、追加会心ダメージはC10〜30%・LR10〜60%。詳しくは `infinite-affixes.md`。本来性能の上表と品1点の合計上限は維持する。
- 全2050装備のうち1490品に会心性能（全758武器を含む）。短剣・刀・弓・片手の剣槍は物理率、斧・槌・両手の剣槍は物理ダメージ。純術者の杖は片手で魔法率・両手で魔法ダメージ。複合武器は格の下限側で物理/魔法の率を持つ。
- 小手は軽装で物理率・重装で物理ダメージ・布で魔法ダメージ。頭と足は軽装で物理率・布で魔法率。小盾・宝珠・聖典はそれぞれ物理率・魔法率・魔法ダメージ。攻撃型の胴・装飾にも用途に合う項目を付け、守り・回復・探索専用の品はその用途を保つ。
- 原則1〜2項目。元から持つ会心性能も保つが、鷹の目の旧25%などは1品の率20%上限へ合わせる。
- **品1点の上限**：本来性能・品質・追加特性の合計で、物理率/魔法率各20%、物理/魔法の会心ダメージ補正各100%。追加特性の保存値は保持し、品の残り容量に収まる実効値で適用・表示・評価する。率が上限でも博打の被ダメージ増加は消えない。上限に達した項目の巻物は書き込めない。
- **装備全体の合算**：物理・魔法の会心ダメージ補正に上限なし。同種は加算。「会心ダメージ+」は物理・魔法の両方に加算し、「魔法会心ダメージ+」は魔法へ追加する。+100%の品が2つなら合計+200%、元の会心ダメージの3倍。物理なら1.85×3＝5.55、魔法なら1.5×3＝4.5。
- **最終会心率**：物理・魔法とも職業・LUK・装備・技など適用される補正を合算し、0〜100%に収める。魔法会心にLUKや物理の率は流用しない。魔法率の装備+40%制限は廃止。重力・回復は会心しない。魔法属性の通常攻撃は物理側の会心性能を使う。
- 強さ評価の会心点は、率×100＋会心ダメージ補正×20をB/25倍。本来性能と追加特性で同じ物差し。効果の出ない追加分は加点せず、値段にも反映しない。深度・品質・鍛造は既存の順番で適用する。
- 読み込みでは所持品・装備中・保存編成・無限迷宮で退けた本編・魂の記憶の品を、共有参照を保持して一度だけ更新する。

検証：`node tools/balance/catalog-critical.mjs`、`python3 tools/inventory/catalog-critical-browser.py`。全技・出来事は `node tools/balance/check.mjs`、模擬戦は `node tools/balance/run.mjs --sim`。
心得：`t_equipment_critical`、`t_affix_critical`。
