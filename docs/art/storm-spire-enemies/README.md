## 原画・登録・検証

原画は sheet-1.png〜sheet-4.png。切り出しは python3 tools/storm-spire/build-enemies.py（Pillow・NumPy・SciPy）。本体の輪郭を区画へ割り当て、離れた効果は近い本体へ配分する。4枚目は竜の翼が広いため本体中心の境界を調整。長辺512px以下へ縮小し、周囲に透過余白を追加する。

出荷物は art/monsters/ のWebP21枚、合計約5.9MiB。src/monsterphotos.js に寸法、sw.js の ASSETS にパスを登録。CACHE の dos-dev は維持。原画・確認画像は公開対象外のこのフォルダへ保存。

python3 -m http.server 8000 の起動後、node tools/storm-spire/verify-enemies.cjs で実描画を検証する。全7迷宮の出現表・強敵・主・召喚先・共通敵の網羅、29種の画像読み込み、非空の戦闘描画、取得失敗時の旧絵での起動を確認。画像登録による能力・説明・文字グリッドの変更0件、ブラウザ例外0件。
