# 祓魔師 R1〜R5（exorcist）

ユーザーの「祓魔士」はゲーム定義の祓魔師 `exorcist`。承認済みのR1を直接参照し、R2〜R5を各1枚ずつ独立生成した。聖戦士 `crusader` を人体・顔・描画の粒度と装備成長の参考にした。採用原画は `exorcist-r1-final.png`〜`exorcist-r5-final.png`。承認時の比較は `r1-comparison.png`。

既存の青年男性、灰色がかった茶髪、落ち着いた顔、黒い法衣、白い肩布と赤い札、茶色の革具を維持した。既存5ランクの特徴は `existing-ranks.png` に保存。R1は短い祓魔剣と札、R2は肩当てと腕具、R3は刻印付きの剣・鈴・聖典、R4は数珠・背負う祓魔杖・重ねた肩布、R5は大型の祓魔剣・金縁の防具・赤い裏地の法衣を強化した。R5を最も豪華にした。

R5の剣とマントを画像端から内側へ調整し、滑らかになった修正案の描画粒度を戻した。R4・R5は顔の顎位置も修正した。修正前の案は `*-draft.png` に保存。

## 取り込みと測定

`import-settings.json` に原画ごとの頬・主な髪の頭頂・顎・足裏と倍率を保存した。頭頂は跳ね毛の先を除いて測った。`measurement-grid.png` と各 `*-head-grid.png` が測定補助。承認済みR1の人体を保持し、頭頂から足裏を約82.9ドットに合わせた。90×92ドットの共通枠、頭頂9ドット、保存画像360×368px。機械的なドット化・減色はしていない。

再取り込みはリポジトリ直下で `python3 docs/art/exorcist/import-art.py`。既存の `tools/jobimg.py` の取り込み処理を使う。全身の顔アンカーはR1の `[45,20]` に固定し、顔アイコンの切り出しには各原画の実測 `head` を使う。他職業の設定は変更しない。

最新mainを取り込んだ後の共通描画枠は聖戦士と同じ96×96ドット。実表示では顔アンカー `[48,23]`、頭頂12ドット。取り込み前のmainでは96×94ドットだったが、他職業を含む現在の共通枠に従い、聖戦士と祓魔師の倍率は同じ。承認済みR1の頭の高さは約21.18ドットで、聖戦士の約21.93ドットとの差は約0.75ドット。祓魔師5枚の顎位置の差は約0.28ドット。聖戦士の数値を原画の実測値へ置き換えることはせず、顔アイコンはゲームの既存処理で頭の高さを揃える。

出荷画像は `art/jobs/exorcist_1.webp`〜`exorcist_5.webp`。`src/jobphotos.js` の測定値を更新し、`sw.js` の既存5画像の登録を確認して制作基準のコメントを追加した。CACHEは `dos-dev` を維持。`src/jobart.js` に対象の優先画像はない。

## 確認

`python3 docs/art/exorcist/review-game.py` が確認中だけローカルサーバーを起動し、既存の `tools/review-job-art.py` で比較画像を更新する。続いて `python3 docs/art/exorcist/verify-art.py`。承認済みR1の実測の頭を保持するため、聖戦士との顎差0.3ドットを要求する `--require-photos` は使わず、独立した検査で5ランクの新原画選択・顔座標・共通枠を確認する。

`game-display-review.png` は同倍率の全身6枚、56/36/26pxの顔と拡大顔24枚。`game-display-review.json` は実際の画像選択とブラウザーエラー・起動検査、`asset-verification.json` は透過・輪郭・残片・画像端の記録。足先の縮小補間による半透明画素は基準の聖戦士と同様に最下行へ残るが、不透明な人物は画像端に達していない。武器・杖・マントと札の先端は目視確認する。

作業ブランチは `codex/exorcist-job-art`。ユーザーの追加指示でmainへのマージを実施する。
