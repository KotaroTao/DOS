# 洗礼の大水槽の魔物

森の古屋の3体（`docs/art/prologue-enemies/preview.png`）の暗い輪郭・左上の光・細かなドットの陰影を基準に、図鑑の説明・伝承に沿って未作成の3体を制作。作業前に最新mainの登録とWebPを照合し、作成済みの12体は共用した。

| ID | 魔物 | 絵に反映した特徴 |
| --- | --- | --- |
| bs_irongolem | 青銅の神兵 | 緑青に覆われた青銅の兵の像、身を沈めて引き絞る長い矛、光を溜める穂先 |
| bs_voidwalker | 虚無の歩者 | 顔のない細長い姿、揺らぐ輪郭、胸の穴に見える星々 |
| bs_shadowdragon | 深みの海竜 | 角とひれ、長い首、輪状の筋があるうろこ、渦巻く潮のブレス |

通常敵9種・強敵の異端大司教・共通敵5種（銀業、金業、銀業の王、ミミック、マスターミミック）の全15種を確認。大水槽に主はいない。この顔ぶれには追加の召喚先・取り巻きもない。同じIDが出る別の迷宮にも絵が反映される。

原画は [master.png](master.png)。`python3 tools/baptism/build-enemies.py` で輪郭を横切らない位置で3体を切り出し、最大512pxに縮小・周囲4pxの透過余白を付け、ロスレスWebP・寸法台帳・`src/monsterphotos.js`・`sw.js` を更新する。出荷用WebPは3枚で約673KiB。再実行で既存12体の画像は変更しない。

## 確認

ローカルHTTPサーバーをポート8000で起動して `node tools/baptism/verify-enemies.cjs` を実行（PlaywrightとChromiumが必要）。保存なしのw16テストモードで、全15体の登録・非空の戦闘画像・従来の能力値等の維持を確認。画像取得失敗時には全15体が旧絵のまま起動することも確認した。

[全15体の一覧](preview.png)・[図鑑](codex-mobile.png)・[盤面](board-mobile.png)・[戦闘](battle-mobile.png)。JavaScript構文、SW登録、物語の画像登録との整合性も確認。新機能や戦闘ルールの変更はないため、酒場の心得の変更はない。
