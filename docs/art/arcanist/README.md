# 秘術師 R1〜R5

職業IDは `arcanist`。聖戦士の `crusader` と区別し、職業IDやゲームの能力は変更しない。

既存の特徴は白銀の短髪、青緑の目、紺・白・金のローブ、茶色のベルトとブーツ、水宝珠の杖、魔導書。
既存のランク差は、R2で金縁と腰飾り、R3で環付きの杖と大きな魔導書、R4で大型の宝珠と開いた本、R5で多重の環と宝石・鎖の装飾が増える構成。

ユーザー確認済みR1は `arcanist-r1-final.png`。R2〜R5はこの原画と聖戦士を直接参照し、各ランクを独立した透明画像として制作した。
顔・髪・人体・姿勢をR1に揃え、装備と装飾を段階的に強化する。R1の初案と承認時の比較も保存する。

R2は金縁・魔導書の金具・水晶、R3は杖の環・肩と裾の装飾、R4は大型の宝珠・開いた魔導書・腰の飾り、R5は多重の環・金の鎖・星と水晶・天体模様の魔導書を採用した。
R4の配置がずれた初案と、R5の姿勢が変わった初案は採用せず、R1の配置へ戻した。R4・R5の杖の上部を修正し、顔アイコンの端へ入る飾りを左へ寄せた。修正前の案も保存している。

R4とR5の差が弱いというユーザーの指摘を受け、R5をさらに強化した。大きな金と水晶の肩飾り、三重環の杖、厚い大型魔導書、白と金の広い縁取りで最上位の違いを出した。
変更前のR5は `arcanist-r5-before-rank-contrast.png`、R4と更新後R5の実描画比較は `r4-r5-comparison.png`。

## 取り込み

`tools/jobimg.py` で `art/jobs/arcanist_1.webp`〜`arcanist_5.webp` と `src/jobphotos.js` の顔・頭設定を更新した。
共通枠は90×92ドット（360×368px）、主な髪の頭頂は9ドット。原画を機械的にドット化・減色していない。
測定値は `import-settings.json`。再取り込みはリポジトリのルートで `python3 docs/art/arcanist/import-art.py`。

`sw.js` には5枚とも既に登録されているため一覧の変更は不要。CACHEは `dos-dev` を維持している。
`src/jobart.js` に秘術師の優先画像はなく、全ランクで新しい原画を選ぶことを実描画で確認した。

## 確認

`final-review.png` は聖戦士R1と秘術師R1〜R5の同倍率全身、56/36/26pxの顔アイコンと顔拡大。
`final-review.json` に全身6枚・顔24枚の描画、画像選択とブラウザーエラーなしを記録した。
再確認はlocalhost限定のサーバーを起動してから `python3 tools/review-job-art.py arcanist --label 秘術師 --output docs/art/arcanist/final-review`。
`python3 docs/art/arcanist/verify-art.py` は透過・画像端・輪郭・画像選択・SW登録・R1からの配置差を検査する。Pillow・NumPy・SciPyを使用する。

実描画の顔位置は全6枚で `[48,21]`、主な髪の頭頂は10ドット、表示枠は96×94ドットで一致する。
確認済みR1の輪郭を維持したため、秘術師の顎は聖戦士より約0.55〜0.62ドット上。秘術師のランク間の顎位置差は0.07ドット以内。
この差を実測値のまま保存し、聖戦士からの顎位置差0.3ドット未満を要求する `--require-photos` は使用していない。
画像選択・顔座標・共通枠・各測定値との一致は `verify-art.py` で別途検査し、結果を `asset-verification.json` に保存した。
全5枚で画像端は透明で欠けはなく、8近傍で不透明な輪郭はひと続き。細い斜線も同じ輪郭として検査している。
JavaScriptの構文、ゲーム起動と `git diff --check` も確認した。

作業ブランチは `codex/arcanist-art`。ユーザーの指示に基づき、mainへの反映はPR経由で行う。
