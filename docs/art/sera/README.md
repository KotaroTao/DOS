# 灯守（sera）の制作記録

## 確定したR1の仕様

- 職業IDは `sera`、セラ専用職「灯守」。
- セラは木の器と黒鉄の継ぎ目を持つ人業。褐色の人間の体へ変更した案は採用しない。
- R1の装飾は控えめにし、黒い長髪、白い衣装、胸の灯、丸盾を維持する。
- 額の中央に、金色の「灯を掌に載せた手」の師の印を付ける。宝石や花の模様に置き換えない。
- 頭身はユーザーが再添付した初期原画 `sera-r1-candidate.png` を直接の基準にする。頭・顔と胴・脚の比率を維持し、装飾の簡素化で体型を変えない。

## 額の印の根拠

- `src/story.js` の `w04_arm`：手首の刻印を「灯を掌に載せた手。師の印」と説明。
- `src/story.js` の `w07_sera`：黒い木彫りの髪と、額にある師の印を説明。
- `art/story/chapter2/w07_sera.png`：額の中央に金色の手と灯の印が描かれている。
- `art/story/chapter2/irene_sera.png`：館で守られているセラの頭にも額の金色の印がある。

ユーザー承認済みの原画は `sera-r1-final.png`（`sera-r1-proportions.png` と同じ画像）。初期原画・修正版・聖戦士R1との全身・顔の比較は `r1-proportions-comparison.png`。

## ランクごとの制作方針

既存絵は全ランク共通の仮ドット絵で、長い黒髪、胸の灯、丸盾が特徴。新原画は確定R1を直接参照して各ランク1枚ずつ制作する。

| ランク | 名前 | 装備と装飾の成長 |
|---|---|---|
| R1 | 灯の人業 | 簡素な白布、黒鉄の継ぎ目、灯の丸盾 |
| R2 | 灯守 | 金縁、継ぎ目の補強、小さな肩鎧、短い灰青のマント |
| R3 | 灯の盾 | 重ねた肩鎧、強化した丸盾、灯と水の模様、腰までのマント |
| R4 | 守り灯 | 青い宝石、金の彫金、白い裏地のマント、白布の刺繍 |
| R5 | 永灯の守り手 | 灯をかたどる髪飾り、豪華な肩鎧と盾、金の鎖、白金と青のマント |

顔・人体・ポーズ・ドット粒度と額の師の印は全ランクで維持する。頭身は聖戦士の数値へ無理に変更せず、最後にユーザーが承認したセラR1を基準とする。聖戦士は表示倍率と装飾の成長の参考にする。

## ゲームへの取り込みと確認

- 採用原画：`sera-r1-final.png`〜`sera-r5-final.png`。R2〜R5は確定R1と対応する聖戦士ランクを参照した独立画像。
- 測定値：`import-settings.json`。各原画の顔の左右・主な頭頂・顎・足裏を測定。共通枠90×92ドット、頭頂9ドット、頭頂〜足裏82.5ドット。足元の透過余白を保つため、聖戦士の約82.9ドットよりわずかに短くしている。
- 取り込み：既存 `tools/jobimg.py` を使用。出荷画像は `art/jobs/sera_1.webp`〜`sera_5.webp`（360×368px）。ドット化・減色はしていない。
- `src/jobphotos.js` に全5ランクの顔設定を追加し、`sw.js` のASSETSに画像を追加。CACHEは `dos-dev` のまま。`src/jobart.js` に灯守の優先画像はないため変更していない。
- `source-comparison.png`：聖戦士R1と灯守R1〜R5の同倍率原画比較。
- `final-review.png` / `final-review.json`：実際の `jobSprite` / `jobBust` による全身6枚、56・36・26pxの顔と拡大顔24枚。全ランクの画像選択を確認。ブラウザーエラーなし。
- `asset-verification.json`：全5枚の透過・寸法・枠端で欠けていないことを確認。
- `mobile-startup.png`：390×844pxでゲーム起動を確認。
- 全 `src/*.js` のNode構文チェック、`sw.js` の構文チェックを実施。

頭身は承認済みセラR1を優先しているため、聖戦士との顎座標の完全一致を要求する共通確認オプションは使用せず、`review-game.py` でセラの全ランク同士の頭・顔の位置を検査している。

再取り込みは `python3 docs/art/sera/import-images.py`。確認画像の再作成はローカルサーバー（8000番）起動後 `python3 docs/art/sera/review-game.py`。原画比較は `python3 docs/art/sera/compare-sources.py`。

作業ブランチは `codex/sera-job-art`。mainへのマージは未実施。
