## 確定したR1の仕様

- 職業IDは `sera`、セラ専用職「灯守」。
- セラは木の器と黒鉄の継ぎ目を持つ人業。褐色の人間の体へ変更した案は採用しない。
- R1の装飾は控えめにし、黒い長髪、白い衣装、胸の灯、丸盾を維持する。
- 額の中央に、金色の「灯を掌に載せた手」の師の印を付ける。宝石や花の模様に置き換えない。
- 頭身はユーザーが再添付した初期原画 `sera-r1-candidate.png` を直接の基準にする。頭・顔と胴・脚の比率を維持し、装飾の簡素化で体型を変えない。

## ランクごとの制作方針

既存絵は全ランク共通の仮ドット絵で、長い黒髪、胸の灯、丸盾が特徴。新原画は確定R1を直接参照して各ランク1枚ずつ制作する。

| ランク | 名前 | 装備と装飾の成長 |
|---|---|---|
| R1 | 灯の人業 | 簡素な白布、黒鉄の継ぎ目、灯の丸盾 |
| R2 | 灯守 | 金縁、継ぎ目の補強、小さな肩鎧、短い灰青のマント |
| R3 | 灯の盾 | 重ねた肩鎧、強化した丸盾、灯と水の模様、腰までのマント |
| R4 | 守り灯 | 青い宝石、金の彫金、白い裏地のマント、白布の刺繍 |
| R5 | 永灯の守り手 | 灯をかたどる髪飾り、豪華な肩鎧と盾、金の鎖、白金と青のマント |

顔・人体・ポーズ・ドット粒度と額の師の印は全ランクで維持する。頭身は聖戦士の数値へ無理に変更せず、最後にユーザーが承認したセラR1を基準とする。聖戦士は表示倍率と装飾の成長の参考にする。

- 採用原画：`sera-r1-final.png`〜`sera-r5-final.png`。R2〜R5は確定R1と対応する聖戦士ランクを参照した独立画像。

頭身は承認済みセラR1を優先しているため、聖戦士との顎座標の完全一致を要求する共通確認オプションは使用せず、`review-game.py` でセラの全ランク同士の頭・顔の位置を検査している。

再取り込みは `python3 docs/art/sera/import-images.py`。確認画像の再作成はローカルサーバー（8000番）起動後 `python3 docs/art/sera/review-game.py`。原画比較は `python3 docs/art/sera/compare-sources.py`。

作業ブランチは `codex/sera-job-art`。main統合の指示後、最新mainの大魔導師・狂戦士の画像追加を保持して競合を解消し、構文・全ランク描画・モバイル起動を再確認した。
