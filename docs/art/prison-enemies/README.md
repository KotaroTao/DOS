# 捨て砦の地下牢の魔物

森の小屋の敵3体（`docs/art/prologue-enemies/bs_dustroach.png`、`bs_littlecentipede.png`、`bs_woodbee.png`）を画風の基準に、図鑑の説明・伝承・能力を参照して通常敵9体を制作した。作業中に大手門の更新で共通3体がmainへ入ったため、その3体は作成済みとして採用し、最終的な追加は残り6体とした。左上の光、暗い輪郭、控えめな色、細かなドットの質感をそろえ、背景は透過とした。

| ID | 魔物 | 絵に反映した特徴 |
| --- | --- | --- |
| d03_ghost | さまよう亡霊 | 忘れられた囚人の魂、冷たい長い指、破れた青灰色の衣 |
| bs_banshee | バンシー | 泣き女の霊、広がる灰色の髪、死を報せる絶叫 |
| bs_cultist | 邪神の僧 | 古い僧衣と聖印、魂を求めて伸ばす霊の手 |
| bs_shadowmage | 影の術師 | 肉体のない黒紫の影、闇の手下を呼ぶ炎 |
| bs_dullahan | デュラハン | 首のない黒鎧、小脇に抱えた己の首、首筋を狙う剣 |
| bs_bloodorc | 血狂いのオーク | 赤褐色の巨体、飢えた捕虜の首輪とちぎれた鎖、激怒する姿 |
| bs_bloodwraith | 血霊 | 血だまりから伸びる暗赤色の霊体、液状の腕 |
| bs_vampire | ヴァンパイア | 夜の貴族の衣、青白い顔と牙、命を奪う手 |
| bs_bonecolossus | 骨の巨兵 | 幾十のどくろと骨を組んだ巨体、胴の中の叫ぶ顔 |

最新mainの登録を照合し、作成済みの処刑人の大鬼・ミミック・マスターミミック・黒い宝箱・金属の魔物3種を維持した。地下牢には主は設定されていない。召喚先のさまよう亡霊も今回の対象に含む。能力値・技・伝承・出現条件は変更していない。同じIDの敵はほかの迷宮でもこの絵を共用する。新機能・戦闘ルールの変更はないため、酒場の心得は変更しない。

邪神の僧・血狂いのオーク・骨の巨兵は大手門の作成済み原画を共用する。下記シートのこの3体は制作案としてのみ保存する。

原画: [sheet-a.png](sheet-a.png)。`python3 tools/prison/build-enemies.py` で輪郭と離れた炎をまとまりごとに切り出し、余白を付けてロスレスWebPへ変換する。公開物は `art/monsters/` の6枚のみで、原画と確認画像は公開しない。登録は `src/monsterphotos.js` と `sw.js`。

## 確認

ローカルHTTPサーバーをポート8000で起動し、`node tools/prison/verify-enemies.cjs` を実行する（Playwright・Chromiumが必要）。保存なしのテストモードで次を確認する。

- 通常敵9種・強敵・召喚先・共通の敵を合わせた16種の網羅と、非空の戦闘用画像。
- 戦闘・盤面・図鑑での表示と、既存の能力値・旧絵の維持。
- 画像取得をすべて失敗させても、16体が旧絵で起動すること。

確認画像: [一覧](preview.png)・[図鑑](codex-mobile.png)・[盤面](board-mobile.png)・[戦闘](battle-mobile.png)。
