# 別セッション用の職業イラスト制作プロンプト

下の【職業名】と【職業ID】を置き換えて新しいセッションへ貼る。最初はR1の確認で止まり、承認後に続行プロンプトを送る。聖戦士は `crusader`、聖騎士は `paladin`。IDはゲームの定義で確認する。

## 最初に貼るプロンプト

```text
「魂の迷宮（DOS）」の【職業名】（ID: 【職業ID】）のR1〜R5のイラストを作り直し、ゲーム画像を差し替えてください。

まずAGENTS.md、CLAUDE.mdの関連箇所、docs/art/job-art-standard.md、docs/art/crusader-reference.jsonを読んでください。mainを取り込んだ専用のcodexブランチで作業してください。下準備の資料がmainにまだない場合は、origin/codex/job-art-preparationを取り込んでから始めてください。

今回確定した聖戦士（赤髪の女性、crusader）を全職業共通の新しい制作基準にします。
・人体と顔の基準原画：docs/art/crusader/crusader-r1-final.png
・装備と装飾の成長の参考：docs/art/crusader/crusader-r2-final.png〜crusader-r5-final.png
・実表示の参考：docs/art/crusader/game-display-review.png
・取り込み実例：docs/art/crusader/import-settings.json、README.md
原画を実際に開き、画像生成時にも参照画像として渡してください。

制作条件：
1. 対象職業の現在のR1〜R5をゲームから確認し、固有の性別・顔立ち・髪型・髪色・配色・武器・衣装・装備の成長を維持してください。聖戦士の性別や衣装を対象へ移植しないでください。職業名とIDを取り違えないでください。
2. 顔のサイズと位置、主な髪の頭頂・顎・目・足裏、頭身、描かれたドット粒度を聖戦士R1と揃えてください。全ランクで固定し、人物を縮めず装備と装飾を段階的に強化してください。
3. 最初から各ランク1枚ずつの独立した画像として制作してください。集合絵を分割する方式は禁止です。背景は透明にしてください。
4. まず対象R1だけを制作し、聖戦士R1と同倍率の全身・顔の比較画像を提示してください。私の確認を待ってからR2〜R5へ進んでください。
5. 原画の背景余白や飾りの大きさで人物の倍率を変えないでください。帽子・角・ポニーテール等の先を人体の頭頂として測らないでください。設定値だけで合わせず、輪郭も比較してください。
6. R1承認後はその対象R1を直接参照し、聖戦士も参照してR2〜R5を制作してください。R5を最も豪華にし、マントや装飾は体の中心に対して正しく配置してください。
7. 5枚完成後、聖戦士と同倍率で並べ、全身と56/36/26pxの顔アイコンを確認してください。武器・マント・髪飾りの欠け、不要な残片、背景の残りを修正してください。
8. 原画・測定値・採用案・比較画像をdocs/art/【職業ID】/に保存し、既存tools/jobimg.pyで取り込んでください。機械的なドット化・減色はしないでください。共通枠90×92ドット、頭頂9ドットを基本にし、各原画を測って--per-dotと--headを設定してください。聖戦士の原画座標をそのまま流用しないでください。
9. src/jobphotos.jsとsw.jsを更新し、旧src/jobart.jsの対象ランクが優先される場合は対象だけを外してください。他職業や職業IDは変更しないでください。CACHEはdos-devを維持してください。
10. 実際のjobSprite/jobBustによる画像選択と描画、透過と欠け、構文、ゲーム起動を確認してください。tools/review-job-art.pyを活用し、完了時に確認画像と変更内容を提示してください。mainへのマージは別途指示します。

効率のため、制作前に対象の既存5ランクの特徴と成長差を短く記録してください。R1で人体と顔の配置を確定し、R2以降は装備と装飾の差分を明示して編集してください。ずれが出たときはその箇所だけ修正し、全体を作り直して別の人体へ変えないでください。
```

## R1確認後の続行プロンプト

```text
R1でOKです。確定したR1を直接参照してR2〜R5を各1枚ずつ独立制作してください。顔・人体の位置とサイズ・頭身・ドット粒度・ポーズを固定し、既存職業の装備の成長を維持してください。5枚の最終比較と修正、原画保存、ゲームへの取り込み、顔設定更新、実表示の確認まで進めてください。mainへのマージはまだ行わないでください。
```

## 生成ツールへの指示のひな型

これは上記の作業を行うエージェントが使う指示。対象職業の特徴を確認してから角括弧を具体化し、基準原画と対象の既存画像を参照画像として渡す。

```text
透明背景のゲーム用ピクセル調全身キャラクターを、1人・1ランクだけ、独立した1枚として制作する。
参照1の確定した聖戦士R1と、主な髪の頭頂・顎・目・顔の幅・肩・腰・足裏の高さ、顔と人体の大きさ、約3.78頭身、輪郭と髪と目のドット粒度を合わせる。
対象キャラクターは[性別・顔立ち・髪型・髪色]。既存の[配色・武器・衣装・装備]を維持する。聖戦士の赤髪や十字模様などをコピーしない。
全身、武器、マント、髪と装飾の先まで収め、四辺に透明な余白を残す。人物を小さくして収めない。文字、枠、台座、背景、別キャラクター、不要な破片を入れない。
[R2以降：参照2の確認済み対象R1の顔・髪・人体・ポーズ・位置を維持し、今回のランクの差分である装備と装飾だけを次のように強化する：具体的な差分。]
```

## 比較スクリプト

ローカルサーバーを起動してから実行する。初期の既存絵の確認では `--require-photos` を外せる。R1をゲームへ取り込む前の承認用比較は、原画から一時的な比較画像を作り、承認前に出荷画像を上書きしない。

```bash
python3 -m http.server 8000
# 別の端末で実行（【職業ID】と職業名を置き換える）
python3 tools/review-job-art.py 【職業ID】 --label 【職業名】 --ranks 1 --output docs/art/【職業ID】/existing-review
# 完成5枚のゲーム内表示の確認
python3 tools/review-job-art.py 【職業ID】 --label 【職業名】 --require-photos --output docs/art/【職業ID】/final-review
```

Pillow・NumPyは取り込み、PlaywrightとChromiumは実描画比較に必要。比較スクリプトは出荷画像やゲーム設定を書き換えない。数値・読込・描画の検査を補助するもので、粒度・顔立ち・欠け・装備の成長は目視確認する。
