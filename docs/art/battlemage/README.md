# 魔闘士（battlemage）R1〜R5

聖戦士（crusader）を共通基準とし、ユーザー承認済みR1を各ランクの直接参照として独立生成。

## 維持する特徴

若い男性、銀白色の乱れた髪、紫の瞳、袖なしの黒紫の衣装、赤紫の腰布、露出した腕と脚、黒と青銅の拳甲・ブーツ、数珠、紫の法力。片拳を顔の横へ上げた構えを維持する。

## 装備の成長

- R1 闘僧：基本の拳甲と腰布、片拳の小さな法力。
- R2 魔闘士：拳甲の重ね板・刻印・宝石、胸元の数珠、腰の金具。
- R3 闘法士：軽装の角形拳甲と短い腰布、中央の細長い札布、両手首を囲む幾何学模様の法力帯。
- R4 大魔闘士：大型の重ね板拳甲と肘当て、肩・腹・膝・すねの重装備、肩から伸びる幅広の短いマント。
- R5 闘神：大型の金と黒の水晶拳甲、金の肩飾り、銀紫の裏地が見える長い法衣、太い数珠と胸の紫水晶、浮遊する法印を結ぶ紫白の法力。

原画は `battlemage-r1-final.png`〜`battlemage-r5-final.png`。R1の承認比較は `r1-comparison.png`。取り込み設定は `import-settings.json`、実描画比較は `final-review.png`。

R3〜R5はユーザー指定により、装備の輪郭と布の長さで大きな差をつけた案へ更新。更新前の3枚と比較・測定記録は `previous/` に保存。

取り込みは `tools/jobimg.py` の共通枠90×92・頭頂9を使用する。原画を機械的にドット化・減色しない。

## 検証

`tools/review-job-art.py` により全身6枚・顔24枚の描画とゲーム起動を確認。各ランクの新WebPが実際に選択されることを確認した。

承認済みR1を維持しており、聖戦士との頭の高さには約1〜2ドットの差がある。ランク間にも最大約0.9ドットの差があるため、`--require-photos` の座標完全一致・0.3ドット以内の検査は未達。設定値だけを基準に寄せる補正は行っていない。原画の実測値は `import-settings.json` に保存する。
