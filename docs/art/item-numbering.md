# アイテムの制作番号

全アイテムに1から始まる固定の制作番号を付ける。セーブや図鑑で使う文字列の `id` は変えない。
正本は `src/itemnumbers.js` の `NUMBERED_ITEM_IDS`。配列の位置 + 1 が制作番号で、基本品 (`src/items.js`) と追加カタログ (`src/catalog/index.js`) の各雛形には `number` として付く。
番号は品の種類を表し、同じ品を複数持っていても番号を分けない。ゲーム画面への番号表示は行わない。

## 固定する規則

- 初回は基本品の定義順、続いてカタログの統合順で採番した。ドロップ対象外・既存WebPのある品も含む。
- 既存行の並べ替え・途中への挿入・削除・番号の再利用はしない。
- 新しい品は末尾へ追加する。他セッションの追加が先にmainへ入った場合はmainを取り込んでから追加し直す。
- アイテムを追加・改名した時は `node tools/itemart/numbers.mjs --update` で台帳を更新し、続けて引数なしで検査する。

## 100点ずつの制作分担

`docs/art/item-number-ledger.csv` に制作番号・100点単位の担当範囲・既存ID・名前・部位・レア度・説明・既存WebPのパスを収録する。
初回は1〜2,201の全2,201点。100点ずつの22組と、最後の2,201番だけの1組に分かれる。
担当範囲はCSVの「担当範囲」列を参照する。

```bash
node tools/itemart/numbers.mjs          # 全品の採番・台帳を検査
node tools/itemart/numbers.mjs 1 100    # 制作番号1〜100の既存IDと名前を表示
node tools/itemart/numbers.mjs 101 200  # 次の担当
```

各セッションには「制作台帳の番号1〜100を担当。既存WebPのある品は制作済みとして確認し、未制作の品を共通の見本・制作指示書に従って描く」と指示する。
画像名は `<既存ID>.webp` とし、原画と確認資料はバッチ専用の `docs/art/` 以下へ置く。
番号からアイテムを毎回並べ直して選ばず、この固定台帳で担当を決める。
