# 黒水の取水口の魔物

森の小屋の3体（ほこりゴキブリ・枯葉ムカデ・森の小蜂）の原画を直接参照し、暗い輪郭、段のある細かな筆致、左上の光、青灰色の影、控えめな土色をそろえた透過原画。図鑑の説明・特徴と `src/dungeons/monlore.js` の伝承を確認して制作した。

`w04` の通常敵9種と強敵1種を新規制作。女王の召喚先は通常敵の吸血大ヒルなので共用する。宝箱のミミックは既存のWebPを継続して使う。この迷宮には主がおらず、第2層には金属の魔物・マスターミミックは出ない。共通の出来事で他所から現れる魔物は、各IDの既存の絵を使う。

原画は [master-a.png](master-a.png) と [master-b.png](master-b.png)。出荷物は `art/monsters/<ID>.webp` の透過ロスレスWebP 10枚、合計約2.6MB、長辺512px以内。能力・技・伝承・出現表・セーブ形式は変更しない。同じIDを使う他の迷宮にも同じ絵を表示する。既存の `photo` 描画を利用し、取得失敗・寸法不一致・4秒の待ち時間超過では従来のドット絵に戻る。仕様変更がないため酒場の心得は変更していない。

## 再生成と確認

```sh
python3 tools/crypt/build-blackwater-enemies.py
python3 -m http.server 8000
node tools/crypt/verify-blackwater-enemies.cjs
```

変換にはPillow・NumPy・SciPyが必要。A面は連結した輪郭で切り分け、触角・霧の尾・鎌が格子をまたいでも欠けないようにする。離れた粉と半透明の縁は近い本体へ割り当て、RGBAを保持する。B面は2×2の枠で切り出す。輪郭へ余白を付けて縮小し、ロスレスWebPに保存する。登録寸法は `src/monsterphotos.js`、配信登録は `sw.js` の `ASSETS`。

保存なしのテストモードで次を確認済み。

- 出現表・強敵・召喚先・ミミックの登録に漏れがない。
- 全11種の原画と戦闘画像が空でなく、能力等に変更がない。
- 11種すべての画像取得を失敗させても旧絵で起動でき、ブラウザ例外がない。
- 携帯幅で図鑑・盤面・戦闘の絵を表示できる。
- JavaScript構文、SW登録、304体の伝承、物語画像の登録整合性を確認。
