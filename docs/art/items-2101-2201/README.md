# アイテム制作番号2101〜2201

固定制作番号2101〜2201の101点を、図鑑の名称・説明を参考に制作した。
`items.json` は番号・既存ID・名称・説明・部位の対応表。
既存の文字列ID・性能・入手条件は維持する。

画風の基準は `docs/art/prologue-enemies/preview.png` 上段のほこりゴキブリ・枯葉ムカデ・森の小蜂。
暗い輪郭、左上の光、深い影、控えめな色、細かなドットの質感を参照した。
恩寵・天恵の装備は古びた銀・象牙・金、終焉の装備は黒い鋼・暗紫、万象の装備は古金・銀と宝石で表現。
刀・太刀・大剣の長さ、鎖・板金・竜革の材質、祈祷書・水晶・魔晶の形を描き分けた。

原画は20点ごとの `master-2101-2120.png` など5枚と、単品の `master-2201-2201.png`。
通常の原画は5列×4行。2181〜2200だけは上から5・6・6・3点。
いずれも左から右、上から下の番号順。本体の連結成分から切り出して、
離れた制作ラベル・粒子を除き、透明な余白を付けて384×384のWebPへ変換する。
出荷先は `art/items/<既存ID>.webp`。原画と確認資料は公開対象外。

```sh
python3 tools/itemart/build-2101-2201.py
node tools/itemart/numbers.mjs --update
node tools/itemart/numbers.mjs
python3 -m http.server 8000
node tools/itemart/verify-2101-2201.cjs
```

`src/itemphotos.js` の共通描画口へ101点を登録し、図鑑・袋・装備・商会へ表示する。
未鑑定の装備には既存の伏せ絵を優先し、取得失敗・寸法不一致・時間切れでは既存の絵に戻す。
`sw.js` のASSETSへ全101点を登録。キャッシュ名は変更しない。

確認資料は番号順の `preview.jpg`、共通描画口の `game-preview.png`、
スマートフォン幅での `codex-*.png`。ブラウザ検証は全101点の原画選択・
未鑑定の伏せ絵・取得失敗・寸法不一致・時間切れでの代替表示と、対象外の原画不変を確認する。
酒場の話の変更はない（画像の追加のみ）。
