# 第十三章「溶鉄炉」の出撃情景

既存の `src/backdrops.js` の半解像度ラスタ・ベイヤー減色・灯火・粒子・霧を使った専用ドット絵。480×320のCanvasを240×160で焼き込み、補間せず拡大する。時刻から描画し、ゲームの乱数・セーブには触れない。

| 迷宮 | 絵と動き |
| --- | --- |
| w50 鉄くずの搬入路 | 鉄くず、奥へ続く軌道、鎖につられて下る荷箱、炉火と火の粉 |
| w51 千型の鋳造場 | 腕・脚・胸の空の鋳型、刻印、鉄の流路、熱の脈動 |
| w52 焼き入れの水路 | 段々の水槽、熱した器、水面の波、蒸気、揺れる交代の鐘 |
| w53 休まぬ大炉 | 格子越しの大炉、送風器、鉄板の注文の束、流れる鉄、炉火の脈動 |
| ws28 継ぎ手の置き場 | 寸法の合わない継ぎ手の棚、作業台、冷たい光と漂うほこり |
| ws29 鐘のない休憩所 | 空の寝床、湯飲みと食卓、鐘のない留め具、残る灯のゆらぎ |

出撃シートではこの6迷宮だけ専用Canvasへ切り替える。約15fpsで更新し、非表示・閉じる・迷宮切替で描画を止める。`prefers-reduced-motion` では時刻を固定し、表示中の設定変更にも追従する。他章の原画表示と戦闘背景は従来どおり。

確認: localhost:8000を起動して `python3 tools/chapter13/vistas-browser-check.py`。6景の違い・全景の時刻変化・同時刻の再現性・静止設定とその切替・携帯幅の実出撃シート・他章の表示を検査する。`review.png` は全景、`departure-phone.png` は携帯幅の実画面。酒場の心得: `t_forge_vista`。
