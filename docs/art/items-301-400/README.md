# 制作番号301〜400のアイテム原画

固定台帳の301〜400に対応する100点。文字列ID・名称・説明・性能・入手条件は維持。
森の小屋のほこりゴキブリ・枯葉ムカデ・森の小蜂の原画を直接参照し、左上からの光、深い影、控えめな色、細かなドットの質感を合わせる。各品の図鑑の素材・形・傷み・魔法の意匠を描き分ける。

`items.json` が制作番号・既存ID・名称・説明の対応表。
原画 `master-301-320.png` 〜 `master-381-400.png` は5列×4行、左から右、上から下の順。
本体と小部品を分離して384×384透過WebPへ変換し、`art/items/<既存ID>.webp` を出荷する。
原画・一覧・画面確認は公開対象外。
323番は指先の割れが明確な独立原画 `correction-323.png` を優先する。修正だけの再変換には `--corrections-only` を付ける。

```sh
python3 tools/itemart/build-301-400.py
node tools/itemart/numbers.mjs --update
node tools/itemart/numbers.mjs
python3 -m http.server 8000
node tools/itemart/verify-301-400.cjs
```

既存の共通描画口で図鑑・所持品・装備・商会へ反映する。未鑑定装備の伏せ絵を優先し、取得失敗・寸法不一致・4秒の時間切れには従来の固有ドット絵を表示する。
絵の追加のみのため酒場の心得の変更は不要。

確認結果: 100点すべて384×384・背景透過・端に余白あり・画像の重複なし。
出荷画像の合計は約3.16 MiB。SWのASSETS全件実在と `dos-dev` の維持も確認。
制作台帳の番号・ID・名前・説明は現行データと一致する。
実ブラウザの通常表示では100点を描画し、未鑑定100点の伏せ絵を維持。
取得失敗・寸法不一致・時間切れでも100点の代替表示が通過した。
既存登録分を含む読み込み結果も同時に検査する。
`preview.jpg` は最終WebPの番号順一覧、`game-preview.png` は共通描画口の100点、
`codex-*.png` はスマホ幅の図鑑表示。
