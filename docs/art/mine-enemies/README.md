# 鎖の垂れる坑口の魔物

森の古屋の3体を画風の基準に、図鑑の説明と `src/dungeons/monlore.js` の伝承を参照。左上の光、暗い輪郭、控えめな土色を揃えた透過WebPを15枚追加。

通常敵12種（坑火の精・鎖つなぎの罪人・粉塵の亡霊・坑掘りのコボルド・坑道の吸血蝙蝠・坑木喰いの白アリ・岩喰いの大蟲・坑道掘りの獣・ガーゴイル・水晶喰い蟲・トロール・鋼蜘蛛）、鎖鞭の坑監、坑道の主、銀業が対象。主と坑監の召喚先は通常敵と共通。ミミックは既存WebPを共用し、この層に出ないマスターミミック・金業・銀業の王は対象外。

罪人の足かせとつるはし、砕けた魂の粉塵、盗んだ財布、水晶内の灯、トロールの肩の三つの火傷、機械蜘蛛の鋼糸、坑監の鉄のむち、岩の内側の闇、銀の人業の関節を描き分けた。

原画は sheet-a/b/c.png と蝙蝠の単独修正版 bat.png。`python3 tools/mine/build-enemies.py` で輪郭を切り出し、最大512pxと周囲4pxの透過余白を付け、ロスレスWebPへ変換する。蝙蝠は隣の素材の混入を避けて単独原画を使う。原画は公開対象外。ゲーム用は `art/monsters/`、登録は `src/monsterphotos.js` と `sw.js`。同じIDの敵は別の迷宮でも共用。

戦闘・盤面・図鑑で既存のphoto描画口を使用。能力・技・伝承・出現条件・セーブ形式は変更しない。新機能やルール変更はないため酒場の心得の変更なし。

## 確認

ローカルHTTPサーバーを8000番で起動し、`node tools/mine/verify-enemies.cjs` を実行。対象全15体の読み込み、非空の戦闘画像、通常敵・強敵・主・召喚先・共通敵の登録網羅、既存データの不変、画像取得失敗時の旧絵への復帰、ブラウザ例外なしを確認済み。
