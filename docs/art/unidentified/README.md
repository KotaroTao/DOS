# 未鑑定品の伏せ絵

武器8種（長剣・短剣・刀・斧・槌・槍・弓・杖）と盾・鎧・頭・小手・足・装飾の全14種。青紫の布と金の「？」で未鑑定を表し、品ID・品質・レア度・属性の違いを表示しない。

原画は `master.png`（画像生成による4列×4行、末尾2枠は空欄）。各384×256の枠を切り出し、上下64pxの透明余白を付け、384×384のWebP（品質88）を `art/unidentified/<ジャンル>.webp` に保存した。`preview.png` は実ブラウザの描画見本。

起動時に読み込み、取得失敗・寸法不一致・4秒の時間切れは従来のドット伏せ絵へ戻す。鑑定後の品の絵は従来どおり。

`node tools/itemart/verify-unidentified.cjs`（localhost:8000 が必要）で実ブラウザで全14種のWebP表示・代替表示・品IDとレア度によらない共通表示を確認。既存の制作番号1〜100の検証も未鑑定品の判定を共通伏せ絵との一致で確認するよう更新した。
