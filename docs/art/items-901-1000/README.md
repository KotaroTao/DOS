# アイテム制作番号901〜1000

固定制作台帳の901〜1000番を、森の小屋の敵3体（ほこりゴキブリ・枯葉ムカデ・森の小蜂）の原画を直接参照して制作。左上の光、深い影、控えめな色、細かなドットの質感を合わせ、図鑑に記された素材・傷み・固有の意匠を各品へ反映した。

`items.json` は制作番号・既存ID・名前・図鑑説明・部位の対応表。原画は `master-901-920.png` から `master-981-1000.png` までの5枚。各5列×4行、左から右・上から下の順。つながった本体を基準に切り出し、刃先・装飾・透過を保って中央へ配置した。948番は木彫りの形、994番は黄金鋏の片刃を明確にするため、同名IDの個別PNGを描き直し原画として優先する。出荷画像は `art/items/<既存ID>.webp` の100点（384×384）。

```sh
python3 tools/itemart/build-901-1000.py
python3 -m http.server 8000
node tools/itemart/verify-901-1000.cjs
```

`src/itemphotos.js` と共通の描画差し替え口に登録し、図鑑・袋・装備・商会に表示する。未鑑定時は従来の伏せ絵、取得失敗・寸法不一致・時間切れ時は既存の固有ドット絵を使う。`sw.js` のASSETSに全100点を登録。品の定義・性能・説明・固定番号、CACHEのdos-devは維持した。画像追加のため酒場の心得の変更はない。
