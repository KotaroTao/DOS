# 魔盗賊 R1〜R5

`arcthief-r1.png` はユーザーが承認した顔サイズと頭身を基準に、髪型変更の指示を反映した原画。R2〜R5も同じ髪型に揃え、それぞれ独立した透明背景画像として制作した。`arcthief-r1-before-proportion-fix.png` は不採用の旧案で、取り込みには使わない。

髪型は青緑がかった黒髪の短いポニーテール、耳の上の編み込み、紫のリボン。死霊術師の肩までの髪型と区別する。髪型の変更は頭部周辺に限定し、装備・武器・脚などの画素を維持した。

全ランクで軽い革装備と布の衣装を維持し、重装甲にはしない。R2で掌の魔晶、R3で浮遊短剣、R4で大きな魔晶と3本の浮遊短剣、R5で複数の魔晶・多数の浮遊短剣・魔力の輪・背後の魔法陣を追加し、魔力の成長を明確にする。R1は承認済み原画を維持し、R2〜R5の描画はR1のドット粒度を参照した。顔と頭身は承認済みR1を基準に、人物を縮小せず取り込み倍率を調整する。

ゲーム用画像は `art/jobs/arcthief_1.webp` 〜 `arcthief_5.webp`。旧 `JOB_IMAGES.arcthief` を除去し、`JOB_PHOTOS.arcthief` を使う。顔アイコンは測定した `head` で切り出し、旧 `BUST_FIT.arcthief` は不要。

取り込みは `tools/jobimg.py`。原画を一時的に白背景へ合成して渡す（原画の透明背景は保存）。`--per-dot` は `14.46,14.47,14.54,14.57,13.61`、`--head` は順に `480,606,87,395`、`480,606,87,395`、`480,606,86,395`、`480,606,85,395`、`367,493,128,405`。切り抜き上端が頭頂より下の場合は透明余白で補い、顔の配置を維持する。R5の魔法と布は人物の大きさを変えず内側へ収めた。取り込み時の横幅制限は顔中心から左右46升目とし、共通96×90枠に収まることを確認する。人物の頭頂〜足裏は死霊術師R1と同じ約83升目。R5は頭頂より上の魔法エフェクトも含むため、画像全体の高さとは区別する。

確認用画像は `../arcthief-preview.png`（全ランクの全身・胸像）、`comparison.png`（死霊術師R1と魔盗賊R1〜R5を共通表示枠に配置した比較）。
