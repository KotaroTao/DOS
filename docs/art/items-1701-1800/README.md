# アイテム制作番号1701〜1800

固定台帳 `src/itemnumbers.js` と `docs/art/item-number-ledger.csv` の制作番号1701〜1800を担当。
既存ID・名称・説明・性能・入手条件は維持。`items.json` は制作時の番号・ID・図鑑の説明の対応表。

森の古屋のほこりゴキブリ・枯葉ムカデ・森の小蜂の原画3枚を直接参照し、
左上の光・深い影・控えめな色・細かなドットの質感を基準に描き下ろした。
図鑑の神話銀、淡紅の宝玉布、光竜革、天帝の金、聖痕銀、象牙色の神授布、
闇竜革、神血、聖遺鋼などの素材と意匠を描き分ける。
両手武器の長い柄・刀身、靴と手袋の対も含め、品全体を収める。

原画は `master-1701-1720.png` から `master-1781-1800.png` の5枚。
各5列×4行、左から右・上から下の順。1升に1点（靴・手袋は1組）を配置。
透明背景の原画を連結した本体と升目内の重心から分離し、境界をまたぐ刃先や飾りも含めて
透明余白を除いて中央へ配置、384×384 WebPへ変換。
原画・制作記録・確認用画像は公開対象外のこのフォルダ、出荷物は `art/items/<既存ID>.webp` の100点。

```sh
python3 tools/itemart/build-1701-1800.py
node tools/itemart/numbers.mjs --update
node tools/itemart/numbers.mjs
python3 -m http.server 8000
node tools/itemart/verify-1701-1800.cjs
```

共通の `src/itemphotos.js` と `sw.js` に登録し、図鑑・装備・袋・商会で使用する。
未鑑定時の伏せ絵と読み込み失敗時の既存ドット絵への代替表示は共通処理を使う。
`preview.jpg` は番号順100点、`game-preview.png` はゲームの共通描画口の100点。
`codex-*.png` は携帯幅390pxでの図鑑確認。
今回は既存アイテムの絵の追加だけで機能・仕様・物語の変更はなく、酒場の心得の変更はない。
