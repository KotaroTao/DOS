# 制作番号1401〜1500のアイテム原画

固定台帳の1401〜1500に対応する100点。既存の文字列ID・名称・説明・性能・入手条件は維持する。
森の古屋のほこりゴキブリ・枯葉ムカデ・森の小蜂の原画を直接参照し、左上からの光、深い影、控えめな色、細かなドットの質感を合わせる。各品の図鑑にある素材・形・魔法の意匠を描き分ける。

`items.json` は制作番号・既存ID・名称・説明の対応表。
原画 `master-1401-1420.png` 〜 `master-1481-1500.png` は5列×4行、左から右・上から下の順。
1461〜1480の原画は竜将の脚甲が欠け、3行目が手袋5点・4行目が4点の配置となったため、変換時に対応を補正する。1471番は専用原画 `correction-1471.png` を使用する。
原画から本体と小部品を分離し、384×384の透過WebPへ変換する。
出荷画像は `art/items/<既存ID>.webp`。原画・確認資料は公開対象外。

```sh
python3 tools/itemart/build-1401-1500.py
node tools/itemart/numbers.mjs --update
node tools/itemart/numbers.mjs
python3 -m http.server 8000
node tools/itemart/verify-1401-1500.cjs
```

`src/itemphotos.js` の共通描画口で図鑑・袋・装備・商会へ反映する。
未鑑定装備は伏せ絵を優先し、取得失敗・寸法不一致・4秒の時間切れは従来の固有ドット絵で表示する。
絵の追加のみのため酒場の心得の変更は不要。

`preview.jpg` は最終WebPの番号順一覧、`game-preview.png` は実ブラウザの共通描画口の100点、`codex-*.png` はスマホ幅の図鑑表示。

確認結果: 100点すべて384×384 WebP・背景透過・端に余白あり・画像の重複なし。出荷画像の合計2.63 MiB。固定台帳の番号・ID・名称・説明は一致。SWのASSETS全2,575件の実在と `dos-dev` の維持を確認した。
実ブラウザでは通常表示100点・未鑑定100点を確認。取得失敗・寸法不一致・4秒の時間切れの各条件でも100点すべての代替表示が通過した。
