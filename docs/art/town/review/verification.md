# 街の施設3枚の確認記録

酒場はユーザーの承認済み。承認後に宿屋「白狼」と赤い魂の祠を追加した。mainへのマージは別途指示待ち。

- 原画はすべて1536×1024のPNG。docs/art/town/に保存。
- 参照画像は road-to-roadal.png、irene-soul-lamp.png の順で指定。
- 主題の吊り灯・寝台の毛皮と狼の頭・紅い魂は中央に置き、下部を暗く抑えた。文字・看板の字・署名なし。
- 酒場の客は頭巾2人と手前の後ろ姿1人。見える手に余分な指・腕は見当たらない。隠れた指の数は断定できない。宿屋・祠には人を描いていない。
- 宿屋の白狼は寝台に掛けた毛皮。頭は蝋燭の方を向く。小窓、石床、扉の三本の爪痕を確認。
- 祠の紅い魂は鉄の環と左・右・下の三本の帯に抱かれている。両肩の鎖、段の台座、赤い蝋燭2本、骨の供物を確認。

## ゲーム画面とビルド

- python3 tools/townart/build.py と --check 成功。生成された townkeyart.js と sw.js の構文チェック成功。
- 施設の原画からWebPを生成。施設表示のゲームコードは変更せず、CACHEも維持。人物表示の追加変更は下記。
- python3 -m http.server 8000、指定URL、Chromiumで390×844・744×1000を撮影。札全体が見えるよう街の中身をスクロール。
- 両サイズで主題が欠けず、札の名前を読める。390pxでは細部が小さくなるが、狼の頭と紅い魂を識別できる。
- 3枚ともcanvasは tw-vig-hd、1200×750。900ms間隔のフレーム比較で各光源中心の明るさの変化を確認（animation-check.json）。絵の光源と同じ座標で揺らぎ、絵そのものは動かない。
- ブラウザのpageerrorなし。
- 酒場ページの見出しは現行mainでは施設名と店主の肖像。原画の情景は表示されない。READMEの説明との違いを記録し、ゲームコードは変更していない。
- 祠ページの魂の所持数の背景と、宿屋のシートに新しい原画が表示されることを確認。
- 広告・購入・宿泊の操作は行っていない。

## 人物アイコンの追加

ユーザーの追加依頼と、3人の表示に必要な最小限のゲームコード変更の許可を受けて制作・実装した。

- 原画は `keepers/barkeep.png`・`innkeeper.png`・`maiden.png`（各1254×1254）。既存の人物の特徴を引き継いだ肩から上の肖像。ドットの質感・文字・署名なし。手は描いていない。
- 出荷は640×640のWebP。`build.py`で人物の変換と台帳・SW登録も生成する。
- `townart.js`の人物表示だけを追加。480×560のcanvasへ中央6:7で切り取り、滑らかに表示。胸像は静止画、施設の明かりは従来どおり揺らぐ。
- 390×844と744×1000で酒場・宿屋・祠のページを撮影し、人物の特徴・頭や顔の切り取り・名前と台詞の読みやすさを確認。3人の大きい人物シートも両サイズで撮影した。
- 小さいささやきの行でも480×560のcanvasと`image-rendering: auto`を確認。
- 人物画像のリクエストを意図的に失敗させ、3人とも従来の48×56のドット胸像へ戻ることを確認。
- 対象外の商会主と宰相が48×56のドット胸像のままであることを確認。人物のID・名前・台詞は変えていない。
- ブラウザpageerrorなし。検証結果は `keeper-check.json`。`build.py --check`と変更JSの構文チェックも成功。
