# 酒場「沈まぬ灯」確認記録

今回の制作は酒場1枚のみ。宿屋・祠は承認後に制作する。

- 原画: 1536×1024、PNG。参照画像は road-to-roadal.png、irene-soul-lamp.png の順で指定。
- 主役の吊り灯は横幅の中央40%内。下部は暗く抑え、文字・看板の字・署名なし。
- 客は頭巾の2人と手前の後ろ姿1人。見える手に余分な指・腕は見当たらない。隠れた指は数を断定できない。
- 明かりは原画上で目視測定。吊り灯 (773,220)、炉 (1437,536)、卓の蝋燭 (833,613)、奥の灯 (1092,280)、炉上の蝋燭 (1387,239)。points.json は各座標を1536・1024で割った値。
- build.py と --check 成功。生成された townkeyart.js と sw.js の構文チェック成功。
- python3 -m http.server 8000、指定URL、Chromiumで390×844・744×1000を撮影。札全体が見えるよう街の中身をスクロール。
- 両サイズで吊り灯の本体が切れず、札の名前を読める。宿屋・祠は既存のドット絵。
- 酒場のcanvasは tw-vig-hd、1200×750。700ms間隔の2フレームで光の変化を確認。差分の範囲は (495,54)〜(1200,563)。原画の光源と重なる位置にあり、人物や卓そのものは動かない。
- 酒場ページの見出しは現行mainでは施設名と店主の肖像。原画の情景は表示されない。READMEの説明との違いを記録し、ゲームコードは変更していない。
- 祠ページも両サイズで撮影。広告・購入の操作は行っていない。
