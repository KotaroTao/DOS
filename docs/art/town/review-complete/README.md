## 確認結果

- 人物の顔と王冠・帽子が枠から欠けず、人物名・札の文字が読める。画像は滑らかな描画。
- 門の4状態（闇・紫の光・熾火・鎖）が区別できる。紋章の透明背景をWebPでも維持。
- 人物の胸像に手は描いていない。工房・保管庫・隊の器の腕は2本・脚は2本。工房の人形は成人の頭身。
- 原画に読める文字・署名・看板の字はない。
- 情景の光は原画の光源に合わせた割合の位置に重なる。描き下ろし背景のcanvasは1200×750。時間を進めて、追加の12情景の光が変化することを確認。
- WebP全29枚がHTTP200で取得でき、ブラウザで復号できる。
- 読み込みを意図的に止め、王・施設の人物・紋章・情景がそれぞれ42×42・48×56・20×24・120×75の従来canvasに戻ることを確認。
- ブラウザの例外0件。変更したJS、生成JS、SWの構文検査、`build.py --check`、`git diff --check` が通る。
