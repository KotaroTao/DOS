# 戦士 R1〜R5 の原画

## 聖戦士基準の採用版（2026-10-08）

職業IDは `fighter`。`fighter-r1-crusader-final.png`〜`fighter-r5-crusader-final.png` が今回の独立生成原画。R1はユーザー承認済みの `fighter-r1-crusader-draft.png` と同じ画像。

聖戦士 `crusader` R1を人体・顔・描画の参考にし、戦士固有の男性・茶髪・赤い鉢巻と首巻き・茶色の革装備・大剣を維持した。成長差はR2で銀の腕と膝の防具、R3で金縁の赤い上着、R4で装甲の金装飾と腰の鎖、R5で赤い宝石・金の刺繍・装飾大剣。R4・R5の脚とマントの収まり、R5の剣先は生成ツールで部分修正した。

原画の顔の左右・主な髪の頭頂・顎・足裏を測定し、`import-settings.json` に保存。共通枠90×92・頭頂9で `tools/jobimg.py` を使用する。減色・機械的なドット化は行わない。頭頂と顎は手動測定であり、聖戦士の原画座標の流用ではない。

承認済みR1の輪郭を優先した結果、取り込み後の頭の高さは20.43〜20.79ドット（聖戦士R1は21.93）、顔の中心は `[45,19]`（基準は `[45,20]`）。全身の頭頂は9で共通。数値の完全一致はしていないため、確認スクリプトの `--require-photos` に含まれる基準座標一致の条件を満たすとは扱わない。画像選択は実際の読み込み先を別途検証し、顔と輪郭は `final-review.png` で確認した。

確認画像は `r1-crusader-comparison.png`（承認時）、`final-review.png`（実際の `jobSprite` / `jobBust` による全身・56/36/26pxの顔）。ゲーム用ファイルは既存の `art/jobs/fighter_1.webp`〜`fighter_5.webp` を置換し、`sw.js` の既存登録を使う。
