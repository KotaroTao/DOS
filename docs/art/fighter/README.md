# 戦士 R1〜R5 の原画

`fighter-r1.png` 〜 `fighter-r5.png` は、生成した集合絵から各ランクを独立させた原画。ゲーム用の透明背景 WebP は `art/jobs/fighter_1.webp` 〜 `fighter_5.webp`。

今後、職業のランク別イラストは最初から各ランク1枚ずつ、独立した画像として生成する（ユーザー指定）。頭身・顔のサイズ・ドット粒度は死霊術師を基準に揃え、各ランクで髪の主部上端と足裏を揃える。

再取り込みは `tools/jobimg.py` を使用する。今回の `--per-dot` は全ランク `6.8`。`--head` は順に `203,286,21,161`、`208,285,21,161`、`216,290,21,161`、`222,299,21,161`、`218,292,21,161`。確認用画像は `../fighter-preview.png`。
