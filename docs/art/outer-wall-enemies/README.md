# 亡兵の守る外郭の魔物

森の小屋の3体（`docs/art/prologue-enemies/preview.png`）を画風の基準に、図鑑の説明・伝承・能力を読み、暗い影・左上の光・さびた鉄・くすんだ布の透過原画を制作した。ゲーム用はロスレスWebP 14枚、合計約3.2MiB。

## 再生成と登録

原画は `sheet-a.png`・`sheet-b.png`・`sheet-c.png`。`python3 tools/outer-wall/build-enemies.py` で、格子を越える刀や軍旗を切らないよう連結した輪郭ごとに分け、長辺512px以下に縮小して透過余白を付ける。Pillow・NumPy・SciPyが必要。

`src/monsterphotos.js` に寸法、`sw.js` の `ASSETS` にWebPを登録。既存の共通描画口で戦闘・盤面・図鑑へ反映する。能力・技・伝承・出現条件・セーブ形式は変更せず、取得失敗時は従来のドット絵を残す。新機能やルールの変更はないため、酒場の話の更新はない。

## 確認

ローカルHTTPサーバーをポート8000で起動し、`node tools/outer-wall/verify-enemies.cjs` を実行する（Playwright・Chromiumが必要、`CHROMIUM_PATH`で実行ファイルを指定可能）。保存なしのテストモードを使用。

- 外郭の出現表・召喚先・「その他」の共通敵の登録に漏れがなく、16体すべてが透過原画を読み込み、戦闘画像が空でない。
- 読み込み前の定義と比較し、既存の能力・説明・文字グリッドなどが変わっていない。
- 全画像の取得失敗時にも起動し、16体の旧絵を保つ。ブラウザの例外はない。
- スマホ幅で図鑑・盤面・戦闘を目視確認。JavaScriptの構文と既存の物語画像・読み物の整合性検査を実行。
