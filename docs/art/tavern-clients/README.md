# 酒場の依頼者の肖像

掲示板の20人と固有の依頼者を合わせた52人。ダークファンタジー調の絵画的な胸像を生成し、暖かな酒場の光と暗い背景で顔を読み取りやすくした。隻眼のガルムの右目、盲目のヴェスナの白い目、ロッホスのくちばし面、ゴドーの眼帯を確認した。

最初の47人の原画は `atlas-1.png` から `atlas-3.png`。各原画は4列×4行、左から右、上から下の順。`names.json` の順に対応し、最後の1枠は未使用。名前の順序は変えず、追加する場合は末尾へ足す。ゴドーの眼帯は画像生成による修正で追加した。

`python3 tools/tavern/build-portraits.py` で原画をセルごとに切り出し、256×256のWebP（品質88）へ変換する。追加の縦長原画は頭頂を残して正方形に切り出す。出荷画像は `art/quest-clients/`、名前別台帳は `src/questportraits.js`。SWの `QUEST_PORTRAITS` ブロックも同時に登録する。原画と確認画像は公開から除外される `docs/` に置く。

`src/ui/questportrait.js` で一覧28px・固有の依頼一覧40px・詳細52px・報告112pxを滑らかに表示。掲示板の目的の印は残し、その下に顔と名前を添える。画像の読み込み失敗は従来の絵へ戻る。依頼ID・依頼者番号・セーブ形式は変更しない。

確認は `python3 tools/tavern/portrait-check.py`（localhost:8000が必要）。390×844と744×1000で全52人の読み込み、受注からフリー・固定の報告、詳細の横幅、未登録・画像失敗の代替表示、ブラウザーエラーを検査する。

## 追加の五人

`atlas-4.png` は3列×2行。上段左から老侍従エーリク・扉番のカスパル・書き写しのヨルク、下段左から雨受けのミラ・子守りのロッテ、最後の枠は未使用。`atlases.json` で原画ごとの列・行・人数を指定し、`names.json` の末尾へ追加した。既存の47人の画像番号は変えない。

依頼の本文を基準に、エーリクは王宮の侍従服と白手袋、カスパルは太い腕と穏やかな顔、ヨルクは写本とインクの指、ミラは濡れた外套と硝子瓶、ロッテは前かけと絵本で描き分けた。夜明けの町の四人は自然な人の顔をした人業として描いた。

表示の仕組みは既存のまま。心得 `t_quest_faces` の変更は不要。検査は52人の読み込みと、追加した五人それぞれの固有の報告で名前と画像の対応も確認する。
