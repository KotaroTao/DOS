# 護教官 R1〜R5

職業IDは `chaplain`。R1はユーザー確認済みの `chaplain-r1-review.png` を採用した。R2〜R5はそのR1と聖戦士の各ランクを直接参照して、各1枚の独立した透明原画として制作した。

## 職業の特徴と成長

旧表示は `existing-review.png`。司教冠、目元だけが見える覆面、薄紫と白の法衣、鉄の肩当て、鎚矛と聖典を維持した。

- R1 衛教兵: 基本の銀鎧と金縁の法衣。
- R2 護教官: 重ねた肩当て、強化した腕甲、法衣の二重縁取り、聖典の金具。
- R3 護教騎士: 金紋、胸のメダル、短い鎖、法衣と鎚矛の彫刻。
- R4 護教総監: 紫の宝石、聖遺物の胸飾り、鎧の金彫刻、儀礼用の法衣。
- R5 教皇の盾: 翼形の肩飾り、複数の胸鎖、宝石付きの鎚矛と聖典、最も豪華な金刺繍。

旧上位ランクの光の成長は銀金の装飾に置き換え、顔や装備を隠す背景効果は付けていない。R5の原画右端に接したマントの先端は部分修正した。

## 測定と取り込み

聖戦士の原画座標は流用せず、各原画の覆面の顎相当位置、頬の中心、足裏を確認した。司教冠と覆面で人体の頭頂・顎の肌が隠れるため、顎相当位置から人体の頭頂を推定した。人体の頭頂〜足裏82.9ドット、頭高21.93ドットを基準とし、冠先端は頭頂として扱わない。隠れた人体の測定値は推定であり、全身と目元の比較で併せて確認する。

原画と `import-settings.json` を保存し、次のコマンドで既存 `tools/jobimg.py` の取り込み処理を使用する。機械的なドット化や減色は行わない。

```bash
python3 docs/art/chaplain/import-art.py
python3 tools/review-job-art.py chaplain --label 護教官 --require-photos --output docs/art/chaplain/final-review
```

共通枠は90×92ドット、人体の頭頂は9ドット。`src/jobphotos.js` と `sw.js` に5ランクを登録する。`src/jobart.js` に護教官の優先データはなく、新原画は `jobSprite` と `jobBust` から選ばれる。`CACHE` は `dos-dev` を維持する。

mainへのマージは行わない。

## 確認結果

`final-review.png` と `final-review.json` に、聖戦士R1と護教官5ランクの同倍率の実表示を保存した。全身6枚、56/36/26pxと拡大表示の顔24枚について、画像の選択・読込・非空の描画、基準座標との一致、ゲーム起動時のブラウザーエラーなしを確認した。
