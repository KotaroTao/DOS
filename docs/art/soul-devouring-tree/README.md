# 魂喰らいの大樹の敵イラスト

最新mainの出現表と原画台帳を照合し、未作成の主「霧の森の主」だけを制作した。森の古屋のほこりゴキブリ・枯葉ムカデ・森の小蜂を画風の基準に、暗い輪郭、左上の光、控えめな土色・苔色、細かな段のある質感を合わせた。

図鑑の説明にある、森の意思を宿す古木、青白い呪文の輪、霧、従える絞め蔦を反映。伝承の「地の底の庭の番人」に合わせ、太い幹と広がる枝で道をふさぐ姿にした。幹の空洞から霧が流れ、枝の魔法陣と根元のとげの蔦で、通常敵の霧の古木・柳の魔女と区別する。

通常敵12種、強敵の霧の繭母・古樹の番人、召喚先、ミミック・銀業などの共通敵は既存WebPを共用する。能力・技・説明・伝承・出現条件は変更しない。新機能・ルール変更がないため酒場の心得の変更もない。

原画は [bs_forestlord.png](bs_forestlord.png)。`python3 tools/soul-devouring-tree/build-enemy.py` で最大504pxに縮小し、周囲8pxの透過余白を加えた520×520のロスレスWebPを作る。出荷先は `art/monsters/bs_forestlord.webp`、登録先は `src/monsterphotos.js` と `sw.js`。

確認画像: [図鑑](codex-mobile.png)、[戦闘](battle-mobile.png)。ブラウザーで通常敵・強敵・主・召喚先・共通敵の登録の網羅、主の非空の戦闘画像、図鑑表示、画像取得失敗時の旧絵、実行時エラーなしを確認した。
