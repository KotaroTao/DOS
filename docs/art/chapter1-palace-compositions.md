# 第一章・王宮関連6枚の描き直し

2026-10-19の最新依頼により、同じ玉座の間の背景を固定して人物を重ねる方式から、場面ごとに異なる構図の一枚絵へ変更した。本文・場面ID・解放条件は変更していない。

| 場面 | 新しい構図 | 背景の不一致を避ける工夫 |
|---|---|---|
| report_w01 | 王宮の倉庫で、作業台の人業を受け取る | 人業と支える手を中心に上から寄り、部屋の配置を出さない |
| report_w02 | 修道院へ続く地図と指し示す手 | 顔と建築を画角から外し、次の道を主題にする |
| report_w03 | 王が宰相から目をそらす | 顔・衣装・暗い布だけで沈黙を伝える |
| report_w04 | 弟子の手に残った金貨、答えを止めた王と宰相 | 肩越しの寄りで、玉座・窓・階段を画角から外す |
| minePass | 宝物庫の受け渡し場所で通行証を受け取る | 手元が主題。背景は別室の箱と布にする |
| report_w05 | 手記を膝に置き、宰相を手で制する王 | 斜め上から顔・手・手記に寄り、家具の形を出さない |

生成指示の正本は [指示書A-60〜A-65](codex-story-art-brief.md)。旧A-49〜A-59の背景固定指示は過去の制作記録で、今回の6枚には適用しない。

人物は既存の基準シートを参照。王の冠・白髪と白いひげ・赤い衣と白い毛皮、弟子の茶髪と黒地に金の外套、宰相の帽子・衣・赤い宝石の鎖を共有する。宰相の胸の秘密は描かない。`prompt.mjs` も第五章より前には胸の参照シートを渡さないようにした。
