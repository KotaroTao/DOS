# 職業イラストの共通基準

ユーザー指定: 全職業の顔の位置・サイズ、頭身、ドット粒度を死霊術師に統一する。各職業はR1〜R5の5枚を、最初から1ランク1画像として制作する。

## 基準画像

基本の体格と顔は `art/jobs/necromancer_1.webp` を基準とする。R2〜R5の死霊術師は装備や装飾の増え方の参考に使う。全ランクで同じ体格・顔サイズを維持し、装飾の大きさに合わせて人物を縮小しない。

`src/jobphotos.js` の死霊術師R1の現在の記録は、全身枠45×83升目、顔位置 `[19, 11]`、頭の範囲 `[19.07, 0, 22.125]`。頭頂からあごまで22.125升目、画像高との比は約3.75。顎先はユーザーの白線による指定を元画像の約88.5画素に換算し、旧設定21.29升目から補正した。これらは取り込み後の配置の基準であり、83は画像枠の高さ。実際の足裏・頬の幅・目の高さは基準画像の輪郭を見て合わせる。

## 確定した頭身・顎先の位置

2026-10-08、ユーザーが比較画像に引いた白線を正しい顎先として確定。以後の全職業・全ランクは、この顎先まで含めた頭の高さを基準にする。

| 項目 | ゲーム用画像の画素座標・寸法 | 升目単位 |
|---|---|---|
| 基準画像の大きさ | 180×332px | 45×83 |
| 頭の中心X | 76.28px | 19.07 |
| 頭頂Y | 0px | 0 |
| 正しい顎先Y | 約88.5px | 22.125 |
| 頭頂から顎先までの高さ | 約88.5px | 22.125 |
| 全身画像高÷頭の高さ | 332÷88.5 ≈ 3.75 | 83÷22.125 ≈ 3.75 |

顎先は顔の肌色部分の下端だけで切らず、ユーザーの白線が示す顎の下側の輪郭まで含める。旧値の85.16px（21.29升目）は浅かったため、今後の基準に戻さない。88.5pxは提示画像の表示倍率から換算した概算で、白線の位置を測定根拠とする。

約3.75頭身は全身画像高332pxを使った比率であり、透明余白を除いた解剖学的な頭身の厳密な計測値ではない。制作時はこの数値だけで判断せず、頭頂・顎先・目・足裏と頬の幅を同倍率の基準画像へ合わせる。フード・帽子の上端を頭頂、マフラーなど首元の布の下端を顎先として代用しない。隠れている位置は確認済みR1の人体の比率から揃える。

ゲームの設定は `head: [19.07, 0, 22.125]`、`face: [19, 11]`。数値の記録は `necromancer-reference.json`。白線を反映した確認画像は `brigand/brigand-r1-chin-corrected-comparison.png`。

保存解像度は既存仕様の1升目4画素。これは描かれたドットの粒度とは別なので、保存寸法だけで粒度が一致したと判断しない。基準画像と同倍率で並べて、輪郭・目・髪のドットの大きさを確認する。全身の顔位置は共通表示枠に配置した後に比較する（装備の幅で切り抜き画像内の座標は変わる）。

## 制作と確認

1. ゲーム内の既存データから、職業の色・髪・武器・衣装と各ランクの装備差を整理する。
2. 死霊術師R1を直接参照して、その職業のR1を制作する。顔の中心・頭頂・あご・足裏・頬の幅・目の位置とドット粒度を基準に合わせる。
3. 確定した職業R1と死霊術師を参照し、R2〜R5をそれぞれ独立した画像として制作する。顔と体格を固定し、装備・装飾を段階的に増やす。
4. 5枚と死霊術師を同倍率で並べ、全身と顔アイコンの両方を確認する。武器・マントの欠け、不要な残片、背景の残りも検査する。
5. 原画を保存し、`tools/jobimg.py` で透明背景WebPと顔位置の設定を更新する。背景除去・切り抜き・縮尺調整を行い、原画を機械的にドット化し直さない。`--per-dot` と `--head` は原画の寸法から測定する。

生成への指示だけで一致を保証せず、顔・体格・ドット粒度がずれた画像は取り込み前に修正する。
