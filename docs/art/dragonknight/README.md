# 竜騎士の職業画像

職業IDは `dragonknight`。下準備は `origin/codex/job-art-preparation` から取り込んだ。

## 既存の特徴と成長

淡い金髪の女性、緑の目、右側の長いポニーテール、濃緑のリボン。
金縁の竜鱗鎧、白布、濃緑の翼マント、長槍を維持する。

- R1（竜の従士）：控えめな竜角、簡素な鎧と短いマント。
- R2（竜騎士）：重ねた肩鎧、竜の紋章、槍の装飾を追加。
- R3（飛竜騎士）：翼を思わせる肩鎧と広がる翼マント。
- R4（竜騎士長）：厚い竜鱗鎧、大きな翼マントと軍旗風の布。
- R5（竜帝）：竜角の冠、宝石、幾重もの翼飾り、最も豪華な槍とマント。

## R1の採用

`dragonknight-r1-final.png` は、槍の位置についてユーザーが「完全に槍の位置が合っています」と指定した画像。
生成元は `exec-0a55a8c4-8430-4c0c-b339-f18c47199adf.png`。
後に生成した別案を採用版と取り違えない。
R2以降はこのR1を直接参照し、顔・人体・ポーズ・槍の軸を固定して装備を強化する。
共通の人体基準と装備成長の参照は聖戦士 `crusader`。赤髪や十字装束は移植しない。

## 取り込みと検証

`import-settings.json` に各原画の測定値を記録。
`tools/jobimg.py` の `--frame 90,92 --frame-top 9 --per-dot 14.5` と各画像の `--head` を使用した。
ドット化・減色はせず、画像の透過・縮小と位置合わせのみ行った。
旧 `JOB_IMAGES.dragonknight` を外し、`JOB_PHOTOS.dragonknight` の5枚を選択する。
`sw.js` の画像一覧を追加し、`CACHE = "dos-dev"` を維持した。

`final-review.png` は `tools/review-job-art.py` によるChromiumの実描画。
聖戦士R1と竜騎士5枚を同倍率で並べ、56/36/26pxの顔と拡大胸像を確認した。
ローカルHTTPサーバーの代わりにPlaywrightのリクエスト差し替えで、
`sw.js` に列挙された出荷ファイルだけをブラウザへ渡した。リポジトリを公開していない。
ゲーム起動・30枚の非空Canvas・ブラウザエラーなしを確認。
全ランクの画像選択、顔位置一致、竜騎士5ランクの頭位置一致を別途検査した。
承認R1の顎は聖戦士より約0.9ドット上のため、基準との頭座標一致を要求する
`--require-photos` は使っていない。測定値を基準へ書き換えて差を隠していない。
5枚のWebPの四辺は完全透明で、取り込み時の枠外切り取りはない。
変更したJavaScriptの構文検査も通った。

作業ブランチは `codex/dragonknight-job-art`。
