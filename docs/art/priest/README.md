# 僧侶 R1〜R5 制作

職業IDは `priest`。`src/souls.js` の職業定義と既存 `src/jobart.js` の全5ランクを確認した。
制作基準は聖戦士 `crusader`。下準備はPR #587を含む最新main（32e5644）から取り込み済み。
作業ブランチは `codex/priest-job-art`。R1はユーザー確認済み。各ランクを独立生成してR1〜R5をゲーム画像へ取り込んだ。

## 既存の外見と成長

灰茶色の短髪、穏やかな少年風の顔立ち。黄土色〜象牙色の頭巾、濃茶のローブ、茶革のベルトと靴、淡い肩布、金色の聖印。武器は聖印をあしらったメイス。

- R1 見習い僧侶：無地の黄土色の頭巾、簡素な濃茶ローブ、肩布、小さなメイス。
- R2 僧侶：頭巾と肩布の金縁、淡い前垂れ、胸の聖印。
- R3 神官：聖印入りの頭巾、肩・腕の装備、長い前垂れ、メイスの装飾を強化。
- R4 聖職者：高い飾り付き頭巾、重ねた肩装備、赤茶色の首布、飾り帯と長い衣装。
- R5 聖者：最も豪華な頭巾・肩・胸、金縁の長いマント、赤い装飾と帯、豪華なメイス。

R1は聖戦士の原画と既存僧侶R1を直接参照して独立生成する。聖戦士の赤髪・女性の顔・鎧を僧侶へ移植しない。

## R1確認案

原画は `priest-r1-draft.png`、同倍率の全身・56/36/26px顔アイコン比較は `r1-comparison.png`。
比較は `python3 docs/art/priest/make-r1-review.py` で再現できる。
測定値は `r1-review-settings.json`。頭巾に隠れた主な髪の頭頂は推定位置であり、頭巾の上端とは区別する。
R1案はユーザーの「とても良いです。この感じでR2～５も制作」により確定した。比較時の暫定測定は履歴として残す。

## 採用原画と取り込み

採用原画は `priest-r1-final.png`〜`priest-r5-final.png`。R2〜R5は確定R1・聖戦士R1・各ランクの旧画像を直接参照して、それぞれ独立した透明画像として生成した。集合画像の分割はしていない。R2の顔位置とR4のマント先端を追加修正した。修正前の案は `priest-r2-draft.png` と `priest-r4-draft.png`。

各画像の測定値と縮尺は `import-settings.json`。頭巾で隠れた頭頂はR1の人体から推定し、目・顎・頬・足裏を原画で比較して決めた。聖戦士の原画座標は流用していない。
共通枠90×92ドット、人体の頭頂9ドット。足裏下の半透明な輪郭も残せるよう、輪郭下端まで82.8ドットを基本に縮尺を決める。機械的なドット化・減色はしていない。

再取り込み：`python3 docs/art/priest/import-art.py`。
`tools/jobimg.py` を使って `art/jobs/priest_1.webp`〜`priest_5.webp` と `src/jobphotos.js` を更新。優先される `src/jobart.js` の僧侶だけを削除し、`sw.js` へ5枚を追加した。CACHEは `dos-dev`。

## 確認

- `node docs/art/priest/verify-import.mjs`：全5ランクの選択、共通枠と顔設定、キャッシュ登録、他職業の設定維持。
- `python3 docs/art/priest/verify-assets.py`：全5枚の透過・画像端・不透明な残片。結果は `asset-verification.json`。
- ローカルサーバー起動後、`python3 tools/review-job-art.py priest --label 僧侶 --require-photos --output docs/art/priest/final-review`：聖戦士R1と僧侶全5ランクの全身、56/36/26pxの顔アイコンと顔拡大、ゲーム起動。結果は `final-review.png` と `final-review.json`。

上記の検査と変更したJSの構文確認はすべて通過した。全6枚のゲーム内共通枠は96×94ドット、顔位置は `[48,21]`、人体の頭頂は10ドット。顎の設定は聖戦士との差が最大0.192ドット（保存画像で1px未満）。全身6枚・顔24枚の描画を確認し、ブラウザーエラーは0件。武器・頭巾・マントの輪郭と装備の成長も目視確認した。

ユーザーの指示により、mainへの反映はPR経由で行う。
