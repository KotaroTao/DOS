# 水晶の鉱脈の魔物

森の古屋の3体（`docs/art/prologue-enemies/preview.png` 上段）を画風の基準に、図鑑の説明・伝承・能力を参照して制作。暗い輪郭、左上の光、控えめな土色と青白い水晶を使った透過原画。出荷物はロスレスWebP 9枚、合計約1.5MB。

最新mainで作成済みの強敵「鉱脈喰らい」（`el_oremaw`）は画像・登録とも変更しない。水晶の鉱脈（ws22）の通常敵9体を追加し、同じIDの別の迷宮にも反映する。主・召喚先はこの迷宮に存在しない。共通ミミックも作成済み。

| --- | --- | --- |

原画は [master.png](master.png)。最終段右の鉱脈喰らいは制作途中の案であり、出荷しない。`python3 tools/crypt/build-crystal-enemies.py` で9体だけを切り出し、輪郭の外に透過の余白を付ける。文字グリッドへの減色は行わず、既存のphoto描画で戦闘・盤面・図鑑に表示する。原画・制作記録・確認画像は公開対象外のdocsへ置く。

登録は `src/monsterphotos.js` と `sw.js`。既存の能力・技・説明・伝承・出現条件・セーブ形式は維持。新機能や戦闘ルールの変更はないため酒場の心得は変更しない。CACHEはdos-devのまま。

## 確認

ローカルHTTPサーバーをポート8000で起動後、`node tools/crypt/verify-crystal-enemies.cjs`（Playwright・Chromiumが必要）。保存なしのテストモードを使い、10体の出現表に登録漏れがないこと、新規9体の戦闘画像が空でないこと、能力等が変化しないこと、画像の取得失敗でも9体とも旧絵で起動することを確認する。

確認画像: [9体の一覧](preview.png)、[図鑑](codex-mobile.png)、[盤面](board-mobile.png)、[戦闘](battle-mobile.png)。伝承検査、JS構文検査、物語の画像登録・読み物の整合性検査も実行。
