# 雷の回廊〜亡き観客の階段席の探索盤面

地下墓地と同じ高解像度の描き下ろし素材を、w32〜w36の全55階に適用する。各迷宮専用の床一枚と、未踏の蓋3種・壁材を含む原画を画像生成で制作した。

比較は同じ乱数の種の盤面で左下の一部を開いた制作見本。初期配置は別に保存する。

原画は `w32-materials-master.png`〜`w36-materials-master.png` と各 `floor-master.png`（1536×1024）。素材原画は上段に512px四方の蓋3種、右下に壁用石材を配置。床は反復や反転をせず、一枚の床原画から切り出す。出荷するWebPは10枚で約6.1MiB。原画と比較画像は公開配置から除外される。

既存の `cryptpaint.js` に迷宮を登録し、床・蓋・壁を3倍密度で合成する。二枚が揃うまで旧描画を維持し、読込完了後にキャッシュを切り替える。帯電床・腐ったわら・灰と落ちる床は既存の土地固有の仕掛けを継続する。人物・小物は共通素材を使用する。

再変換:

```bash
bash tools/crypt/build-dungeons.sh w32 w33 w34 w35 w36
```

HTTPサーバーを8000番で起動後、PlaywrightとChromiumで確認:

```bash
NODE_PATH=/path/to/node_modules CHROMIUM_PATH=/usr/bin/chromium node tools/crypt/verify-w32-w36.cjs
```

対象55階と地下墓地5階、320/390/600/1280px、素材失敗・不正寸法・遅延、タップ・めくり・ドラッグ・全体表示、蓋と中身の独立、乱数の保持、危険な床、対象外とキャッシュ上限を確認する。ローカルChromiumでの確認であり、スマホ実機の速度測定ではない。

酒場の心得: `t_storm_stonework`・`t_arena_stonework`。
