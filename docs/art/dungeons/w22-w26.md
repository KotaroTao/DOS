# 氷棚〜腐れ水の岸の探索盤面

地下墓地と同じ描き下ろし素材をw22〜w26の全55階に適用する。

画像生成で各迷宮に1536×1024の素材集と床を一枚ずつ制作。`wNN-materials-master.png`の上段は512角の蓋3種、右下は壁材。`wNN-floor-master.png`は連続した床の原画で、反転や繰り返しを使わず盤面に合わせて切り出す。原画はこのディレクトリに残し、配信には品質88のWebPだけを使う（10枚で約5.7MiB）。

既存の共通処理で床・蓋・壁を論理寸法の3倍で合成し、光・影・めくりを重ねる。明るい壁と暗い床を分ける。凍てつく床・毒の沼の染み、氷の割れ目・泥穴、動く粒は既存の仕掛けを維持する。蓋の模様は中身に依存しない。人物・小物は全迷宮共通の原画を使う。

画像が未読込・取得失敗・寸法不正の時は旧描画を使い、両方の画像が到着した迷宮だけ原画に切り替える。盤面キャッシュは2組までで、遊びの乱数は消費しない。

## 再変換・検証

```bash
bash tools/crypt/build-w22-w26.sh
python3 -m http.server 8000
# 別の端末。必要に応じてNODE_PATHを指定する。
node tools/crypt/verify-w22-w26.cjs
```

[検査結果](w22-w26-review/checks.json)。対象55階と地下墓地5階、読込遅延・失敗・不正寸法、危険な床、蓋と中身の独立、乱数の保持、タップ・めくり・ドラッグ・全体表示、画面幅320〜1280px、対象外の迷宮を確認する。比較画像では同じ種の盤面の左下を一部開いている。実際の初期状態は[初期配置](w22-w26-review/initial-mobile.png)。速度はローカルChromiumでの測定で、スマホ実機の測定は含まない。
