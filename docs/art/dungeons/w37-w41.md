# 闘技場〜大伽藍の探索盤面

地下墓地と同じ描き下ろし素材を、w37〜w41の全60階へ適用する。各迷宮に1536×1024の床原画と素材原画を一枚ずつ、計10枚を画像生成で制作した。

素材原画は `wNN-materials-master.png`。上段512×512の3区画が未踏の蓋、右下が壁材。下段左と中央は制作見本。地下墓地の素材原画を画風と配置の参照にした。床原画 `wNN-floor-master.png` は全体を一枚の地面として描き、鏡合わせや反復を使わず盤面の縦横比で切り出す。

配信画像は `art/dungeon/wNN-materials.webp` と `wNN-floor.webp`。原画と確認画像は公開配置に含めない。共通の `cryptpaint.js` に迷宮IDを登録し、読込失敗・遅延・寸法不正時の旧描画、3倍解像度、壁の陰影、キャッシュ上限2組を引き継ぐ。蓋の意匠は中身を示さず、描画では遊びの乱数を消費しない。危険な床は既存の専用表示を重ね、人物・宝箱・階段などには共通原画を使う。心得 `t_deep_stonework` を追加。

## 再変換と確認

```bash
bash tools/crypt/build-dungeons.sh w37 w38 w39 w40 w41
python3 -m http.server 8000
# 別の端末。必要ならNODE_PATHとCHROMIUM_PATHを指定する。
node tools/crypt/verify-deep-dungeons.cjs
```
