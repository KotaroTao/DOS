## 原画・配信素材

画像生成で各迷宮に1536×1024の原画を2枚ずつ制作。
`wNN-materials-master.png` の上段は512px四方の蓋3種、右下は壁材。下段の床見本はゲームには使わない。
`wNN-floor-master.png` は連続した一枚の床で、反復や鏡合わせをせず盤面に合わせて切り出す。
配信物は品質88の `art/dungeon/wNN-materials.webp` と `wNN-floor.webp` の10枚。
原画と確認用画像は公開配置から除外される。

既存の共通描画処理で論理寸法の3倍で合成し、光・影・壁・めくりを重ねる。蓋の模様は中身と無関係で、遊びの乱数を消費しない。
各迷宮の2枚が揃うまでは旧描画を保ち、別迷宮の素材失敗から独立して切り替わる。人物・小物は既存の共通素材を使用する。
危険な床は原画に描き込まず、聖水・灼けた床・熱い灰・煮えた霊薬をゲームの状態に応じて重ねる。

## 再変換・確認

```bash
bash tools/crypt/build-dungeons.sh w17 w18 w19 w20 w21
python3 -m http.server 8000
# 別の端末。必要ならNODE_PATHとCHROMIUM_PATHを指定する。
DUNGEON_REVIEW_GROUP=w17-w21 node tools/crypt/verify-dungeons.cjs
```

対象60階と地下墓地5階、画面幅320/390/600/1280px、取得遅延・失敗・片方の失敗・不正寸法、タップ・めくり・ドラッグ・全体表示、危険な床、乱数保持、蓋と中身の独立、キャッシュ上限を確認する。検証環境はローカルのヘッドレスChromiumで、スマホ実機の速度測定ではない。
酒場の心得は `t_crypt_stonework` を更新。
