# 苗床〜大水槽の探索盤面

比較は同じ乱数の種を使い、床を確認するため一部のマスを開いた制作見本。実際の初期配置は [initial-mobile.png](review-w12-w16/initial-mobile.png)。

原画はこのフォルダの `w12-materials-master.png`〜`w16-materials-master.png` と `w12-floor-master.png`〜`w16-floor-master.png`。蓋原画の上段3区画を未踏マスに、右下区画を壁に使用する。床は別原画一枚から切り出し、反復・鏡合わせは使わない。地下墓地の石材原画を蓋・壁材の画風の参照に使用した。

共通の `src/cryptpaint.js` に迷宮を登録し、3倍の描画密度、遅延取得と失敗時の旧描画、めくり、壁の明暗を継承する。吸い根・よどんだ聖水の床と落ちる床は既存の描画を重ねる。彫刻はマスの中身を示さず、描画は遊びの乱数を消費しない。共通の人物・小物を使用する。酒場の心得 `t_rootwater_stonework` を追加した。

```bash
bash tools/crypt/build-dungeons.sh w12 w13 w14 w15 w16
python3 -m http.server 8000
# 別の端末。Playwrightの所在をNODE_PATHで指定する。
NODE_PATH=/path/to/node_modules DUNGEON_REVIEW_SET=w12-w16 node tools/crypt/verify-dungeons.cjs
```

全55階と地下墓地5階、320/390/600/1280px幅、取得失敗・片方の失敗・寸法不正・遅延、タップ・めくり・ドラッグ・全体表示、乱数保持、危険な床、対象外の迷宮、キャッシュ上限の121項目をローカルChromiumで確認済み。スマホ実機の速度測定は含まない。原画と確認画像は公開配置から除外する。
