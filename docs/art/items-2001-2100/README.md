# 制作番号2001〜2100のアイテム原画

固定台帳の2001〜2100に対応する100点。既存ID・名称・説明・性能・入手条件を維持。
森の小屋のほこりゴキブリ・枯葉ムカデ・森の小蜂の原画3枚を直接参照し、左上の光、深い影、控えめな色、細かなドットの質感を合わせた。
神威・神器は古い金と淡い鋼、星辰・星海は藍と銀を基調に、図鑑の火・氷・風・聖光、竜革、鎖編み、星図などを描き分ける。

`items.json` が番号・ID・名前・部位・図鑑説明の対応表。
原画 `master-2001-2020.png` 〜 `master-2081-2100.png` は5列×4行、左から右・上から下。
ゲーム用は `art/items/<既存ID>.webp`（384×384・背景透過）。原画と確認資料は公開対象外。

```sh
python3 tools/itemart/build-2001-2100.py
node tools/itemart/numbers.mjs --update
node tools/itemart/numbers.mjs
python3 -m http.server 8000
node tools/itemart/verify-2001-2100.cjs
```

既存の共通描画口で図鑑・袋・装備・商会へ反映する。未鑑定時の伏せ絵を優先し、取得失敗・寸法不一致・4秒の時間切れには従来の絵を使う。
絵の追加のみのため酒場の心得の変更は不要。

`preview.jpg` は番号順100点、`game-preview.png` は共通描画口、`codex-*.png` はスマホ幅の図鑑表示。

確認結果: 100点すべて384×384・透過・余白あり・画像の重複なし。出荷WebP合計5.31 MiB。
実ブラウザで通常100点の描画、未鑑定100点の伏せ絵、取得失敗・寸法不一致・時間切れの各100点の代替描画を確認。
スマホ幅390pxで暗刃・ローブ・水晶球・覇輪の図鑑表示を確認。SW登録2251件の実在と `dos-dev` 維持、制作台帳の整合も確認。
