# 大空洞の主の寝床の敵イラスト

森の古屋の3体（ほこりゴキブリ・枯葉ムカデ・森の小蜂）の原画を直接参照し、暗い輪郭、落ち着いた土色、細かなドットの陰影を合わせた。図鑑の説明と能力に合わせ、未作成の4体を描き下ろした。

| ID | 名前 | 反映した特徴 |
| --- | --- | --- |
| bs_cavetroll | 洞窟のトロール | 苔に覆われた背、複数の灯籠、ふさがる傷、両腕を振り上げる姿 |
| bs_blindhorror | 盲いた深淵獣 | 目を覆う滑らかな皮、四つの大きな耳、やせた体、飛びかかる牙 |
| bs_cavernlord | 大空洞の主 | 山のような巨体、分厚い皮、背の毛の黒いガラス片、すすの息 |
| bs_gloomstalker | 闇這いの蟲 | 黒い百足の甲殻、節ごとの濁った灯のかけら、尾の毒針 |

通常敵9種・主・強敵2種・召喚先を照合。穴蔵の王の召喚先「闇這いの蟲」も含む。ほかの通常敵7種、鉱脈喰らい・穴蔵の王、ミミック2種・金属の魔物3種は作成済みの原画を共用する。大空洞の主の召喚先は盲いた深淵獣。

原画はこのフォルダの各IDのPNG。`python3 tools/cavern-lair/build-enemies.py`（Pillow）で透明領域を保ち、最大512pxに縮小、外周に4pxの余白を足し、個別の透過ロスレスWebPに変換する。`src/monsterphotos.js` の寸法と `sw.js` のASSETSも登録する。公開用は `art/monsters/` のWebPのみ。

`node tools/cavern-lair/verify-enemies.cjs`（localhost:8000・Playwright・Chromium）で対象全種と召喚先の登録、4体の非空の戦闘画像、能力・図鑑本文の維持、画像取得失敗時の旧絵表示を検査し、図鑑・盤面・戦闘の確認画像を保存する。
