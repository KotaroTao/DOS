# 枢機卿 R1〜R5

職業IDは `cardinal`。基準の聖戦士は `crusader`。

既存の特徴は、淡い肌、金髪、紫の角帽とマゼンタ帯、桃〜紫の長衣、銀の十字杖。R2では配色が鮮やかになり、R3では金の聖印、R4では背面の飾りと外套、R5では冠と豪華な聖杖が加わる。既存描画は `existing-review.png` に保存した。

ユーザーが確認した `cardinal-r1-draft.png` をR1確定原画として採用。R2〜R5はその原画と聖戦士の基準原画を直接参照し、各ランクを独立した透明背景画像として制作する。顔、髪、人体とポーズを保ち、衣装と装備を段階的に強化する。

R2は鮮やかな法衣と金縁、R3は胸元の聖印と刺繍・杖、R4は濃紫の外套、R5は金の冠と宝飾を強化する。

帽子が主な髪の頭頂を隠すため、人体の頭頂は見えている髪・顔・帽子の位置から推定する。帽子の先を人体の頭頂に含めない。測定用画像は `inspect-source.py` で原画を変更せず生成する。

作業ブランチは `codex/cardinal-art`。mainへのマージは別途指示を待つ。

## 取り込みと確認

採用原画は `cardinal-r1-final.png`〜`cardinal-r5-final.png`。透明WebPは `art/jobs/cardinal_1.webp`〜`cardinal_5.webp`。既存の `tools/jobimg.py` で取り込み、`src/jobphotos.js` の画像・顔設定と `sw.js` の画像一覧を更新した。枢機卿に優先される旧 `JOB_IMAGES` の項目はないため、旧絵の削除は不要。

共通枠は90×92ドット、人体の頭頂は9ドット。原画ごとの測定値は `import-settings.json`。縮小時の外周の補間に必要な余白を確保するため、頭頂から足元は約82.6ドットとした。聖戦士の約82.9ドットとの差は0.4%未満。顔の輪郭と目の位置も実表示で比較した。原画のドット化・減色は行っていない。

再取り込みは `python3 docs/art/cardinal/import-art.py`。

`final-review.png` は聖戦士と同倍率の全身、56/36/26pxの顔アイコンと顔の拡大。`final-review.json` にゲーム描画関数による画像選択、全身6枚・顔24枚、共通座標、ブラウザーエラーなしを記録した。杖・外套・冠の欠けを目視確認した。`asset-verification.json` に透明背景と画像端の余白の確認結果を保存する。
