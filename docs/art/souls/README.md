# 職業の魂の入手イラスト

`acquisition-master.png` は入手ポップアップ専用の透過原画。職業の姿ではなく、白い芯と流れる炎の人魂を描く。原画は公開対象外。

`python3 tools/soulart/build.py` (Pillow が必要) でゲーム用の320×320 WebPを作る。40フレーム・80ms間隔・3.2秒の無限ループ。輪郭を上ほど大きく、上下をわずかに揺らす。先頭フレームを動きを減らす設定用の静止WebPにも書き出す。

ゲームは `src/ui/soulart.js` で職業の `glow` を中間色に適用し、白い芯と透明度を保つ。受け取り・残火・レア度などの処理には触れない。読み込み失敗時はドット絵の人魂に戻す。
