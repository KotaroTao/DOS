便0の基準シート11枚と一門の印 `sigil.png` はすべてユーザー承認済み。候補と比較画像は制作記録として残す。ゲームへの登録は行わず、mainへのマージは別途指示を待つ。

館の灯の形は、2026-10-16 のユーザー指定により `art/story-review/opening/flame.png` を最優先とする。`props.png` は灯の種類と材質の参照として残し、燭台の台座・短い支柱・受け皿・白い蝋燭の比率はオープニングへ合わせる。


## 王宮内部の基準 (2026-10-19)

ユーザー依頼により、以後の王宮関連イラストの基準として同じ玉座の間を5つのアングルで制作。各1536×1024 PNG、人物なし。灰色の石、黒い石床、黒鉄と金、深紅の布、ろうそくの色を共通にする。

[5視点の確認ページ](palace/README.md)で個別の原画を確認できる。正面を建築・家具の位置の主基準とし、ほかの4枚を構図の参照に使う。細部が食い違う場合は正面を優先する。窓の外の建物・月の位置は空間の固定要素に数えない。

|---|---|---|

| [palace-left.png](palace-left.png) | 入口の左側から玉座を見る | 制作済み |
| [palace-right.png](palace-right.png) | 入口の右側から玉座を見る | 制作済み (左側に寄った初稿を描き直し) |
| [palace-reverse.png](palace-reverse.png) | 玉座側から入口を見る逆方向 | 制作済み |
| [palace-high.png](palace-high.png) | 上階から全体を見下ろす | 制作済み |

制作指示の正本は [指示書2-4・2-5](../codex-story-art-brief.md)。`node tools/storyart/prompt.mjs ref:palace-front` (ほかは `left`・`right`・`reverse`・`high`) で画像生成用の指示を出す。王宮・玉座の間の場面では prompt.mjs が正面画を参照に含める。必要なアングルの原画も追加して渡す。回廊・倉庫は材質・彫刻・配色だけを共有する別室。人物の基準シート、章ごとの空と時刻、宰相の不在、王の杯・膝掛けなどの物語設定を優先する。

これらは制作資料として `docs/` に保存し、ゲーム向け画像の変換・SW登録の対象にはしない。
