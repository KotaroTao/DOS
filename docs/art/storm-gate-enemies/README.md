# 雷雨の大手門の魔物

森の小屋の3体（`../prologue-enemies/preview.png` 上段）を直接参照し、暗い輪郭・左上の光・控えめな色・細かな質感をそろえた。図鑑の説明・伝承（`src/dungeons/bestiary.js`・`monlore.js`）と固有デザインを確認して、未作成の5種を透過ロスレスWebPで制作。

| ID | 魔物 | 絵に反映した特徴 |
| --- | --- | --- |
| bs_bloodorc | 血狂いのオーク | 飢えた赤褐色の体、首の古い鎖、白い戦化粧、二本の肉切り包丁 |
| bs_thunderknight | 雷電の騎士 | 紺鉄の鎧、真鍮の角兜、突き出す長槍、落雷をまとう速い踏み込み |
| bs_cultist | 邪神の僧 | 黒い法衣、影に沈む顔、魂へ伸ばす手、紫の煙を流す香炉 |
| bs_stormgiant | 嵐の巨人 | 青灰の巨体、雲の髪と髭、肩を包む雷雲、落雷を伴う拳 |
| bs_bonecolossus | 骨の巨兵 | 骸が組み合う胴、頭蓋と肋骨、大腿骨を束ねた腕、閉じ込められた魂の光 |

通常敵9種、名のある強敵「軍旗の亡将」、召喚先「無人の鎧」、宝箱・出来事・金属の共通敵6種の計17体が透過原画を使用する。作成済み12種のWebPは維持。大手門に主はいない。能力・出現表・説明文・伝承・セーブ形式の変更はない。新機能やルール変更ではないため酒場の話の更新はない。

## 原画と登録

原画は `sheet.png`。`python3 tools/storm-gate/build-enemies.py`（Pillow・NumPy・SciPy）で輪郭ごとに分ける。格子を越えた包丁やマントを切らず、離れた雷や煙も近い本体へ割り当ててRGBAを保ち、長辺512px以下に縮小して透過余白を付ける。

出荷物は `art/monsters/` のWebP5枚（合計約1.4MiB）。`src/monsterphotos.js` に寸法、`sw.js` の `ASSETS` にパスを登録。`dos-dev` は維持。原画・確認画像・道具は公開対象外。

## 確認

`python3 -m http.server 8000` を起動し、`node tools/storm-gate/verify-enemies.cjs` を実行（Playwright・Chromium）。保存なしの大手門テストモードで、出現表・召喚先・共通敵の網羅、17体の原画読み込みと非空の戦闘画像、能力・説明・文字グリッドの維持、画像取得失敗時の旧絵への代替表示、ブラウザ例外がないことを検証する。図鑑・盤面・戦闘のスマホ幅の確認画像も保存する。

検証結果: 17体すべての原画・非空の戦闘画像を確認。画像取得失敗時は17体すべて旧絵で起動し、ブラウザ例外なし。画像登録による能力・説明・文字グリッドの変更は0件。スマホ幅の確認画像を目視し、JavaScript構文、物語画像登録・指示書・読み物の整合性検査も通過。
