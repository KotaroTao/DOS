# 王宮の書庫番オルデン

図鑑の手ほどき専用イラスト。2026-10-30、ユーザーの制作・組み込み・mainへのマージ指示に基づき制作。

- 原画：`olden.png`（1536×1024）。画像生成で新規制作。
- 配信用：`art/tutorial/olden.webp`（原画の画角を維持しWebP品質90で変換）。`sw.js` に登録。
- 人物：白髪交じりの短髪と短いひげ、丸眼鏡、深緑の学者の衣。穏やかな表情で迎える王宮の書庫番。王・宰相・師オルドとは別人。
- 場面：王宮の書庫で図鑑を開き、訪問者を迎える。挨拶・操作の案内・締めの会話に同じ絵を表示する。
- 確認：両手と指、図鑑の虫の絵、スマホでの顔の見やすさ、会話画面での読み込みを確認。

会話は `src/ui/tutorial.js` の `insight` と `playTutorialScene`。絵はストーリー一覧用の挿絵ではなく、`art/tutorial/gatekeeper.png` と同じ操作案内用の素材として管理する。
