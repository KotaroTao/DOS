# 化石竜の墓所の魔物

森の古屋の3体（ほこりゴキブリ・枯葉ムカデ・森の小蜂）の原画を直接参照し、左上の光、深い影、控えめな土色と冷たい輪郭光を合わせた。図鑑の説明・伝承・能力を参照して未作成の6体を制作。出荷物は個別の透過ロスレスWebP 6枚（合計約1.4MB）。

| ID | 魔物 | 絵に反映した特徴 |
| --- | --- | --- |
| bs_fossildragon | 化石竜 | 石になった骨と肋骨、割れ目の濁った魂、岩片とすすの息 |
| bs_primalbeast | 原初の獣 | 大きな角と牙、飛びかかる姿、前足の六本指 |
| bs_primalserpent | 原初の大蛇 | 黒い鱗、とぐろ、濁った灯と同色の目、黒い灯籠の山 |
| bs_cavebehemoth | 大空洞の巨獣 | 岩のような灰色の皮、吠える口、背に積もった黒い灯籠 |
| bs_earthshaker | 地揺らす巨体 | 岩山の甲羅、身をかがめた巨人、四肢、砕けた灯籠のガラス |
| bs_abysshorror | 深淵の異形 | 溶け合った魂、浮き沈みする顔と手、不定形の霊体 |

[原画A](sheet-a.png)・[原画B](sheet-b.png)は各3体。原画の透明領域を保ち、本体と近い岩片・霊気を個体ごとに切り出して最大512pxへ縮小し、外周に透過の余白を付ける。再変換・寸法とSW登録の更新は `python3 tools/fossil-tomb/build-enemies.py`（Pillow・NumPy・SciPyが必要）。

通常敵12種（主の化石竜も同じID）と強敵・鉱脈喰らいを網羅。作成済みの黒曜の獣・岩の巨人・水晶竜・大空洞の守護像・晶蟲の大蜘蛛・深淵の顎・鉱脈喰らい、ミミック2種・金属の魔物3種は画像を変更せず共用する。対象に召喚先はない。

`src/monsterphotos.js` と `sw.js` に登録し、戦闘・盤面・図鑑の共通描画口へ反映。同じIDの別の迷宮にも絵が反映される。画像の取得失敗時は旧絵を使う。能力・技・図鑑本文・伝承・出現条件・セーブ形式は維持。画像の追加のみなので酒場の心得は変更しない。CACHEはdos-devのまま。

## 確認

ローカルHTTPサーバーをポート8000で起動し、`node tools/fossil-tomb/verify-enemies.cjs`（Playwright・Chromiumが必要）。保存なしの試遊で対象18種の登録網羅、新規6体の非空の戦闘画像、既存の能力・本文の維持、取得失敗時の旧絵表示、図鑑・盤面・戦闘を確認する。
