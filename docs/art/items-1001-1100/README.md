# アイテム制作番号1001〜1100

固定制作台帳の1001〜1100を対象に、図鑑の名称・説明に合わせた透過原画を制作した。
既存の文字列ID・名称・説明・性能・入手条件は維持する。

森の小屋のほこりゴキブリ・枯葉ムカデ・森の小蜂の原画3枚を直接参照し、
左上の光、深い影、控えめな色、細かなドットの質感をそろえた。
神殿の祭具と石・火の洞の硫黄と黒曜石・氷窟の氷と毛皮・沼の葦と薬草・
雷の地の銅線と鐘など、図鑑にある素材と由来を描き分ける。

`items.json` は番号・既存ID・名称・部位・レア度・図鑑説明の対応表。
原画は `master-1001-1020.png` から `master-1081-1100.png` の5枚。
各5列×4行、左から右・上から下の順。つながった本体と周囲の小部品を
近い品へ割り当て、余白を付けて384×384の透過WebPへ変換する。
出荷物は `art/items/<既存ID>.webp` の100点。原画・確認資料は公開対象外。

```sh
python3 tools/itemart/build-1001-1100.py
node tools/itemart/numbers.mjs --update
node tools/itemart/numbers.mjs
python3 -m http.server 8000
node tools/itemart/verify-1001-1100.cjs
```

`src/itemphotos.js` と `sw.js` へ登録し、図鑑・袋・装備・商会の共通描画に反映。
既存の未鑑定時の伏せ絵、取得失敗・寸法不一致・時間切れ時の代替表示を利用する。
`preview.jpg` は番号順100点、`game-preview.png` は実ブラウザの共通描画口での確認。
