## 章の景色と主題 (全項目共通)

大書庫の底の扉 (師が内側から閂を掛けた) の下に広がる、この国の **王家の廟**。王が死ぬと亡骸に香油を塗り、ろうで固め、王都の地下の縦穴から綱で降ろしてここへ葬る。
- 千年分の棺が段をなして並ぶ。壁のくぼみに **一度も消えないろうそく** が何千本。甘い香油の匂い、金の死面と金の飾り。
- 亡骸は「ろうのように白く固まった人の亡骸」。**木の人業とは見分ける** (木目・黒鉄の継ぎ目は無い)。
- 光は温かい琥珀のろうそくの灯だけ。地下なので空は描かない (王宮の報告の窓の外は晴れた空)。
- 門の上に古い字の一行「王を終わらせるな」(読める文字にしない)。
- 主題は「誰の意思で、誰の救いを決めるのか」。最初の王・師オルド・防腐師たちを **悪人にも聖人にも見せない** (恐ろしさより痛ましさ)。
- 迷宮: 弔い灯の参道 `w46` / 香油の仕立て場 `w47` / 眠らずの近衛廊 `w48` / 終わらずの玉座 `w49` (主: 王家の廟の主) / 寄り道: 名の無い墓所 `ws25` / 剥製の大広間 `ws26` / 王子の墓所 `ws27`。
