# 大司教 R1〜R5

職業IDは `archbishop`。`src/souls.js` で確認済み。
ランク名は修道院長、大司教、首座大司教、総大司教、聖座の代行者。

## 既存画像の特徴

銀白色の短い髪、茶系の目、ひげのない若い男性。白・紫・金を基調とする法衣と司教冠、曲頭杖、閉じた聖典、茶色の靴を維持する。

- R1: 簡素な白い司教冠と金の十字、紫のストラ、巻いた先端の杖、控えめな金縁の聖典。
- R2: 冠と法衣の金縁が増え、杖の輪に十字が入る。
- R3: 高い冠、金の肩留め、紫の肩衣と後ろのマント、杖と法衣の装飾を強化。
- R4: 青い宝石を冠・肩・胸・杖に追加し、金の刺繍とマントを拡充。
- R5: 最も豪華な宝冠、青い宝石付きの聖典と杖、広がる白・紫のマント、豊かな金の刺繍。

## 制作状況

ユーザーが添付した大きな司教冠の初期案をR1として採用。
`archbishop-r1-final.png` は `archbishop-r1-initial.png` の無変更コピー。
後から作った低い冠の `archbishop-r1-review.png` は採用していない。
今回の明示的な採用を優先し、R1の顔・髪・人体・頭身・ポーズを基にR2〜R5を独立生成した。
聖戦士 `crusader` の原画も各生成で参照し、描画スタイルを確認した。
集合絵を分割していない。R4は冠の上端だけを修正した。

R2は金縁と十字付きの杖、R3は肩留めと紫のマント、R4は青い宝石と金刺繍、
R5は宝冠・胸の鎖・聖典・法衣・マントを最も豪華にした。
採用原画は `archbishop-r1-final.png`〜`archbishop-r5-final.png`。

作業ブランチ: `codex/archbishop-art`。
最新mainと職業イラストの下準備資料は取り込み済み。

## ゲームへの取り込み

`tools/jobimg.py` で透明WebPを `art/jobs/archbishop_1.webp`〜`archbishop_5.webp` へ出力し、
`src/jobphotos.js` の大司教の顔・頭設定を更新済み。
原画を機械的にドット化・減色していない。
`sw.js` には既存の5画像の登録があるため、登録と `CACHE = "dos-dev"` を検査した。
`src/jobart.js` に優先される大司教のエントリーはない。

測定・設定は `import-settings.json`。帽子や跳ね毛の先を頭頂として測っていない。
採用R1の高い冠を保持し、全ランク同じ倍率で90×94ドットの透明枠に配置。
人体の頭頂は15.2ドット。従来の90×92枠・頭頂9ドットにはこの冠が収まらないため、
枠を2ドットだけ広げた。共通枠は96×94から96×96になるが、最大辺96は変わらず、
他職業の表示倍率に影響しないことを実際の描画設定で確認した。
聖戦士との頭身の数値一致より、ユーザーが明示的に採用したR1の人体を維持する。

再取り込み: `python3 docs/art/archbishop/import-art.py`。
