# 王宮から語られた情景へ・第1便（10枚）

ユーザーの2026-11-03の依頼に従い、王宮を約1割に減らす提案の第1便を制作。`report_w02`〜`report_w08` と `report_w10`〜`report_w12` の10枚を、報告で語られる地下の道・砦・牢・根の森へ変更した。王宮で話す本文・場面ID・解放条件は変えない。絵は会話の場所を移すものではなく、語られた情景を示す。

- [縮小一覧](overview.jpg)：全10枚を384×256で並べたもの。
- [制作台帳](manifest.json)：ID・原画・主題・実生成指示・参照・生成元・SHA-256・寸法。
- [本文と従来指示](prompts/)：各IDで実行した `node tools/storyart/prompt.mjs <ID>` の出力と、今回の生成指示。
- [変更前](before/)：`origin/main` の原画を `git show` で取得。古い共有checkoutの原画を変更前として採用していない。

## 確認

全10枚を画像生成ツールで制作。原寸表示と384×256一覧を目視し、主題・人物の形・読める文字がないこと・王宮の建築や玉座がないことを確認。全原画1536×1024のPNGであることとハッシュを機械確認。02の一門の印は承認済み基準を参照し、親指1・右指3・短い手首・離れた炎を確認した。地下の無人景に灯った集落・吊り灯を置かず、隊の手提げ灯の照り返しや魂の光にした。

本文分岐に対応するため、04では人業の腕、07では読める固有名、11では小屋・手記・ヴェルナーの骸、12ではセラの胴を描かない。03の閉じた坑口は王が語る過去の情景として扱い、現在の通行証や開放状態を変更しない。

WebP変換・台帳登録・CI・PR・mainマージは統合担当が最新mainから行う。
