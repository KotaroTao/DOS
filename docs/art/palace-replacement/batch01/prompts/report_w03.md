# report_w03「封じた者の沈黙」 第1章

出荷済み。直す項目は指示書に無い。

### 本文 (ストーリー一覧)
> 修道院長の記憶を伝えると、王の目が宰相から離れた。古い坑口は王家が封じた場所だという。師は、その封の向こうを探していた。
> 何を恐れて閉じたのか。王は詳しく語らず、宰相も問いを受けなかった。報告を聞く二人の間に、弟子の知らない過去があった。
> 迷宮に残る記憶の方が、地上の言葉よりも率直なのかもしれない。弟子はその考えを口にせず、次の支度へ戻った。
