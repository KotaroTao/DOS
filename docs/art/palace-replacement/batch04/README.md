# 王宮の挿絵の置き換え・第4便

対象は `report_w36`〜`report_w46` のうち、残す `report_w41` を除いた10枚。王への報告で語られた情景へ主題を移し、本文・場面ID・解放条件を変えずに制作した。

- [縮小一覧](overview.jpg)
- [実生成指示と参照](manifest.json)
- [寸法・原画と変更前のSHA-256](verification.json)
- [変更前](before/) は `origin/main` の原画から保存。
- [既存の制作依頼](prompts/) は各場面で `node tools/storyart/prompt.mjs <ID>` を実行した出力。

既存の玉座の間・固定構図の指示は、今回のユーザーによる王宮削減・独自の情景への変更指示を優先して置き換えた。生成ツールは全枚 `image_gen`。原画は全て1536×1024 PNG。人物・小道具や場所の参照絵を閲覧後に生成へ渡し、各原画と384×256相当の縮小を目視した。

## 本文との整合と修正

- `report_w36` は巨大な観客席を、その下の空の狭い空間から見上げる無人の情景。初案に出た灯った吊り灯を除去後、独立レビューで指摘された `w36_nook` 未取得時の先出しを防ぐため、寝床・毛布・玩具・箱も画像生成で完全に除去。
- `report_w37` は過去の火災の記憶を繰り返さず、試合が終わった現在の静かな砂と明るい夕空。
- `report_w38` は人物を置かず、一つの磨かれた灯籠と捨てられた灯籠の山。師本人や墓守の正体を示さない。
- `report_w39` は岸に対応する実体のない湖面の灯が主題。灯籠を持ち帰らせない。
- `report_w40` は取得分岐で墓守が誰か分からない本文にも合わせ、初案のモルデン本人を完全に除去。無人の壁と匿名の荷車・清掃布だけを残した。最終生成の指示はmanifestの `revisionPrompt`。
- `report_w42` は町へ到着する既存絵と異なり、働く・休む・話す人業を近くから描く。町の幸福を疑う演出はしない。
- `report_w43` は瓶を調べる弟子ではなく、今日の瓶へ落ちる一滴。
- `report_w44` は書物の発見と別構図で、一つだけ火の入った工房を冷えた炉の内側から見る。
- `report_w45` は師との会話の記憶を繰り返さず、読み続ける司書だけを背後から描く。
- `report_w46` は弟子が書き置きを見つける場面から、町を守る閂の近景へ。法文を読める文字では描かない。

本文・登録・出荷WebP・生成台帳は担当者では変更していない。統合担当が公式の `build.py` により仕上げと検査を行う。
