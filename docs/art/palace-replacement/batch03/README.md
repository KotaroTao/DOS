# 王宮の挿絵差し替え・第3便（10枚）

ユーザー承認の「王宮を約1割だけ残し、残りは語られた情景へ変更する」方針に基づく制作。対象は `report_w24`、`report_w26`〜`report_w32`、`report_w34`、`report_w35`。報告の本文・場面ID・解放条件は変更していない。

- [10枚の縮小一覧](overview.jpg)
- [主題・原画パス・実際の生成指示・参照・ハッシュ](manifest.json)
- [既存の手がかり・記憶絵の構図確認](existing-contact.jpg)
- `prompts/` に各IDの `prompt.mjs` 出力と実生成・修正指示を保存。
- `before/` は `origin/main`（94f9b203）の変更前原画。共用checkoutの旧原画ではない。

全10枚を画像生成で制作。原画は1536×1024 PNGで担当する各章へ保存した。原寸と384×256縮小を目視し、人体、材質、文字の有無、主題の読みやすさを確認した。本文の取得条件分岐は、一覧用の固定本文とゲーム内の両方を確認し、明確な未取得品や読める手記・印を絵へ追加していない。新しい絵は報告で語られる場所・歴史の情景であり、王宮に幻影を投影した構図ではない。

`report_w24` は人物を外し氷に受け止められた魂の広がりへ、`report_w27` は器の内側から捨て場全体を見る構図へ、`report_w29` は命令を託す手に近づき、既存の発見・記憶絵と視点を分けた。`report_w35` は過去の闘技場の魂移し替えを示すため、歴史の火を残す。現在の無人迷宮を描く30・32・34は生成時に入った据付灯や窓の明かりを画像生成による再編集で消した。32には不要に生成された隊も除去し、魂を縛る鎖と雷を中心にした。

WebP変換・共通台帳・指示書更新・CI・PR・マージはrootの統合担当が行う。この担当では共有ファイルやGit履歴を変更していない。
