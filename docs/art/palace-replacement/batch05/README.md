# 王宮削減・第5便（10枚）

ユーザー承認の方針に従い、王への報告を「語られた情景」の独立した一枚絵へ変更した。王宮の会話・本文・ID・解放条件は変更しない。旧王宮固定構図の制作指示より今回の依頼を優先する。

対象: report_w47、48、49、50、51、53、54、55、56、57。

- 実生成プロンプト・参照画像・原画のSHA256は [manifest.json](manifest.json)。各場面の従来の制作依頼と本文は [prompts/](prompts/)。
- 変更前原画は `origin/main` のファイルを [before/](before/) に保存。共用checkoutの旧HEAD由来の画像は保存に用いない。
- 10枚とも画像生成で制作し1536×1024 PNGを担当原画へ配置。各原寸と384×256の一覧で主題・手・小道具・文字・王宮不在を目視確認。[一覧](overview.jpg)。
- report_w47は `w47_ledger` 未取得時にも表示されるため、初稿の若い王・王冠・魂・母の手を除いた。最終版は匿名の亡骸の白布を整える防腐師の手。正体や術の起源を明かさない。初稿は `report_w47-first-draft.png` として制作記録に留める。
- report_w48は必須手がかりの三枚の死面を中心に、従来の発見絵の「壁に並ぶ多数の面」から独立した三枚の静物へ変更。
- report_w49は千年ぶりの解放後の灯と隊の手。既存記憶絵の王と師・過去の母の構図を繰り返さない。
- report_w50/51は必須手がかりの仕事の札と個人の手の型。針仕事の願い／杯を持てる可能性を静物で描く。
- report_w53は工房を壊さず低い火にして休む結末。鎚・灯・水路を残し、既存の工房長の全景と区別する。
- report_w54は木の靴職人の手と小さな木靴へ接近。地上の娘をその場へ実在させない。
- report_w55は生者の家から鏡を見る逆視点。明るい青空を守り、死者の木の器は鏡の中だけにいる。
- report_w56は呼び起こす鎖を外した後の眠り。人業を消滅させず、祈る者の死後も願いが残ったという本文に対応。
- report_w57は聖堂に残した鈴と大司教の灯。王宮に小道具を持ち帰らず、返事を急かさない静けさを描く。
