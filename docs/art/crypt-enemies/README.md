# 忘れられた地下墓地の魔物

森の小屋の3体（`docs/art/prologue-enemies/preview.png`）を画風の基準に、図鑑の説明・伝承・能力を参照して制作。暗い輪郭、左上の光、骨の黄褐色と青灰色を基調とする透過原画。出荷用はロスレスWebP 9枚、合計約1.4MB。

| ID | 魔物 | 絵に反映した特徴 |
| --- | --- | --- |
| bs_bonebat | 骸蝙蝠 | 骨の翼、破れた薄膜、舞う骨の粉 |
| bs_carrioncrow | 腐肉あさりの大鴉 | 青黒い羽、鋭いくちばし、墓のどくろ |
| bs_corpsemaggot | 屍ウジ | 肥えた節、かみつく口、毒の体液 |
| bs_grasphand | 這い寄る腐手 | 指で這う腐った手、土のかけら |
| bs_gravewisp | 墓火 | 青い鬼火、未練を宿す顔、実体のない炎 |
| bs_bonepile | うごめく骨山 | 積み重なるどくろ・肋骨・長い骨 |
| el_cryptlord | 墓所の君主 | 古い骨、貴人の冠と紫の衣、王家の封、死者を呼ぶ手 |
| d01_skeleton | 囚人の亡骸 | やせた骨、囚人の布、手足のかせと鎖 |
| mimic | ミミック | 木と鉄の宝箱、牙のある口、伸びる舌 |

通常敵6種に加え、強敵とその召喚先、宝箱のミミックまで対象。第1層には金属の魔物・マスターミミックは出ず、地下墓地には主もいない。同じIDを使う別の迷宮にも同じ絵が反映される。

原画は [master.png](master.png)。`python3 tools/crypt/build-enemies.py` で輪郭に合わせて切り出し、透過の余白を付けて `art/monsters/<ID>.webp` を再生成する。文字グリッドへの減色は行わず、既存の原画描画口（photo）で表示する。登録は `src/monsterphotos.js`、起動時に並列読み込みし、成功した絵だけを共通の魔物辞書へ登録。画像の取得失敗・寸法不一致・4秒の待ち時間超過では元のドット絵を使う。能力・技・伝承・出現条件・セーブ形式は維持。新機能や戦闘ルールの変更はないため酒場の心得は変更しない。

## 確認

ローカルHTTPサーバーをポート8000で起動後、`node tools/crypt/verify-enemies.cjs`（PlaywrightとChromiumが必要、`CHROMIUM_PATH`で実行ファイルを指定可能）。保存なしのテストモードで確認する。

- 通常敵・強敵・召喚先・ミミックの登録漏れがないこと。
- 9体の原画が空でなく戦闘用ビットマップへ描かれること。
- 読み込み前の定義と比較し、既存の能力値・絵・伝承等が変化しないこと。
- 全画像の取得失敗時にも例外なく起動し、9体とも旧絵を残すこと。
- 全JavaScriptの構文、物語の画像登録、読み物の整合性を検査。

確認画像: [9体の一覧](preview.png)・[図鑑](codex-mobile.png)・[盤面](board-mobile.png)・[戦闘](battle-mobile.png)。
