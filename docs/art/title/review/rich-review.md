# タイトルの空模様と光の演出

雲と稲光を画面内の空に配置し、原画の切り取りによって消える問題を修正。雲の濃さと移動速度、空にかかる暗幕も調整。初回の雷は約3〜4秒、以後12〜26秒の間隔。月の光輪、墓標の魂火、濃淡と速度の異なる地霧を追加。
