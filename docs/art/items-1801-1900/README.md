# アイテム制作番号1801〜1900

固定台帳 `src/itemnumbers.js` の1801〜1900番、100点の専用イラスト。
既存の文字列ID・名称・説明・性能・入手条件は維持する。

森の小屋の「ほこりゴキブリ」「枯葉ムカデ」「森の小蜂」の絵を参照し、
左上の光・深い影・控えめな色・細かなドットの質感を合わせた。
図鑑の説明を基に、聖遺鋼・殉教銀・淡色の布・黄金・竜鱗・竜革・竜骨の素材、
竜眼や龍王の意匠、片手・両手武器と各盾種の形を描き分けている。

`items.json` は制作番号・既存ID・名前・部位・レア度・図鑑説明の対応表。
原画は `master-1801-1820.png` から `master-1881-1900.png` までの5枚。
各5列×4行、左から右・上から下の順。つながった本体を基準に切り出し、
透明な縁と離れた小部品を近い本体へ割り当て、各品を中央に配置する。
出荷するのは `art/items/<既存ID>.webp` の100点（384×384、背景透過、品質92）。
原画と確認資料は公開対象外のこのディレクトリに保存する。

```sh
# Pillow・NumPy・SciPy が必要
python3 tools/itemart/build-1801-1900.py
node tools/itemart/numbers.mjs --update
node tools/itemart/numbers.mjs
python3 -m http.server 8000
node tools/itemart/verify-1801-1900.cjs
# 別のサーバーを使う場合: ITEM_ART_BASE_URL=http://127.0.0.1:8001 を指定
```

`src/itemphotos.js` の既存描画口に登録し、図鑑・袋・装備・商会へ表示する。
未鑑定装備は伏せ絵を維持。取得失敗・寸法不一致・時間切れでは既存の絵へ戻る。
`sw.js` の `ASSETS` に100点を登録し、`CACHE = "dos-dev"` は維持する。

- `preview.jpg`: 制作番号順100点の見本。
- `game-preview.png`: 実ブラウザで共通描画口から100点を描画した結果。
- `codex-*.png`: スマホ幅での図鑑表示（巨斧・鎧・護符・刀）。
- 検証: 100点の原画選択・未鑑定100点の伏せ絵・空でない描画・対象外の維持、取得失敗・寸法不一致・時間切れでの代替表示。
