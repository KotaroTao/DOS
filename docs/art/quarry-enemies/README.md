# 石眠りの石切り場の魔物

森の古屋の3体（`docs/art/prologue-enemies/preview.png` の上段）と地下墓地の原画を直接参照し、暗い輪郭・左上の光・控えめな色・細かな質感を合わせた。図鑑の説明・伝承と既存の固有デザインを基に制作した透過WebP。通常敵9種・強敵1体・銀業を新規制作し、ミミックは地下墓地の既存WebPを共用する。石切り場には主はいない。第3層には金業・銀業の王・マスターミミックは出現しない。

原画は `master-a.png`（6体）と `master-b.png`（5体）。再変換はリポジトリのルートで `python3 tools/crypt/build-quarry-enemies.py`。輪郭に合わせて切り出し、ほぼ透明な背景を除いて最長辺512px以下・4pxの透過余白付きのロスレスWebPにする。11枚で約2.9MB。出荷先は `art/monsters/`、登録先は `src/monsterphotos.js` と `sw.js`。同じIDを使うほかの迷宮も共通の絵になる。

能力・技・説明・伝承・出現条件・セーブ形式の変更はない。読み込みに失敗した場合は従来のドット絵を維持する。機能・戦闘ルールの変更はないため酒場の心得の変更はない。

## 検証

ローカルHTTPサーバーを8000番ポートで起動し、`node tools/crypt/verify-quarry-enemies.cjs` を実行する（Playwright・Chromiumが必要）。

- 出現表9種・強敵・取り巻き・銀業・ミミックの全12種が登録され、空でない戦闘画像になること。
- 読み込み前後で既存の能力・技・説明などが変わらないこと。
- 全WebPの取得失敗時にも12種の従来の絵で起動すること。
- 保存なしの試遊で盤面・図鑑・6体戦闘を表示し、ブラウザの例外がないこと。

確認画像は [原画一覧](preview.png)、[ゲームの一覧](game-preview.png)、[図鑑](codex-mobile.png)、[盤面](board-mobile.png)、[戦闘](battle-mobile.png)。JavaScript構文・SWの登録と画像寸法・透過余白・読み物と伝承の整合性も確認した。
