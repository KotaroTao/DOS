# アイテム制作番号1901〜2000

固定制作台帳の100点。番号は制作番号で、既存の文字列ID・名前・説明・性能・入手条件は維持する。
`items.json` に制作時の番号・ID・名称・部位・図鑑説明を収録。

森の小屋のほこりゴキブリ・枯葉ムカデ・森の小蜂（`../prologue-enemies/preview.png` 上段）を直接参照。
暗い輪郭、左上の光、深い影、細かなドットの質感に合わせ、図鑑の素材・属性・意匠を描き分けた。
英雄鋼と黄金、星竜革の青い星模様、神代鋼の銀、原初竜革の暗紫、創世の白金の意匠を使う。
風の刀・弓、炎の斧と紅の魔晶、氷槍、琥珀色の創世の魔晶、水の滴を封じた盾も説明に合わせている。

原画5枚は各5列×4行、左から右・上から下の順。長剣・槍の先端が区画を越えても、
連結した本体を基準に分離し、左右一組の靴・手袋は同じ制作番号として切り出す。
1963のツヴァイハンダーは全体と剣先を収めた独立原画を優先する。
原画・確認資料は公開対象外のこのフォルダに置き、出荷物は `art/items/<id>.webp` の透過384×384画像100点。

```sh
python3 tools/itemart/build-1901-2000.py
node tools/itemart/numbers.mjs --update
node tools/itemart/numbers.mjs
python3 -m http.server 8000
node tools/itemart/verify-1901-2000.cjs
```

`src/itemphotos.js` の既存の読込口と共通スプライト差し替え口に追加。
図鑑・袋・装備・商会に反映し、未鑑定は伏せ絵を優先する。
取得失敗・384×384以外・4秒の時間切れは既存の固有ドット絵に戻る。
`sw.js` のASSETSへ100点を登録し、CACHEは変更しない。

確認資料: `preview.jpg`（100点一覧）、`game-preview.png`（共通描画口）、`codex-*.png`（スマホ幅の図鑑）。
見た目の差し替えだけなので、酒場の心得とゲームの仕組みは変更しない。
