# アイテム制作番号1501〜1600

固定台帳の100点を図鑑の名称・説明に合わせて制作。
森の小屋の3体（`../prologue-enemies/preview.png` 上段）を確認し、暗い輪郭、左上の光、青灰色の影、細かなドット調を基準にした。
星図の深青と星模様、魔鋼の青灰色、魔導の紫、真銀の澄んだ銀、竜帝の紅金と鱗などを描き分ける。

`items.json` に番号・既存ID・名称・図鑑の説明を保存。
5枚の `master-*.png` は左から右・上から下の順。最初の原画は上から5・5・6・4点、それ以外は5列×4行。
切り出しは原画の実際の中心を使い、靴などの左右の部品も同じ品へまとめる。
1521番は専用原画 `f_r7_magisteelsabaton.png` を優先する。
原画を個別に切り出し、余白を付けて384×384の透過WebPに変換する。
出荷物は `art/items/<既存ID>.webp` の100枚。原画と確認資料は公開対象外。

再変換と確認:

```sh
python3 tools/itemart/build-1501-1600.py
node tools/itemart/numbers.mjs --update
node tools/itemart/numbers.mjs
python3 -m http.server 8000
node tools/itemart/verify-1501-1600.cjs
```

`src/itemphotos.js` と `sw.js` に登録し、図鑑・袋・装備・商会の共通描画口で表示。
未鑑定の伏せ絵と読み込み失敗・寸法不一致・時間切れ時の代替表示を維持する。
`preview.jpg` は制作番号順の一覧、`game-preview.png` はブラウザの共通描画口での一覧。
品の性能・名前・説明・入手条件は変更しないため、酒場の心得の変更はない。

検証結果: 通常表示100点・未鑑定100点・描画100点。取得失敗、寸法不一致、4秒の時間切れでも全100点で代替表示と伏せ絵を確認。WebP合計 3647198 バイト。
