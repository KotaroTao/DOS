# 第一部・第二部と「壁」— 第十章からの難しさ

2026-10-11、ユーザーの指示で決めた方針。2026-10-14 の追加指示で、第十章以降の敵の強さを従来の10倍に変更。2026-10-15 の追加指示で、第十章で急に上げるのをやめ、第三章から迷宮ごとに少しずつ強くし、蘇生とHP1で踏みとどまる技を覚える第四章の入口で一段強くして、第十章の入口で10倍に届く段に変えた (2章)。同日の追加指示で、主・強敵のHPの追加も同じく段階的に (第四章の入口で一段) 強くした。さらに同日、HP・VIT が意味を持つよう段を能力ごとに分け (攻撃は軽く・HP は重く)、第二部の伸びを第13層の入口で約45倍に改めた (2章)。以下の旧指示は物語の二部構成の背景として残す。

> 10章で物語を一区切りして、11章からガラッと展開を変えたい。
> 11章から敵の強さが一気に上がり、魂融合やトレハン、鍛え直しなどをしないと先に進めない難易度にする。
> 10章クリアで無限迷宮も解放するので、無限迷宮でトレハン、魂集め→本編に挑戦という流れ。
> 11章以降は1層ごとの敵の強さの上げ幅を、これまでとは大きく変えて、1層ごとに大きな壁ができるように。
> 10章までがチュートリアル、11章からが本番というイメージ。

## 1. 二部の作り (決定)

| | 章 | 層 | 遊び方 |
|---|---|---|---|
| **第一部** (チュートリアル) | 序章〜第十章 | 第1〜12層 | 第二章までは推奨Lv に届けば進める。第三章から敵が少しずつ強くなり、第十章の入口で第二章までの物差しの10倍に届く。仕組み (融合・サブ魂・結社・鍛え直し・遠征・再戦) を1つずつ覚える |
| **第二部** (本番) | 第十一章〜第十八章 | 第13〜20層 | 土地 (層) が変わるたびに大きな壁。推奨Lv に届くだけでは勝てず、隊を鍛えてから挑む |

- **第十章で物語を一区切りにする。** 第十一章から展開をガラッと変える (中身は第九・十章を作る時にユーザーと決める。`docs/unlocks.md` の第十一章以降の層の景色・題は仮)。
- **第八章の結びで無限迷宮を開く** (`docs/infinite-labyrinth.md` — 決定済みの内容のまま)。第二部の流れは
  「無限迷宮で品・魂・残火を集める → 本編で魂を融合・Lv上限を上げる・装備を鍛え直す → 本編の壁に挑む」。

## 2. 壁の仕組み (実装済み — `src/dungeons/world.js`)

敵の強さ (HP・攻撃・防御) = 強さの素 `power` × 推奨Lv の伸び `lvPow` × **壁 `wallOf(cfg)`** × 手直し `tune`。

- **敵の強さの段 (2026-10-15 ユーザーの指示)**: 第十章で一気に10倍にするのではなく、味方の育ちに合わせて敵を強くし、第十章の時点で今の強さに届かせる。プレイの実感: 序章〜第十章の隊の育ちはほぼ推奨Lvどおり。第二章までは従来のままでちょうど良く、第三章から差が開き、第四章以降は隊が強くなりすぎる。隊が一気に強くなるのは、蘇生とHP1で踏みとどまる技を覚える頃。
  - 第一章・第二章 (第1〜4層) は従来のまま (倍率1)。
  - 第三章の最初の本筋 `w10` を段0として、本筋の迷宮を一つ進むごとに緩やかに等比で強くなる (HP・攻撃・防御 ×1.059、素早さ ×1.040、主のHPの追加 ×1.033、強敵のHPの追加 ×1.015)。
  - **第四章の入口 `w14` (推奨Lv52) で HP・攻撃・防御と、主・強敵のHPの追加を一段 ×2** (`RAMP_JUMP`)。蘇生 (リバイブ: 僧侶・枢機卿 Lv50、護教官 Lv55、聖騎士・司教・隠修士・勇者・死霊術師・賢者 Lv60) と HP1 で踏みとどまる技 (武僧 Lv35・守護騎士 Lv45・魔騎士 Lv60・騎士/狂戦士 Lv75 …、護教官・セラ・勇者・大司教は早くから) を覚える頃。素早さは跳ねない。主の HP は全体で w13 の約1.3倍から w14 の約5.7倍へ、強敵は約1.2倍から約5.3倍へ。
  - 第十章の入口 `w38` (段28) で **HP・攻撃・防御 ×10・素早さ ×3・強敵のHP ×3・主のHP ×5** に届く。
  - 第十章の中は本筋の迷宮ごとに ×1.5・素早さ ×1.1 (強敵・主のHPの追加は ×3・×5 のまま)。`w41` = ×33.75 / 素早さ ×3.99。
  - 段は本筋の層・推奨Lv順の番号 (`dungeonProgressOf`)。寄り道・格上の迷宮は推奨Lvが届いている最後の本筋の段 (第一部 = 第12層までの寄り道は第二部の本筋を数えない。ws20→w38、ws22→w39、ws21→w41 (推奨Lv135 は w45 の132を越えるが第一部の寄り道)、ws23→w42、ws24→w45、ws7→w18、ws13→w35、ws5→w15、第三章より前の推奨Lvなら段0)。踏破・開放の順番で強さは変わらない。
  - 第二部 (第13層〜) は本筋の迷宮ごとに ×1.07・素早さ ×1.03 (`PART2_STEP`) と、層の入口の段 `LAYER_WALL` (第13層 ×1.25、第14〜20層 各 ×1.2) を重ねる (`wallAt`)。第13層の入口 = w41 × 1.07 × 1.25 ≈ **45倍** (2026-10-15 ユーザーの指示: 100倍はやり過ぎ。テスト記録の隊は w41 の雑魚戦で1戦に0.5人砕け、主で全滅 — w41 がすでに限界なので、入口は1巡り鍛え直せば届く ×1.33 にした)。1層あたり約 ×1.57 (×1.07⁴ × 1.2)。
- **能力ごとの段 (`STAT_SPLIT`、2026-10-15 ユーザーの指示「HP・VIT に意味が生まれるように」)**: ここまでの倍率 W (`wallOf`) は「HP・攻撃・防御を同じだけ上げたら」の物差し。味方の守りは引き算 (敵の攻撃 − VIT÷2) なので、敵の攻撃を W 倍すると VIT で減る割合が 第二章の約7割 → w14 で2割 → w41 で2%、一撃が隊員の HP の約7倍になり、HP・VIT を積んでも意味がなかった (無効化・回復・蘇生だけで支えていた)。そこで実際の能力は
  - **攻撃 = W^(1/3)**、**HP = W^1.3**、防御 = W (素早さ・主/強敵のHPの追加は従来どおり別の段)。
  - 1.3 は模擬戦で決めた: 推奨Lv の標準の隊 (`tools/balance/jobs.mjs` の A 組 + 聖騎士) を、W 倍の敵 (変更前の仕様) に休まず12戦して半ばまでもつ強さまで鍛え、その隊が攻撃 W^(1/3) の敵に同じだけもつ敵の HP を w13〜w41 で探すと W^0.3 前後だった (ばらつきは大きい)。難しさは保ったまま、一撃は軽く・戦いは長くなる (1戦のターン数はおよそ2倍)。
  - 実装: `strengthAt` は W のまま (戦果の割り戻し・図鑑の基準もそのまま) で、`statWallOf(cfg)` = {atk: W^(−2/3), hp: W^0.3} を `combat.js scaleFoeStats` が個体に一度だけ掛ける (`_statWall` の印。Battle の `statWall`、召喚・保存復元・図鑑・表示Lv も同じ)。金属の魔物の HP (会心で削る数)・隊の写し身 (写した能力)・無限迷宮 (`wall: 1`) は直さない。宿敵の再戦は強さを写した手本の迷宮の段。

- **重さの目安**: 強さが k 倍になると、同じ隊の1戦の被ダメはおよそ k² 倍 (一撃が k 倍 × 倒すまでの手数が k 倍)。
- 入口は `world.js` の `RAMP_FROM_LAYER` (5)・`WALL_FROM_LAYER` (12)・`RAMP_TO`・`RAMP_JUMP`・`STEP_AFTER`・`LAYER_WALL`。`wallOf` (HP・攻撃・防御)・`agiWallOf` (素早さ)・`strongHpWallOf` (主・強敵のHP、`{boss, elite}`) が返し、`strengthAt`・`Battle` (`agiWall`/`strongHpWall`)・図鑑・表示Lv・召喚・戦闘の保存復元が同じ値を使う (二重に掛けない)。主・強敵・ミミック・出来事の魔物・金属・召喚された手下も素早さの段を受け、HPの追加は主・強敵だけ。無限迷宮 (`wall: 1`) と台帳外の素体は対象外。
- 出撃画面の「壁 HP×N・攻撃×N」と注意は、大きく跳ねる第十章 (第12層) からだけ出す。第三章〜第九章は推奨Lvを目安に、酒場の心得 `t_foe_ramp` (第三章から)・`t_foe_jump` (第四章の一段)・`t_foe_split` (硬さほど一撃は重くならない) で知らせる。
- 検証: `node tools/balance/walls-check.mjs` (全迷宮・全階・全個体)。
- 寄り道 (`side`)・格上の迷宮 (`challenge`) もその層の壁を受ける。主・強敵・ミミック・出来事の魔物も同じ (どれも `strengthAt` から作る)。
- **変えないもの**:
  - 推奨Lv の曲線 (levelcurve.js)。壁は Lv ではなく強さに乗せる — Lv上げ (✦Soul) では越えられない。✦ は推奨Lv +2 を超えると減る (`soulLvMul`) ので、浅い迷宮で Lv を上げて越えることもできない。
  - 戦果 (✦Soul・金貨)。1戦の戦果は推奨Lv の基準のまま (`battleRewardK` が強さを割り戻す)。強い敵ほど多く得る形にはしない。
- **無限迷宮は壁を受けない**: 独自の推奨Lv の表で強さを決めるので、無限迷宮の cfg には `wall: 1` を持たせる (第十一章以降の魔物が深い階に出ても壁は乗らない)。
- 今の奈落 (無限迷宮へ置き換わるまで) は層ごとに壁を受ける (`abyssCfg` の `layer`)。潜れる深さは主を倒した層までなので、本編の壁を越えた後にしか届かない。

## 3. 壁の越え方 (隊を鍛える手段)

第二部の1層ぶんの壁 (W ×約1.57) を越えるには、敵の HP の伸び (×約1.8) に追いつく攻撃と、攻撃の伸び (×約1.16) に負けない HP・VIT が要る。第二部の章の結びの解放もこの「答え」になるように並んでいる。

| 手段 | 何が伸びるか | 出どころ |
|---|---|---|
| 魂融合 | 魂の能力 (コモン +1% / レア +4% / エピック +10% / レジェンド +100% を1つごと) と Lv上限 | 無限迷宮で拾った魂を ＋1 の素材として持ち帰る |
| 魂の残火 | Lv上限 (第二部の推奨Lv Lv100〜 は上限が足りなくなる) | 本編の死体・無限迷宮 |
| 宝探し | 深い層の装備 (落とし物の帯)・LR | 本編の宝箱・無限迷宮の品 (商会の棚へ。追加の能力つき) |
| 鍛え直し | 装備の品質 (±20%) | 商会 (金貨) |
| 結社5席 (第十二章) | 全員の能力 | 控えの魂 |
| 付呪 (第十一章) | 装備に属性・耐性を1つ | 魂の残火 + 金貨 |
| 魂の転生 (第十四章) | 魂の能力 +5%/回 | 極めた魂 |
| サブ魂3枠 (第十七章) | 能力の分け前・借りる技 | — |

## 5. 第二部の章を作る時にすること

1. 台帳 (world.js) の強さの素 `power` は、第一部と同じく前の本筋の続きで付ける (壁は `LAYER_WALL` が掛けるので、`power` に壁を混ぜない)。
2. 模擬戦 (tools/balance) とテスト記録で段の値を合わせる。物差しの案:
   - **壁にぶつかる隊** = 推奨Lv・本筋だけで手に入る装備 (並品)・融合なし → 1戦の被ダメが壁のない物差しの約 k² 倍 (第十章の入口で約9倍)。
   - **答えた隊** = 想定の強化 (融合・品質・無限迷宮の品・その章までの解放) を入れた隊 → 第一部並み (1戦 7〜9%)。
   - 答えた隊を作れない (手段の伸びが足りない) 段なら、`LAYER_WALL` の値の方を下げる。直すのは `LAYER_WALL` の1か所。
3. その土地の壁を物語・心得・イレーヌの台詞で知らせる (第十一章の入口は特に)。
