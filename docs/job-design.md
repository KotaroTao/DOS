# 職業の固有化 設計表 (36職)

> 方針: **職業ごとに特色を持たせ、系統(職業)が違えば技もパッシブも一切共有しない。**
> この表は実装前の確認用。OK をもらってから `souls.js` / `combat.js` に反映する。

## 共通ルール

### 1. 技表の構成 (全職共通・Lv1〜200 の43段)
各職は **固有技11 + 固有パッシブ4種 (各3段) + 技の強化20段** で43段を埋める。

| 種別 | 習得Lv |
|---|---|
| 固有技 (11) | 1 / 3 / 7 / 15 / 25 / **40★** / 55 / 75 / 100 / 140 / **200 (奥義)** |
| 固有パッシブ (4種×3段) | P1: 5・50・110 / P2: 10・60・120 / P3: 20・70・130 / P4: 30・90・150 |
| 技の強化 (20) | 残りの段 (35, 45, 65, 80, 85, 95, 105, 115, 125, 135, 145, 155, 160, 165, 170, 175, 180, 185, 190, 195) |

- **★Lv40 = 看板技**。他の人業が「宿し技」として借りられるのはこれだけ。
- **技の強化**: Lv200の奥義を除く10技が、それぞれ **「改」(威力+30%)→「極」(威力+60%・追加効果も強化)** と育つ。若い技から順に強化Lvを割り当てる。新しい技を覚えると古い技が要らなくなる、ということを防ぐ。
- 技・パッシブの**名前と効果はどちらも36職で重複なし**。「単体回復」や「全体攻撃」のように役割は同じでも、効果には必ずその職だけの癖を付ける。たとえば回復なら、僧侶は純粋な回復魔法、司教は攻撃と兼ねる、義賊はゴールドで回復する、修験者は失ったHPを癒しに変える、といった具合。

### 2. 「専売」の能力 (この職しか持たない)

現在は1つの加護を最大3職で共有している。これも **36職すべてで別々の加護** に作り直す (各職の欄に記載)。

# 実装で新しく必要になる仕組み (見積もり用)

いまの戦闘エンジン (`combat.js`) にない仕組みのうち、この設計で必要になるもの:

| 区分 | 仕組み |
|---|---|
| 行動系 | 盗む (アイテム・ゴールド・MP・強化)、ジャンプ (空にいる間は攻撃を受けない)、召喚 (死霊)、即死、種族の消滅、呪文のコピー、離脱、行動順の操作 (先制・後回し)、2回行動 |
| 状態系 | バリア (吸収値)、リレイズ、予約回復、リジェネ、沈黙、異端、怯え、転倒、「HP0でも行動」、肩代わり (単体/全体、物理/呪文) |
| 資源系 | ゴールドを消費する技、HPを払う技 (一部はすでにある)、MPの譲渡 |
| 計算系 | 割合ダメージ、VITやINTで計算する物理技、属性の付与・書き換え、二重詠唱・溜め、怒りの累積 |

- **パッシブ**: 現在の53種のうち、職ごとの4種に組み直せるものは流用する (例: 連撃→修羅、鑑定→司教)。残りは新規で、約100種を追加する見込み。
- **結社加護**: 現在の17種に約19種を加えて、36種にする。
- **装備**: 戦士を全8種の武器に広げる。勇者は剣・刀・槍に絞る。
- **段階実装の案**: ① コモン6職 → ② レア12職 → ③ エピック10職 → ④ レジェンド8職。1段階ごとにPRを分け、各PRで「技・パッシブの名前と効果が36職で重複していないか」を自動チェックする。
