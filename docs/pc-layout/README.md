# PC向けの画面

幅1100px以上・高さ600px以上で、主ポインターがマウス相当、かつタッチ非対応の端末に適用する。スマホ・タブレット・狭いウィンドウは従来の配置を保つ。

街の施設メニューは左に常設。街では風景と行動、館では魂と能力を並べ、装備と共有袋は全幅で表示する。商会・図鑑・依頼・魂・出撃・物語の一覧は複数列。設定・詳細は中央のウィンドウで、本文だけがスクロールし、下部の操作を残す。右上の×は既存の戻る操作と同じ取消経路を通る。施設メニューは上下キー・Home・Endでも移動できる。

見本は試遊用の記録。街・館・商会・設定は1280×720、タイトルと物語詳細は1920×1080。外部フォントを使わない検証環境で撮影したもの。

## 確認方法

`python3 -m http.server 8000` で起動してから、`python3 tools/layout/desktop-screens-check.py` を実行する。既定の比較元はPCの探索・戦闘を追加した版（edc3edf8）。`DOS_TEST_BASELINE` で比較元のコミットを指定できる。`DOS_TEST_URL` でサーバーのURLも変更できる。

タッチ端末は変更前のCSS・共通UIを読み込んだページと画面寸法を比較する。PCでは各施設・シート25画面、タイトル2種、会話・序幕・職業一覧、上下キー・Esc・確認の取消を検証する。`DOS_TEST_SCOPE=pc` はタッチ端末の比較を省き、`DOS_TEST_SCOPE=scenes` は会話などの追加検証だけを行う。

`python3 tools/layout/desktop-check.py` では既存の探索・戦闘の配置と狭い窓への切り替えも確認する。検証用HTMLの起動監視だけ60秒に延長し、外部フォントの取得を省く。本体の起動監視・保存・ゲームの進行や計算は変更しない。
