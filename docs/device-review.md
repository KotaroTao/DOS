# PC・iPhoneの表示調整と実機レビュー

## 調整内容

- PC: 幅1000px以上でマウス操作の時、街・迷宮・シートの幅を520pxから640pxへ広げる。
- iPhone: 高さに応じて隊の札、見出し、戦闘コマンドの余白を詰める。名前・HP/MP・効果の札は残す。
- 戦闘: 戦場の高さを縦の余りに合わせる。短い戦場でも敵の名前が上下端で切れないようにする。
- 寸法の再計算: 隊の札や操作帯の高さが変わった時も盤面を合わせ直す。
- 試遊: 上部のバナーでゲームの下端やシートが隠れる問題を修正する。

ゲームの数値・セーブ形式は変更していない。タッチ端末の画面幅は520pxのまま。

街、人業の館、商会、王宮、出撃、探索、敵6体の戦闘をPlaywright/Chromiumで確認する。
Safariそのものの挙動と実機のタップ操作は、下記のレビューで確認する。

2026-10-12の検証: 上記8サイズ・56画面で実行時エラーなし。375×553、390×744、820×1180、1366×768では、出撃シートのタッチ/ホイールスクロールと情景の固定、戦闘ログと隊の重なり、技の選択と戻る操作、リサイズ後のコマンド、試遊バナーとシートの重なり、Canvasの画素も確認済み。WebKitは検証環境のライブラリ不足により実行できず、Safari固有の確認は実機レビューに残る。

## 実機での確認

1. PC: ウィンドウの高さを変え、探索・戦闘でログと最下部のコマンドが見えるか。
2. iPhone: Safariの上下バーを表示した状態と、ホーム画面から起動した状態で戦闘を確認する。
3. iPhone: 技の一覧、対象選択、出撃の地図を最後までスクロールできるか。
4. iPhone: 敵のタップと盤面のスワイプ、隊の札の長押しが操作できるか。
5. iPad: 普段の向きで街・出撃・戦闘が従来どおり表示されるか。

不具合の報告には、端末名・ブラウザ・縦横の向き・画面名を添えると再現しやすい。
PRの変更を公開版へ反映してから、実機レビューを行う。
