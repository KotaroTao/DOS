# 5枚ずつの制作と引き継ぎ

このチャットの統合担当が制作を割り当て、担当をバッチごとに交代する。
画像生成は Codex の画像生成ツールで行う。台帳コマンド自体は画像を生成せず、
新しいチャットや定期実行も開始しない。チャット終了後の継続には、これらの
ツールとリポジトリへアクセスできる Codex の実行が必要。

## 統合担当

```bash
node tools/storyart/batches.mjs init <開始コミットの40桁SHA>
node tools/storyart/batches.mjs next
node tools/storyart/batches.mjs claim batch-001 <担当のID>
node tools/storyart/batches.mjs collect batch-001
python3 tools/storyart/build.py
node tools/storyart/batches.mjs integrated batch-001
node tools/storyart/batches.mjs status
```

初期化は一度だけ。未出荷のストーリーを章ごとに最大5枚、次に由来の絵を最大5枚ずつ
割り当てる。出荷済みの絵は含めない。既存の原画がある場合は、担当が確認して再利用する。
台帳の書き込みは統合担当だけが行い、制作担当は自分の記録ファイルだけを更新する。
基準画像のハッシュを保存し、開始時から変わっていたら割り当てと統合を止める。

担当の記録を回収して全場面が ready になったバッチを目視確認し、build.py を実行する。
このコマンドは対象フォルダの原画全体を処理するので、確認が終わっていない原画は
別の作業場所に保持するか tools/storyart/hold.json の hold に入れておく。
登録・確認ページ・縮小見本は生成物。手で直さない。
PR を用意し、公開指示を受けてからマージする。integrated はローカル登録済みの意味で、
公開済みを意味しない。PR の URL と公開結果は統合担当が台帳の note に記録する。

## 制作担当

- AGENTS.md、作画指示書、docs/art/story-refs/README.md を読む。
- 各場面の prompt.mjs 出力に従い、必要な承認済み画像を実際に画像生成へ渡す。
- 画像生成へ渡す参照は最大5枚。人物・印の基準とセラの必須原画を優先し、
  同じ建物の重複参照を減らす。省いた参照と理由を担当記録に残す。
- 顔の参照として渡した人物が場面に登場するとは限らない。「描かないもの」を
  生成指示にも明示する。胸の扉などの秘密は場面の時系列に従う。
- 生成呼び出しは新規・修正・失敗を含めて最大7回。新規は最大5枚。
- 呼び出し前に生成回数を記録し、保存後はすぐに結果と目視確認を追記する。
- オルドの負傷・衣装、王の衰弱、セラの状態などは場面の時系列に合わせる。
- 印は sigil.png の承認済み形状を使用する。人物の実際の手の指とは区別する。
- 原画・担当記録以外を変更しない。原画は指定先へ1536×1024のPNGで保存する。
- 生成ツールが使用不可なら代替画像を作らず、理由を報告する。

担当の記録は `batch-001-worker.json` などへ、次の形式で保存する。
ready は基準画像・本文・手足・印・文字なし・縮小時の主題を確認できた場面だけに付ける。

```json
{
  "generationCalls": 1,
  "note": "",
  "scenes": [
    {
      "id": "w18_blade",
      "state": "ready",
      "note": "本文と基準画像、見える手足、文字なし、縮小時の主題を確認"
    }
  ]
}
```

修正待ちは needs-fix、ツール停止は blocked と記録する。
未完成なら collect はバッチを blocked にする。担当不明の停止も
`block <バッチID> <理由>` で保存する。元の担当が止まったことを確認してから
`resume <バッチID>` で割り当て直す。既存の原画と記録を読み、完成済みの絵は再生成しない。
担当交代で画像生成の利用枠が増えるとは限らない。利用上限の場合は繰り返し再試行せず、
再開可能になってから未完成分を進める。
resume は前担当の記録を attempt-N.json に残し、新担当の回数を0から数える。
完成済み場面の確認結果は引き継ぐ。collect 後に原画が変わると integrated は停止するので、
修正した原画は再確認して担当記録を更新し、collect をやり直す。
