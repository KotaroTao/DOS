# 第二章「捨て砦」の確認用原画

設定 → ストーリーに対応する全13場面。原画は各1536×1024、3:2のPNG。
`index.html` をブラウザで開くと、物語順に原画と本文を確認できる。画像を押すと原画を開く。
本文は `src/archive-stories.js` の第二章をそのまま記録し、`scenes.json` にも保存した。

制作時の作業環境には第一章の完成原画が未収録だったため、既存の序章の王・イレーヌ・隊の原画と `docs/story-art-plan.md` の人物基準を参照して制作した。
細かなドットの質感、月光とろうそくの光、衣装・木の器・黒鉄の継ぎ目を統一した。
全13枚はユーザーのマージ指示で承認済み。`art/story/chapter2/` にも保存し、ストーリー画面とSWのオフライン対象へ登録済み。

## 修正済みの箇所

- `w07_names`: カタカナと現実の文字に見える刻銘を世界独自の文字へ変更。古い名の風化と新しい名の深い爪刻みを描き分け、師の印を小さな刻みに修正。
- `mem_w09`: 記憶に混ざった王・宰相を除き、砦の主と亡兵の場面へ修正。
- `irene_sera`: 球形の灯を既存原画に合わせたろうそくと燭台へ修正。
- `w08_banner`: 砦に同行しないイレーヌを除去。
- `w09_map`: 王・イレーヌ・宰相と玉座を除き、捨て砦の軍議の間へ修正。
