# 第十二章「王家の廟」の挿絵

2026-10-19、ユーザーの指示で全14場面を制作。1536×1024のPNG原画をこのフォルダへ保存し、WebPを `art/story/chapter12/` へ登録した。ユーザー確認待ち。

- [本文と絵の確認](../review/chapter12.md)
- [384×256の縮小見本](../review/chapter12-small.jpg)
- [場面別の指示・参照画像と原画の記録](manifest.json)

指示は各場面の `node tools/storyart/prompt.mjs <場面ID>` の出力を使用。人物の基準画像と、王宮・館の既存原画を参照した。画像生成の参照上限は5枚のため、館の場面では燭台・人物・セラ原画を優先し、重複する小道具と館の参照を省いた。

廟の主は今の王とは別人。既存の `bs_cryptking.webp` と迷宮の由来、制作した初対面の絵を追加参照し、再挑戦・記憶・結びの姿と玉座をそろえた。「もう、よい」には、依頼の自動抽出で漏れたオルドの承認済み基準画像を追加した。

目視確認では各場面の人物・主題・空と光源・見える手足・読める文字の混入を確認。衣服や構図で隠れた指・脚の本数は直接確認できない。縮小見本でも手がかり・死面・玉座・灯が判別できることを確認した。

| 場面 | 修正・確認 |
|---|---|
| `w48_masks` | 参照から混入した今の王を除去。弟子と、年齢の異なる三枚の死面を残す。(済) |
| `irene_vessel` | イレーヌの開いた手の木目・指の継ぎ目を明確にする。(済) |
| `report_w49` | 卓上の金の杯を玉座の脇の床へ戻す。(済) |
| `w47_ledger` | 作業場の吊り灯を除去し、ろうそくと弟子の手提げ灯を光源にする。(済) |

修正前は `../fixes/<場面ID>-before.png`。元の生成ファイルも `/workspace/generated_images/` に保持した。

変換・登録・確認ページの更新は `python3 tools/storyart/build.py`。登録の一致・指示書と本文の一致・物語台帳の検査がすべて成功した。物語の本文とゲームの進行処理は変更していないため、酒場の話の追加はない。
